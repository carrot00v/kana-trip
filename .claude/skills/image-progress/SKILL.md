# 그림 생성 진행률

`tools/gen_image.py`로 돌리는 그림 배치의 상태를 한 번에 본다.

## 실행

배치의 결과 폴더와 이름별 장수를 알면 함께 넘긴다. 배치 스크립트나 `docs/design/*/brief.md`의 생성 표에서 알 수 있다.

```bash
python3 .claude/skills/image-progress/progress.py --dir <결과 폴더> --expect <이름>:<장수> <이름>:<장수>
```

모르면 인자 없이 실행해 ComfyUI 큐만 본다.

```bash
python3 .claude/skills/image-progress/progress.py
```

## 출력 읽기

- **ComfyUI 큐**: 실행 중인 작업과 대기 중인 작업을 시드와 그림 대상 문장 앞부분으로 보여 준다.
- **평균 시간**: ComfyUI 기록에서 최근 6장의 평균 생성 시간을 계산한다.
- **이름별 진행**: `<이름>_<시드>.png` 파일 개수를 센다.
- **남은 시간과 예상 완료 시각**: 남은 장수와 평균 시간으로 계산한다.
- **경고 두 가지**:
  - 작업이 평균의 두 배를 넘기면 경고한다. `gen_image.py`의 시간 제한(`--timeout`, 기본 1800초)에 걸리면 ComfyUI는 그림을 끝까지 만들지만 결과 폴더에는 저장되지 않는다. 그때는 ComfyUI `/history/<prompt_id>`에서 그림을 꺼내 `<이름>_<시드>.png`로 저장한다.
  - 스왑 사용량이 80%를 넘으면 메모리가 모자라 평소보다 느려진다.

## 사용자에게 알릴 것

- 한두 줄로 알린다: 몇 장 중 몇 장, 지금 그리는 그림, 남은 시간, 예상 완료 시각.
- 경고가 나오면 함께 알린다.
- 연결이 안 되면 CLAUDE.md "그림 생성"의 보류 규칙을 따른다.
