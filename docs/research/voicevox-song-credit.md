# VOICEVOX 노래 합성: 가창 교사(波音リツ) 크레딧 조사

조사한 날짜: 2026-11-16 (모든 출처를 이 날 확인했다)

## 조사 질문

글자 한 박 소리를 VOICEVOX core 0.17.1의 `s0.vvm`으로 만든다. 음소 길이·음량 곡선은 波音リツ ノーマル(style id 6000, 가창 교사)로 만들고, 음높이는 직접 평탄하게 덮어쓴 뒤, 소리는 春日部つむぎ(노래 스타일 id 3008)로 합성한다. 들리는 목소리는 春日部つむぎ다.

1. 이때 波音リツ 크레딧(`VOICEVOX:波音リツ`)이 필요한가. 공식 문서·약관·GitHub에 가창 교사의 크레딧을 다룬 문장이 있는가.
2. 波音リツ 권리자 약관의 상업 이용, 크레딧, 금지 사항 중 이 앱에 걸리는 것이 있는가.
3. 공식 근거가 없으면 안전한 쪽의 표기 예시.

## 결론

- **1번: 근거 없음.** 가창 교사로만 쓴 캐릭터의 크레딧이 필요하다는 문장도, 필요 없다는 문장도 공식 문서·약관·GitHub에서 찾지 못했다.
- 정황은 "필요 없다" 쪽이다. 공식 에디터는 2026-09까지 모든 가수의 교사를 波音リツ(6000)로 고정해 왔는데 [C5], 그동안 약관과 Q&A는 가수 캐릭터의 `VOICEVOX:캐릭터명`만 요구했다 [C1][C2][C3]. 다만 이것은 해석이고 공식 답이 아니다.
- **2번: 걸리는 것 없음.** 波音リツ 권리자 약관은 상업 이용 가능, 크레딧 표기 불필요이고, VOICEVOX를 쓸 때는 VOICEVOX 쪽 약관을 따르라고 한다 [C4]. 곧 波音リツ 표기를 요구할 수 있는 쪽은 VOICEVOX 약관뿐이다.
- **3번: 둘 다 적기를 권한다.** 波音リツ를 적어서 생기는 약관상 부담이 없고(권리자 약관이 가장 느슨하다), 적지 않았을 때의 불확실성만 없앨 수 있다.

권하는 크레딧 문구(앱 정보 화면, App Store 설명란):

```
音声: VOICEVOX:春日部つむぎ
歌い方(教師): VOICEVOX:波音リツ
```

한 줄로 줄이면 `VOICEVOX:春日部つむぎ / VOICEVOX:波音リツ`. 한국어 화면이면 "음성: VOICEVOX:春日部つむぎ (가창 보조: VOICEVOX:波音リツ)"처럼 풀어 써도 되지만, `VOICEVOX:캐릭터명` 부분은 약관에 적힌 모양 그대로 둔다.

## 1. 가창 교사의 크레딧에 관한 공식 문장

| 대상 | 확인한 내용 | 짧은 인용 | 출처 |
|---|---|---|---|
| VOICEVOX 음성 모델(VVM) 약관 (`.voicevox/voicevox_core/models/TERMS.txt`, 0.17.1) | 노래·교사·ハミング을 따로 다룬 조항이 없다. 캐릭터별 문장은 모두 "그 캐릭터의 음성 라이브러리를 써서 만든 음성"이 대상이다. 波音リツ 문장도 같은 모양이다 | 「波音リツの音声ライブラリを用いて生成した音声は、「VOICEVOX:波音リツ」とクレジットを記載すれば」 | [C1] |
| VVM README의 스타일 표 | `s0.vvm`의 波音リツ에 3009, 3065, 6000 세 줄이 있다. 6000이 교사라는 설명이나 크레딧 안내는 없다 | - | [C1] |
| VOICEVOX 소프트웨어 약관 | 노래·교사 조항 없음. VOICEVOX를 썼음을 알 수 있는 크레딧만 요구 | 「VOICEVOX を利用したことがわかるクレジット表記が必要です」 | [C2] |
| VOICEVOX Q&A | 노래·ハミング·교사 항목 없음. 가장 가까운 항목: 음성의 중간 표현(AudioQuery/FrameAudioQuery)을 VOICEVOX가 아닌 합성에 써도 크레딧이 필요하다. 어느 캐릭터 이름을 적는지는 적혀 있지 않다 | 「音声の中間表現(AudioQuery/FrameAudioQuery)を VOICEVOX 以外の音声合成に利用した場合は…必要です」 | [C3] |
| VOICEVOX ENGINE README | 쿼리 생성과 합성에 서로 다른 스타일을 넣을 수 있다고 안내한다. 공식 예제가 교사 6000 + 가수 3001이다. 크레딧 안내는 없다 | 「異なるスタイルを指定することも可能です」 | [C6] |
| 에디터 PR #3073 "歌い方変更機能を追加する" (2026-09-03 병합) | 이 PR 전까지 에디터는 교사 스타일을 波音リツ 6000으로 고정했다. 곧 그동안 에디터로 만든 ハミング 노래는 모두 波音リツ 교사를 거쳤다. PR 본문·댓글에 크레딧·약관 언급은 없다 | 「歌い方の生成に使うスタイルは波音リツ（styleId: 6000）に固定されていました」 | [C5] |
| 에디터 issue #3005 "歌い方(teacher)のUIを追加する" (열림) | 波音リツ를 "teacher 제공 캐릭터"라고 부른다. 크레딧·약관·권리 언급은 없다 | - | [C7] |
| 에디터 issue #1561 (내보내기 경로에 캐릭터 약관 동의 넣기, 열림) | 노래 쪽 내보내기도 있다는 메모만 있고 교사 캐릭터 언급은 없다 | - | [C8] |
| 공식 사이트 ソング 페이지, 사용법 페이지 | 波音リツ만 "ソング", 나머지는 "ハミング"으로 소개. 크레딧·교사 설명 없음 | - | [C9] |
| GitHub 검색 (VOICEVOX 조직의 issue·PR) | "歌唱教師" 1건(#3073), "singing_teacher" 27건(제목상 API·용어 논의), "クレジット ソング" 1건(#1561). 교사 크레딧을 묻거나 답한 글은 찾지 못했다 | - | [C10] |

해석:
- 약관 문장을 글자 그대로 읽으면 두 쪽 다 가능하다. 최종 소리는 春日部つむぎ의 합성 모델이 낸 것이므로 "波音リツ 라이브러리로 만든 음성"이 아니라고 읽을 수 있다. 반대로 길이·음량 곡선을 波音リツ 스타일 모델이 만들었으므로 "波音リツ 라이브러리를 써서 만든 음성"에 든다고 읽을 수도 있다.
- 에디터가 2년 넘게 교사를 6000으로 고정한 동안 VOICEVOX가 ハミング 이용자에게 波音リツ 크레딧을 요구한 흔적은 없다. 요구했다면 30명 가수 전부의 약관 문장이나 Q&A에 적혀 있어야 한다. 이것이 "필요 없다" 쪽 정황이다.
- Q&A의 중간 표현 항목은 "쿼리만 가져다 써도 크레딧 의무가 따라온다"는 VOICEVOX의 태도를 보여 준다. 쿼리를 만든 스타일이 크레딧과 무관하다고 단정하기 어렵게 하는 문장이다. 이것이 "적는 편이 안전하다" 쪽 근거다.
- KanaTrip은 음높이를 덮어쓰지만 음소 길이와 음량 곡선은 교사 값을 쓴다. 덮어쓴다고 교사를 쓰지 않은 것이 되지는 않는다.

## 2. 波音リツ 권리자 약관 [C4]

VVM 약관이 가리키는 `http://canon-voice.com/kiyaku.html`은 `https://www.canon-voice.com/terms`로 안내한다. 페이지 원문을 직접 읽었다.

| 항목 | 내용 | 짧은 인용 |
|---|---|---|
| 상업 이용 | 가능. 무상, 비독점 | 「商用利用可です。」 |
| 크레딧 | 권리자 약관으로는 불필요. VOICEVOX를 쓸 때는 "VOICEVOX" 크레딧이 필요하다고 따로 강조한다 | 「クレジット表記不要」 |
| 다른 소프트웨어에서 쓸 때 | 그 소프트웨어의 약관이 波音リツ 약관보다 우선한다. 소프트웨어가 금지한 것은 할 수 없다 | 「そのソフトウェアの規約に従ってください」 |
| 표현 제한 | 성적·폭력·정치·종교 표현을 기본적으로 금지하지 않는다 | - |
| 금지·조건 | 범죄 이용은 별도 허락 필요(6조 3항). 권리자가 부적절하다고 판단해 공개 중지·삭제를 요청하면 따라야 한다(8조 2항). 약관은 예고 없이 바뀔 수 있다(8조 1항) | 「公開中止・削除を求めた場合は、要請に従っていただく」 |
| 앱·게임, AI 생성 그림, 기계 학습 | 따로 다룬 문장 없음 | - |

해석:
- 학습 앱에 걸리는 금지 항목은 없다. 개인·법인 구분도 없다.
- 요청 시 삭제 조항(8조 2항)은 앱에 번들한 소리에도 적용될 수 있다. 春日部つむぎ만 쓸 때에는 없던 조건이지만, 약관 요약이 "거의 있을 수 없는 큰 문제에 대비한 것"이라고 설명한다.
- 권리자 약관이 크레딧을 요구하지 않으므로, `VOICEVOX:波音リツ` 표기 의무가 있다면 그 근거는 VVM 약관 문장 하나다. 그 문장이 교사 용도에 미치는지가 1번의 "근거 없음"이다.

## 3. 표기 제안

| 안 | 문구 | 평가 |
|---|---|---|
| A (권함) | `音声: VOICEVOX:春日部つむぎ` + `歌い方(教師): VOICEVOX:波音リツ` | 두 해석 모두를 채운다. 역할을 나눠 적어 "들리는 목소리가 波音リツ"라는 오해를 막는다. "歌い方(教師)"는 에디터 PR이 쓰는 말이다 [C5] |
| B | `VOICEVOX:春日部つむぎ / VOICEVOX:波音リツ` | 짧다. 역할 구분이 없다 |
| C | `VOICEVOX:春日部つむぎ`만 | 정황상 통할 가능성이 높지만 공식 근거가 없다 |

- 위치는 春日部つむぎ 약관과 기존 조사(`voicevox-terms.md`)의 기준대로 앱 정보 화면과 App Store 설명란.
- 확답이 필요하면 물을 곳은 VOICEVOX 쪽이다(波音リツ 권리자는 VOICEVOX 약관을 따르라고 한다). 다만 공식 Q&A는 약관 준수 여부 질문에 원칙적으로 답하지 않는다고 밝히고 있다(`voicevox-terms.md` [S5]).

영향:
- 영향: 크레딧 화면에 波音リツ 한 줄이 더 든다. 화면 문구는 designer·PM 사안이다.
- 영향: 0.17.1의 `s0.vvm`에는 `sing` 종류 스타일이 6000 하나뿐이라 교사를 바꿔 이 문제를 피할 수 없다(`docs/design/voice/README.md` 5차). 에디터 쪽에는 2026-09에 교사 선택 기능이 들어갔으므로 [C5], 나중 버전의 모델에 다른 교사 스타일이 생기는지는 볼 만하다.
- 영향: 공개 직전에 春日部つむぎ, 波音リツ 두 약관 페이지를 다시 확인해야 한다(둘 다 예고 없이 바뀔 수 있다).

## 확인하지 못한 것

- 가창 교사 크레딧에 대한 VOICEVOX 공식 답. 문의하지 않았다.
- X(트위터)의 VOICEVOX 공식 계정·개발자 발언, 디스코드. 검색으로 닿지 않았다.
- 에디터 0.26 이후 버전의 화면(교사 선택 UI, 내보내기 때 뜨는 약관 안내)에 교사 캐릭터 약관이 표시되는지. 실행해 보지 않았다.
- GitHub 검색은 인증 없이 몇 가지 검색어로만 했다. `voicevox_blog` 저장소의 Q&A 변경 기록(중간 표현 항목이 언제, 어떤 논의로 들어갔는지)은 요청 한도에 걸려 보지 못했다.
- 波音リツ 약관 페이지에 개정일 표기가 없어 마지막 개정 시점을 알 수 없다.
- 법률 검토는 아니다. 약관 문장과 공개 자료를 읽은 결과다.
