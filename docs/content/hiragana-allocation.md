## 1. 요약

- 장면 순서: **스시집 → 돈카츠집 → 소바·우동집 → 역 → 신사·축제 → 이자카야 → 온천 → 료칸**. 장면마다 단계 a, b 두 개.
- 기본 히라가나 46자를 16단계에 한 번씩 배정했다. 장면별 5~6자, 단계별 2~4자.
- 단어 60개. 두 단계에 겹치는 단어는 없다. 46자 모두 자기 단계의 단어에 한 번 이상 나온다.
- 60개 중 35개가 그 단계까지 배운 글자로 전부 읽힌다(탁음을 못 읽는 글자로 셀 때). 3a(소바·우동집 간판)만 전부 읽히는 단어가 없다. 3a의 そば, うどん은 탁음 1자씩만 발음 표기가 붙는다.
- 탁음·반탁음이 든 단어 19개, 촉음 1개(きっぷうりば), 요음 0개. 가르치지 않는 한자가 붙은 단어 3개(かつ丼, ぬる湯, ほうじ茶).

- **장면 1의 배우기 순서는 확정**: 1a す → し, 1b い → か → た → こ. 1a에서 すし가, 1b에서 か까지 배우면 いか가, こ까지 배우면 たこ가 완성된다.
- 장면 2~8의 배우기 순서는 PLAN.md 8번 미정 항목이다. 정해질 때까지 표의 순서를 쓴다. 3b는 き ね け め 순서로 두어 きつね → かけ → おかめ 순서로 단어가 완성된다.
- 1~3번을 홈에서 묶을지는 designer 판단이다.

### 2.2 순서 근거

- 밥집 3장면은 사용자 요청("스시 간판 > 스시 메뉴 > 돈카츠 간판 > 돈카츠 메뉴")대로 앞에 묶었다. 회전초밥과 소바·우동 메뉴는 히라가나 품명이 많다 [웹 16, 17, 21, 22], [조사 15].
- 역의 えき, のりかえ에 필요한 き가 3b(소바 메뉴의 きつね)에서 나오므로 역은 밥집 뒤다.
- 이자카야의 やきとり, ささみ에 필요한 や, み가 5번(신사·축제)에서 나오므로 신사·축제가 이자카야 앞이다.
- 낮(신사) → 저녁(축제, 이자카야) → 밤(온천, 료칸) 동선과도 맞다.
- 채팅 데이터(메시지 / 사람): 체인 식당 1,808 / 76, 스시 827 / 80, 전철·JR 691 / 76, 신사·절 290 / 57, 축제 775 / 58, 이자카야 825 / 77, 온천·료칸 554 / 62 (`docs/research/travel-chat-analysis.md`).

### 3.3 새 글자를 소화하는 단어

| 단계 | 글자 → 그 글자가 나오는 자기 단계 단어 |
|---|---|
| 1a | す し → すし |
| 1b | い → いか, いくら, いなり / か → いか / た → たこ / こ → たこ |
| 2a | と ん → とんかつ / つ → とんかつ, かつ丼 |
| 2b | お → おろし, おかわり / ひ れ → ひれかつ |
| 3a | そ → そば / う → うどん |
| 3b | き → きつね, たぬき / ね → きつね / け → かけ / め → おかめ, わかめ |
| 4a | え → えき / り → おつり, きっぷうりば |
| 4b | の → のりかえ, のりば / ち → こちら, でぐち, いりぐち / ら → こちら |
| 5a | ま → おまもり, おまいり / み → おみくじ / も → おまもり |
| 5b | あ → あたり, りんごあめ / や → たこやき, やきそば / は → はずれ |
| 6a | く → つくね / わ → かわ / む → むね |
| 6b | さ → ささみ / に → おにぎり / な → なんこつ |
| 7a | ゆ → ゆ, ゆかた / せ → おんせん |
| 7b | ぬ → ぬる湯, くつをぬいでください / る → ぬる湯 / を → くつをぬいでください (문구) |
| 8a | よ → ようこそ / て → おもてなし / ほ → ほうじ茶 |
| 8b | ふ → おふろ, ふとん / へ → おへや / ろ → おふろ |

배정에서 감수한 점:

- 1a는 단어가 すし 하나다. 첫 세션이라 짧은 것은 장점이지만 단어 읽기가 한 번으로 끝난다.
- 1b와 3b는 4자로 단계 중 가장 길다(약 3.1분 추정). 1b에서 こ를 빼면 たこ가 1자 못 읽는 단어가 된다. 3b의 め를 3a로 되돌리면 3a에 め가 나오는 간판 단어가 없다.
- 3a는 전부 읽히는 단어가 없다. 소바·우동집 간판의 단어 そば, うどん은 둘 다 탁음이 하나씩 있다. 탁음을 기본 글자로 보면 うどん은 다 읽힌다(ど → と, 2a).
- ひ れ는 ひれかつ 하나로만 소화되고, 히라가나 ひれ 표기는 とんかつ和幸 한 체인에서만 확인했다 [조사 23]. 유지 이유는 7.4.
- を는 문구 くつをぬいでください에만 나온다 (PLAN.md 8번 미정).
- ほ는 ほうじ茶 하나로만 소화되고, ほうじ茶는 탁음(じ) 1자에 발음이 표기된다. る는 ぬる湯 하나로만 소화된다.

## 4. 단계별 단어

### 4.0 열 설명

- **못 읽는 글자 수**: 그 단계까지 누적한 글자(3.1의 "이 단계까지 누적")로 읽을 수 없는 글자 수. 같은 글자가 두 번 나오면 두 번 센다. 탁음·반탁음과 작은 글자(っ)는 배운 적 없는 글자로 센다. 한자는 세지 않는다 (PLAN.md 3번 "단어의 표기").
- **탁음을 기본 글자로 보면**: ば → は처럼 기본 글자로 바꿔 센 값. 작은 글자는 그대로 못 읽는 글자로 센다.
- **표시**: 탁 = 탁음·반탁음, 촉 = 촉음, 장 = 장음, 한 = 가르치지 않는 한자. 단어 읽기 화면에서는 못 읽는 글자와 한자 위에 발음을 표기한다 (PLAN.md 3번, 5번).
- 장 표시는 처리 규칙과 무관한 참고 표시다. 히라가나 장음은 모음 글자(う)로 쓰므로 새 글자가 필요하지 않다.
- 표의 단어 순서가 데이터의 단어 순서다. 전부 읽히는 단어를 앞에 두었다.

## 7. 결정 결과

### 7.1 2026-11-14 개편안 B 채택 (PLAN.md 3·4·5번)

1. **장면 구조**: 장면 8개, 장면당 새 글자 5~6자 유지. 장면 안을 단계 2개로 나누고 새 글자를 단계에 2~4자씩 배정. 단계 하나 = 세션 하나(배우기 → 퀴즈 → 단어 읽기). 배정은 이 문서 2·3번.
2. **복습 글자 섞기**: 장면 단위 그대로. 이전 장면에서 틀린 글자를 다음 장면 **첫 단계(a)**의 퀴즈에 섞는다. 단계 b의 퀴즈에는 섞지 않는다. 섞는 글자 수는 PLAN.md 8번 미정(임시 최대 3자).
3. **라멘·규동·정식 메뉴**: 히라가나 장면에서 다루지 않고 가타카나 "식당" 장면 후보로 넘긴다. 이 메뉴들은 가타카나(ラーメン, チャーシュー, セット)와 한자(醤油, 牛丼, 定食)가 중심이고 히라가나 표기는 정해져 있지 않다 [웹-요약 10, 24, 27]. 돈카츠의 가타카나 부분(ロース, ヒレ, キャベツ)도 같은 장면 후보다. 한자 품명 위에 앱이 발음을 다는 방식(요미가나)은 쓰지 않는다 [웹-요약 28].

### 7.2 이전 결정 중 계속 유효한 것

1. **탁음 처리**: 허용하고 발음 표기 (2026-11-12, 5번).
2. **보통 한자로 쓰는 단어**: 히라가나로 실을 수 있다. 근거 열에 보통 표기를 적는다 (2026-11-12).
3. **가나 + 한자 한 글자 단어**: かつ丼, ぬる湯, ほうじ茶는 현지 표기대로 한자를 붙이고 가르치지 않는다 (2026-11-13).
4. **공항**: 가타카나 장면 (2026-11-12).

### 7.3 이전 결정 중 바뀐 것

- 첫 장면 "밥집 간판"과 배우기 순서 す し と ん か つ → 첫 장면 "스시집", 1a す し, 1b い か た こ.
- 이미 만든 쓰기 포인트 문구: `hiragana_tips.json`의 す し い か こ는 장면 1에서 쓴다(か는 10.3의 짧은 문구로 바꾼다). と ん つ는 장면 2a에서, よ う そ く는 각각 8a, 3a, 3a, 6a에서 다시 쓴다.

### 7.4 2026-11-14 현지 표기 확인 반영

1. **5a 신사**: おさいせん을 뺀다. 대체 단어는 넣지 않는다. ま み も는 おまもり, おまいり, おみくじ로 소화된다. 남은 신사 단어 4개는 모두 [지식]이라 확인이 필요하다(조사 질문 1).
2. **소바·우동집**: そうめん을 빼고 め를 3a에서 3b로 옮긴다. 3a そ う / 3b き ね け め. め는 3b의 おかめ(0자 못 읽음), わかめ(1자)로 소화한다. 이유: 소바집 간판 단어는 そば, うどん뿐이고 둘 다 め가 없다. め가 나오는 소바 단어(おかめ, わかめ, なめこ)는 모두 메뉴 품명이다. 감수: 3a에 전부 읽히는 단어가 없고(탁음 1자씩), 3b가 4자가 된다.
3. **돈카츠집 메뉴 2b**: お ひ れ를 그대로 둔다. 이유:
   - ひれかつ의 근거는 한 체인이지만 공식 메뉴(1차 자료)다 [조사 23]. 출처가 없거나 현지 표기가 다른 おさいせん, そうめん과는 경우가 다르다.
   - ひ れ를 옮기면 2b에 お 1자만 남아 단계당 2자 하한을 어긴다. 맞추려면 2b에 다른 글자를 들여와야 하고, ひ는 7b(ひのき), れ는 5b(はずれ)로 가야 하는데 5b가 4자가 되면 장면 5가 7자로 6자 상한을 넘는다. 장면 3개 이상을 다시 짜야 하고, 새로 들어갈 단어(ひのき, はずれ)의 근거도 [지식]이나 업체 설명 수준이라 근거가 나아지지 않는다.
   - ひれかつ는 2b의 새 글자 3자를 모두 쓰고 다 읽히는 유일한 단어라, 단계 끝에 완성되는 목표 단어로 맞다. 보조 설명에 "ヒレ로 쓰는 가게도 많아요"를 적어 가타카나 장면의 ヒレ와 잇는다.
   - 이 판단으로 PLAN.md 8번의 "돈카츠집 메뉴 단계 근거가 약함" 항목은 닫을 수 있다.
4. **근거 표시**: たこ는 단독 품명 근거가 생겼다(スシロー). ごはん, おかわり는 1차 근거(濵かつ 공식)가 생겼지만 체인마다 표기가 다르다. あたり, はずれ는 업체 상품 설명 수준이고 제비뽑기 결과 맥락으로 싣는다. りんごあめ는 히라가나 노보리 기성품이 있다.
5. **장면 1 배우기 순서**: 1a す → し, 1b い → か → た → こ로 확정.

아직 정하지 않은 것은 PLAN.md 8번에서 관리한다.

## 8. 데이터로 옮길 때 참고 (developer)

- 단계마다 필요한 값: 장면 번호, 단계(a/b), 단계 이름, 새 글자(3.1의 배우기 순서), 단어(4번 표의 순서).

- 한자(丼, 湯, 茶)는 배운 글자 계산에서 빼고 늘 발음을 표기한다. 퀴즈에 내지 않는다.

- 장면 진입 화면의 목표 단어와 글자 소개의 단어 카드는 단계 단어에서 가져온다(PLAN.md 3번 "장면 연결"). 어느 단계 단어를 몇 개 보여 줄지는 designer 판단이다.

### 10.3 쓰기 포인트 문구 (`hiragana_tips.json`)

L1·L2의 쓰기 포인트 상자는 한 줄 약 19자(15pt, 글 폭 약 295pt, `scene-flow.md` 8.4)로 본다. 두 문구 모두 2줄 이내다. 실제 줄 수는 시뮬레이터에서 확인한다.

| 글자 | 문구 | 글자 수 (공백 포함) | 줄 나눔 추정 | 상태 |
|---|---|---|---|---|
| か | 1획 끝을 왼쪽으로 살짝 올려요. 3획은 오른쪽에 짧게 써요. | 34 | "1획 끝을 왼쪽으로 살짝 올려요." (18) / "3획은 오른쪽에 짧게 써요." (15) | 지금 문구(약 68자, 4줄)를 바꾼다 |
| た | 오른쪽 두 획은 떼어 써요. 아래 획이 더 길어요. | 28 | 2줄 | 새 초안. 쓰기 포인트가 없는 글자(PLAN.md 8번)에서 た를 뺄지는 PM이 정한다 |

- か는 이전 문구의 "2획은 1획을 가로질러 왼쪽 아래로"를 뺐다. 획순 가이드와 시작점 번호가 이미 보여 주는 내용이고, 헷갈리는 곳은 1획 끝의 삐침과 떨어진 짧은 3획이다.
- た는 1b에서 こ보다 먼저 배우므로 こ를 들어 설명하지 않았다. 3획과 4획을 이어 쓰거나 길이를 같게 쓰는 실수를 겨냥했다. 고리가 없는 글자라 판정은 바꾸지 않는다.
