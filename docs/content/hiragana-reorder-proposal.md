## 1. 요약

- **첫 장면: 밥집 간판** (스시·소바·우동·돈가스 가게의 노렌과 간판). 새 글자 **す し と ん か つ** (획 수 2, 1, 2, 1, 3, 1). 두 번째 글자 し를 배우면 すし가 읽히고, 여섯 번째 つ에서 とんかつ가 읽힌다. 단어 6개 중 3개가 배운 글자만으로 전부 읽힌다 (현재 공항은 5개 중 2개).
- **공항: 히라가나에서 빼고 가타카나 장면으로 옮긴다** (나안). 히라가나에는 **이자카야**를 새로 넣는다.
- **새 순서**: 밥집 간판 → 역 → 거리 → 신사 → 축제 → 이자카야 → 온천 → 료칸.
- 46자 배정 검산: 누락 0, 중복 0. 장면별 6, 5, 6, 6, 6, 6, 5, 6자.
- 이미 구현된 よ う こ そ く는 새 첫 장면에 하나도 남지 않는다. く こ는 거리, そ는 축제, う는 이자카야, よ는 료칸으로 간다. 획 데이터는 46자 모두 이미 있다. 새 첫 장면에서 새로 써야 하는 쓰기 포인트 문구는 と ん か 3자다 (し つ す는 `hiragana_tips.json`에 있다).
- 18자가 장면을 옮긴다. 기존 미정 중 온천 단어는 かけゆ, にごりゆ가 빠지고 ぬるゆ 하나만 남는다. を는 그대로 문구 くつをぬいでください로 남는다.

### 2.2 권장: A. 밥집 간판

- 노렌과 간판의 업종 표시(すし, そば, うどん, とんかつ)는 현지에서 히라가나로 보는 대표적인 글자다. 앱의 첫 3분에 배운 글자를 숙소 근처 첫 끼니 거리에서 바로 찾을 수 있다.
- 배우기 순서를 す → し → と → ん → か → つ로 두면 두 번째 글자에서 すし가 완성된다. 장면 진입 화면의 목표 단어 카드가 가장 빨리 채워지는 순서다.
- 획: す 2, し 1, と 2, ん 1, か 3, つ 1 [지식. 획 수는 `hiragana_strokes.json`과 대조 필요]. 3획은 か 하나다. ぬ ね む ほ는 6~8번 장면에 있다.
- 약점: 세 번째로 전부 읽히는 단어 かつ가 약하다. 현지에서는 かつ丼(가쓰동)처럼 한자와 붙여 쓰고, 같은 음식을 カツ丼으로 쓰는 가게도 많다(체인 かつや의 깃발이 カツ丼) [웹 8, 9]. 빼면 전부 읽히는 단어가 2개로 현재와 같아진다. 7번 결정 2.
- 검토하고 버린 조합: 이미 구현된 こ를 살리는 す し と ん こ つ (すし, とんこつ). とんこつ는 라멘 간판에 豚骨와 섞여 쓰이고 [웹-요약 10], 전부 읽히는 단어가 2개라 조건을 넘지 못한다. う를 살리는 す し と ん う か도 うどん의 ど가 탁음이라 전부 읽히는 단어가 すし 1개다.

## 3. 공항을 어디로 보낼지

| | (가) 히라가나 뒤쪽 장면 (귀국·기념품) | (나) 가타카나 장면으로 이동, 히라가나에 새 장면 |
|---|---|---|
| 현장에서 읽히는지 | 약하다. 공항에서 히라가나로 확인된 단어는 おみやげ 하나다 (scene1-airport-review.md 2.4). ようこそ는 기간 한정 보드 1건 | 강하다. 공항 표지의 トイレ, バス, タクシー는 가타카나로 쓴다 [웹: 하네다 사이트가 トイレ만 씀, scene1-airport-review.md 2.5] |
| 8장면 유지 | 기존 8장면 중 하나를 빼야 공항이 들어간다. 첫 장면 밥집이 기존 밥집(4번)을 흡수해서 자리가 하나 남으므로 가능은 하다 | 공항이 빠진 자리에 이자카야를 넣는다 |
| 채팅 데이터 | 공항·입국 1,198 / 86 (사람 수 1위)을 히라가나 뒤쪽에서 늦게 다룬다 | 같은 수요를 가타카나에서 다룬다. 공항버스·리무진 162 / 41도 バス로 이어진다 |
| 비용 | 공항 단어 5개 중 3개가 실제로는 한자 표기라는 문제가 그대로 남는다 | 가타카나 단어에 장음(ー, タクシー)과 작은 글자(チェックイン)가 많다. PLAN.md 8번의 장음·촉음 처리 미정 항목에 걸린다 |

**권장: (나).** 이유는 첫 장면을 바꾼 이유와 같다. 공항 표지는 한자와 가타카나가 중심이라, 히라가나 뒤쪽에 두어도 "배운 글자를 현장에서 읽는다"는 목적에 맞지 않는다. 히라가나에 새로 넣는 장면은 이자카야를 권한다. 채팅 데이터가 크고(825 / 77, 스몰토크 목표 11명), やきとり, つくね, かわ처럼 메뉴가 히라가나로 확인되며, 단어가 적은 ね, わ, け를 소화할 수 있다.

가타카나 공항 단어 후보는 [지식]이며 이 문서의 범위 밖이다: トイレ, バス, タクシー, ゲート, チェックイン.

## 5. 장면별 단어

표의 열은 `hiragana-allocation.md` 4번과 같다. 못 읽는 글자 수는 그 장면까지 배운 글자로 읽을 수 없는 글자 수이고, 탁음·반탁음과 작은 글자(っ, ゃ)는 못 읽는 글자로 센다. "탁음을 기본 글자로 보면"은 ば → は처럼 바꿔서 센 값이다. 비고 끝에 근거 표시를 붙였다.

### 6.2 장면을 옮기는 글자 (18자)

| 글자 | 기존 장면 | 새 장면 |
|---|---|---|
| す | 3 거리 | 1 밥집 간판 |
| と | 3 거리 | 1 밥집 간판 |
| し | 4 밥집 | 1 밥집 간판 |
| ん | 4 밥집 | 1 밥집 간판 |
| つ | 4 밥집 | 1 밥집 간판 |
| か | 2 역 | 1 밥집 간판 |
| く | 1 공항 | 3 거리 |
| こ | 1 공항 | 3 거리 |
| た | 4 밥집 | 5 축제 |
| そ | 1 공항 | 5 축제 |
| う | 1 공항 | 6 이자카야 |
| ね | 4 밥집 | 6 이자카야 |
| わ | 6 축제 | 6 이자카야 |
| ら | 6 축제 | 6 이자카야 |
| け | 7 온천 | 6 이자카야 |
| に | 7 온천 | 6 이자카야 |
| ぬ | 4 밥집 | 7 온천 |
| よ | 1 공항 | 8 료칸 |

나머지 28자(え き の り お / い ち ま れ / み も む さ せ な / や あ め は / ゆ る ひ を / ふ へ ほ ろ て)는 같은 이름의 장면에 남는다. 신사와 축제는 장면 번호만 하나씩 앞당겨진다.

### 6.3 이미 구현된 よ う こ そ く

- 새 첫 장면에 남는 글자: 없음. 빠지는 글자: 5자 모두.
- 옮겨 가는 곳: く こ → 3 거리, そ → 5 축제, う → 6 이자카야, よ → 8 료칸. ようこそ는 료칸에서 전부 읽히는 단어로 다시 나온다.
- 버려지는 것은 없다. 5자의 쓰기 포인트 문구와 획 데이터 검토는 옮겨 간 장면에서 그대로 쓴다.
- 새로 필요한 것: と ん か의 쓰기 포인트 문구 3개. し つ す 문구는 `hiragana_tips.json`에 있고, 획 데이터는 46자 모두 `hiragana_strokes.json`에 있다.
- 첫 장면 글자를 더 살리는 조합도 검토했지만(2.2 끝), 첫 장면의 목적(전부 읽히는 단어 3개 이상)을 채우지 못했다. 사용자가 정한 우선순위대로 현장에서 읽히는 쪽을 택했다.
- 장면 1 데이터(`hiragana_scenes.json`), 화면 설계의 예시(`docs/design/scene-flow.md`는 장면 1 예시를 모두 よ う こ そ く와 공항 단어로 채움)는 이 제안이 확정되면 다시 써야 한다. 이 문서에서는 고치지 않았다.

### 6.4 기존 미정 항목에 미치는 영향

| PLAN.md 8번 항목 | 영향 |
|---|---|
| 온천 단어 재선정 (かけゆ, ぬるゆ, にごりゆ) | かけゆ(け가 이자카야로 감), にごりゆ(に가 이자카야로 감)는 빠진다. おんせん, ゆかた를 넣었다. ぬるゆ는 る를 소화할 다른 단어를 찾지 못해 남는다. 항목이 "ぬるゆ 하나"로 줄어든다 |
| を 처리 | 바뀌지 않는다. 여전히 온천의 문구 くつをぬいでください 하나로만 나온다. 이 문구는 이제 ぬ도 함께 소화한다 (ぬるゆ와 둘) |
| 공항 단어 5개 중 3개가 전부 발음 표기 | (나)안을 고르면 히라가나에서는 항목이 없어진다 |
| 히라가나 첫 장면, 공항의 행방, 재배정 | 이 문서가 답이다. 확정되면 항목이 닫힌다 |
| 단어의 뜻과 현지 표기 확인 | 첫 장면 6개는 웹으로 확인했다 (かつ, とんこつ는 확인 강도가 약함). 이자카야 6개 중 5개 확인. 축제·온천·료칸은 대부분 [지식] |
| 쓰기 포인트 문구 | と ん か 3자가 첫 장면 우선순위로 올라온다 |
| 가타카나 장면 3개 미정 | 공항이 하나를 차지한다. 가타카나 후보로 적힌 이자카야는 히라가나로 왔으니 후보 목록에서 정리가 필요하다 |

## 8. PLAN.md 3번과의 관계

3번의 확정 결정을 바꿀 것은 없다. 다만 3번 밖에서 공항을 전제로 한 문장이 남는다: 2번 차별점의 "공항, 역, 식당 같은 장면", 6번 구현 순서의 "장면 1개(공항, 히라가나 5자)". 확정 시 PM이 함께 고칠 대상이다.
