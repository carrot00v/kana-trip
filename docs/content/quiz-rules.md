## 0. 요약

- 장면 하나 = 세션 3개: 단계 a(배우기 → 단어 읽기), 단계 b(배우기 → 단어 읽기), **종합 퀴즈 `{장면 id}-quiz`**. 단계 세션에는 퀴즈가 없다.
- 종합 퀴즈는 3부로 나뉜다. **1부 글자 보고 발음 고르기 → 2부 단어 보고 읽기 고르기 → 3부 기억으로 쓰기**. 장면의 새 글자 5~6자는 모두 1부와 3부에 한 번씩 나온다.
- 쓰는 유형은 (가), (라), (다)다. (나) 발음 보고 글자 고르기와 (마) 단어 보고 뜻 고르기는 뺀다 (2번).
- 복습 글자: "복습 대기 목록"에서 최대 3자(임시값, PLAN.md 8번)를 골라 1부와 3부에 고르게 끼운다. 한 번에 다 못 섞은 글자는 다음 장면으로 넘어간다.
- 단어 문항: 장면 1은 3개(이 장면 3), 장면 2~4는 3개(이 장면 2 + 직전 장면 1), 장면 5~8은 4개(이 장면 2 + 직전 장면 1 + 지난 장면 1). 이 장면까지 배운 글자로 전부 읽히는 단어만 쓴다. 탁음·한자·장음이 든 단어는 쓰지 않는다.
- 오답 보기는 헷갈리는 글자 쌍(19쌍, 4.1)을 먼저 넣는다. 쌍은 두 글자를 모두 배운 뒤에만 쓰므로 뒤 장면일수록 오답이 어려워진다.
- 통과: 모든 문항을 맞힐 때까지 부 끝에 다시 낸다. 첫 시도 정답률 기준은 두지 않는다.
- 세션 길이 추정: 복습 글자 없을 때 1.7~2.1분, 복습 3자일 때 2.5~2.9분, 복습 3자에 두 번 틀리면 최대 3.2분 (7번).
- 단계 세션 보완: 단계 b의 단어 읽기 맨 앞에 단계 a의 첫 단어 하나를 "다시 읽기"로 넣는다 (9번).

## 1. 세션 구조

| 세션 id | 내용 | 열리는 조건 | 끝나면 |
|---|---|---|---|
| `{장면 id}-a` | 배우기 → 단어 읽기 | 앞 장면 완료 (장면 1은 처음부터) | 단계 b가 열림 |
| `{장면 id}-b` | 배우기 → 단어 읽기 | 단계 a 완료 | 종합 퀴즈가 열림 |
| `{장면 id}-quiz` | 1부 → 2부 → 3부 | 단계 b 완료 | 장면 완료, 다음 장면의 단계 a가 열림 |

- 장면 id는 `sushi`, `tonkatsu`, `soba`, `station`, `shrine`, `izakaya`, `onsen`, `ryokan` (scene-flow.md 17번 결정 11).
- 종합 퀴즈의 "이 장면까지 배운 글자"(이하 **L**)는 앞 장면들의 새 글자 전부 + 이 장면의 두 단계 글자 전부다. 퀴즈가 열릴 때는 두 단계의 배우기를 모두 끝냈으므로 이 값은 진행과 무관하게 데이터로 정해진다. 장면 1 6자, 장면 2 12자, 장면 3 18자, 장면 4 23자, 장면 5 29자, 장면 6 35자, 장면 7 40자, 장면 8 46자 (hiragana-allocation.md 3.1).
- 이 장면의 새 글자(이하 **N**, n자): 두 단계의 새 글자를 단계 순서대로 이은 것. 장면 1: す し い か た こ.
- 복습 글자(이하 **R**, r자, 0~3): 5.4의 복습 대기 목록에서 고른 글자.
- 이 퀴즈의 글자(이하 **Q**) = N + R.
- 화면 배치, 부 사이 안내 화면, 진행 막대, 완료 화면은 designer가 정한다. 이 문서는 문항의 내용과 순서, 판정만 정한다.

## 2. 문항 유형

| 유형 | 문제 | 보기 | 확인하는 능력 | 결정 |
|---|---|---|---|---|
| (가) 글자 → 발음 | 글자 하나 | 로마자 4개 | 글자 모양을 보고 소리를 떠올리는 인식. 현지 표지를 읽을 때 쓰는 능력 그대로다 | **쓴다 (1부)** |
| (나) 발음 → 글자 | 로마자 하나 | 글자 4개 | 소리에 맞는 모양을 비슷한 모양 사이에서 가려내는 변별 | **뺀다** |
| (다) 기억으로 쓰기 | 로마자 하나 | 캔버스 | 모양을 기억에서 꺼내 획순대로 쓰는 회상. 가장 어렵다 | **쓴다 (3부)** |
| (라) 단어 → 읽기 | 단어 하나 | 로마자 단어 4개 | 여러 글자를 이어 읽기. 장면 단어를 실제로 읽는지 확인한다 | **쓴다 (2부)** |
| (마) 단어 → 뜻 | 단어 하나 | 한국어 뜻 4개 | 어휘 기억 | **뺀다** |

뺀 이유:

- **(나)**: 비슷한 모양을 가려내는 능력은 (가)의 오답에 헷갈리는 쌍을 넣어서(4.2) 확인하고, 모양을 떠올리는 능력은 (다)가 더 엄격하게 확인한다. (나)를 넣으면 같은 글자를 인식으로 두 번 묻게 되어 세션이 약 30~45초 길어진다(글자당 5초 × 6~9자). 그 시간은 (라) 단어 문항에 쓴다.
- **(마)**: 이 앱이 1차로 가르치는 것은 가나 읽기다. 뜻은 단어 읽기에서 자기 확인으로 보여 줄 뿐 외우게 하지 않는다. 뜻 문항은 단어 전체 모양을 통째로 기억해도 풀려서 글자를 읽었는지 확인하지 못하고, 틀렸을 때 어느 글자를 틀렸는지 정할 수 없어 복습 대상(5.3)과 이어지지 않는다.
- 발음 듣고 고르기 등 PLAN.md 7번의 2차 기능은 넣지 않는다.

한 손 엄지 조작: (가)와 (라)는 지금의 Q1처럼 아래쪽 2×2 보기와 아래 주 버튼으로 답한다. (다)는 지금의 Q2 캔버스 그대로다. 새 조작은 없다. (라)의 보기는 로마자 단어라 칸 안에 들어갈 길이를 designer가 확인한다. 이 규칙에서 나오는 가장 긴 보기는 11자다(おもてなし omotenashi 10자에서 2자 로마자를 3자 로마자로 바꾼 오답).

## 3. 문항 구성

### 3.1 부 순서와 문항 수

| 부 | 유형 | 문항 | 수 |
|---|---|---|---|
| 1부 | (가) 글자 → 발음 | Q의 글자마다 하나 | n + r |
| 2부 | (라) 단어 → 읽기 | 3.4의 단어마다 하나 | 장면 1: 3, 장면 2~4: 3, 장면 5~8: 4 |
| 3부 | (다) 기억으로 쓰기 | Q의 글자마다 하나 | n + r |

- 순서 근거: 글자 하나 인식(쉬움) → 여러 글자를 이어 읽는 인식 → 모양을 기억에서 꺼내 쓰는 회상(어려움). 1부에서 글자를 한 번씩 떠올린 뒤 2부에서 단어로 묶고, 3부에서 쓴다.
- 장면의 새 글자는 1부와 3부에 반드시 한 번씩 나온다. 그래서 "장면의 글자 5~6자를 모두 한 번 이상 낸다"는 2부의 단어 고르기와 무관하게 지켜진다.
- 부 안에서 다시 내는 문항은 수에 넣지 않는다(5.1).

장면별 문항 수:

| 장면 | n | 단어 문항 | 문항 수 (r = 0) | 문항 수 (r = 3) |
|---|---|---|---|---|
| 1 스시집 | 6 | 3 | 15 | (복습 없음) |
| 2 돈카츠집 | 6 | 3 | 15 | 21 |
| 3 소바·우동집 | 6 | 3 | 15 | 21 |
| 4 역 | 5 | 3 | 13 | 19 |
| 5 신사·축제 | 6 | 4 | 16 | 22 |
| 6 이자카야 | 6 | 4 | 16 | 22 |
| 7 온천 | 5 | 4 | 14 | 20 |
| 8 료칸 | 6 | 4 | 16 | 22 |

### 3.2 1부와 3부의 글자 순서

1부와 3부는 각각 따로 아래 순서를 만든다.

1. N을 무작위로 섞는다 → N₁ … Nₙ.
2. R을 무작위로 섞는다 → R₁ … Rᵣ.
3. i번째 복습 글자 Rᵢ를 새 글자 `floor(i × n ÷ (r + 1))`개 뒤에 끼운다.

결과:

| n | r | 끼우는 자리 (새 글자 몇 개 뒤) | 순서 |
|---|---|---|---|
| 6 | 1 | 3 | N N N R N N N |
| 6 | 2 | 2, 4 | N N R N N R N N |
| 6 | 3 | 1, 3, 4 | N R N N R N R N N |
| 5 | 1 | 2 | N N R N N N |
| 5 | 2 | 1, 3 | N R N N R N N |
| 5 | 3 | 1, 2, 3 | N R N R N R N N |

- 복습 글자는 첫 문항과 마지막 문항이 되지 않는다. 첫 문항은 방금 배운 장면의 글자로 시작하고, 복습 글자끼리 붙지 않게 퍼뜨린다.
- 1부와 3부의 순서는 서로 다르게 섞인다(각자 무작위). 같은 순서가 나와도 다시 섞지 않는다.

### 3.3 2부 단어의 자격

장면 k의 종합 퀴즈에서 단어 문항으로 쓸 수 있는 단어("자격 있는 단어")는 아래 셋을 모두 만족하는 단어다. 데이터(`hiragana_scenes.json`)의 `units`로 판정한다.

| 조건 | 판정 | 걸러지는 것 |
|---|---|---|
| E1 모든 칸이 L에 드는 기본 글자 | `units`의 모든 `kana`가 L에 있다 | 탁음·반탁음(まぐろ, そば), 작은 っ(きっぷうりば), 한자 칸(かつ丼, ぬる湯, ほうじ茶), 아직 안 배운 글자가 든 단어 |
| E2 두 칸 이상 | `units` 수 ≥ 2 | ゆ (1부의 글자 문항과 같아진다) |
| E3 칸 로마자를 이으면 읽기와 같다 | `units`의 `romaji`를 이은 값 == `reading` | 장음 표기 단어(ようこそ: youkoso ≠ yōkoso), 띄어 쓴 문구(くつをぬいでください) |

- 탁음이 든 단어는 칸에 발음을 표기해 보여 주는 방식으로도 쓰지 않는다. 히라가나 8장면은 모두 자격 있는 이 장면 단어가 2개 이상이라(3.5) 대체가 필요 없다.
- 한자가 붙은 단어는 PLAN.md 3번 "단어의 표기"(한자는 퀴즈에 내지 않음)에 따라 쓰지 않는다.
- E3은 2부의 보기를 칸 로마자로 만들기(4.3) 때문에 필요하다. 보기와 단어 읽기 화면의 읽기 표기가 서로 달라지는 단어를 거른다.
- 자격 있는 단어는 화면에서 칸 위 발음 표기가 하나도 없다.

### 3.4 2부 단어 고르기

단어는 세 칸으로 고른다. 모든 고르기는 정렬 키를 위에서부터 차례로 비교해 첫 단어를 고른다.

**(1) 이 장면 단어** — 장면 1은 3개, 장면 2~8은 2개. 후보: 이 장면 두 단계의 자격 있는 단어.

반복해서 하나씩 고른다:

1. 아직 고른 단어에 나오지 않은 N의 글자를 많이 담은 단어 먼저.
2. 데이터 순서(단계 a의 단어 → 단계 b의 단어, 단계 안에서는 데이터 순서).

이 칸은 복습 글자와 무관하게 데이터만으로 정해진다(장면마다 늘 같다).

**(2) 직전 장면 단어** — 장면 2~8에서 1개. 후보: 장면 k−1의 단어 중 장면 k의 L로 자격 있는 단어.

1. R의 글자를 많이 담은 단어 먼저.
2. N의 글자를 많이 담은 단어 먼저.
3. "새로 읽히는 단어" 먼저: 자기 장면의 L로는 자격이 없었는데 지금 L로 자격이 생긴 단어.
4. 장면 k−1의 (1)에서 고른 단어가 아닌 것 먼저.
5. 데이터 순서.

**(3) 지난 장면 단어** — 장면 5~8에서 1개. 후보: 장면 1 ~ k−2의 단어 중 장면 k의 L로 자격 있는 단어.

1. R의 글자를 많이 담은 단어 먼저.
2. N의 글자를 많이 담은 단어 먼저.
3. 새로 읽히는 단어 먼저.
4. 장면 k−4의 단어 먼저 (장면 5 → 1, 6 → 2, 7 → 3, 8 → 4. 네 장면 전 단어로 돌려 가며 되짚는다).
5. 그 단어 장면의 (1)에서 고른 단어가 아닌 것 먼저.
6. 장면 순서, 그 안에서 데이터 순서.

- 2부의 문항 순서: (1)의 고른 순서 → (2) → (3). 이 장면 단어로 시작하고 뒤로 가며 되짚는다.
- 후보가 모자라면 그 칸은 비운다(문항 수가 준다). 다른 칸에서 대신 채우지 않는다. 히라가나 8장면에서는 비는 칸이 없다(3.5).
- 가타카나 장면에도 같은 규칙을 쓰되 장면 번호는 가타카나 안에서 세고, (2)(3)의 후보는 가타카나 장면 단어만으로 한다. 가타카나 단어의 장음(ー)과 작은 ッ 처리가 정해지면(PLAN.md 8번) E1·E3을 다시 확인한다.

### 3.5 히라가나 8장면의 단어 문항 (복습 글자가 없을 때)

R이 비어 있을 때의 결과다. R이 있으면 (2)(3)이 바뀔 수 있다(예시는 8.2).

| 장면 | 자격 있는 이 장면 단어 | (1) 이 장면 | (2) 직전 장면 | (3) 지난 장면 |
|---|---|---|---|---|
| 1 | すし, いか, たこ | すし, いか, たこ | | |
| 2 | とんかつ, ひれかつ | とんかつ, ひれかつ | すし (장면 1의 셋 모두 (1)에서 썼다 → 데이터 순서) | |
| 3 | きつね, かけ, おかめ | きつね(き ね), かけ(け) | とんかつ | |
| 4 | えき, おつり, のりかえ, こちら | のりかえ(の り え), こちら(ち ら) | おかめ (장면 3의 (1)에서 안 쓴 단어) | |
| 5 | おまもり, おまいり, たこやき, おまつり, あたり | おまもり(ま も), たこやき(や) | えき | すし (장면 1 우선, 데이터 순서) |
| 6 | やきとり, つくね, かわ, むね, ささみ, なんこつ, しいたけ | つくね(く), かわ(わ) | おまいり | おかわり (わ를 담음, 새로 읽힘, 장면 2) |
| 7 | おんせん, ゆかた, ひのき | おんせん(せ), ゆかた(ゆ) | やきとり | たぬき (ぬ를 담음, 새로 읽힘) |

- 3a(うどん, そば)는 탁음 때문에 자격 있는 단어가 없지만, 장면 3 전체로는 3b의 단어 3개가 있다.
- 2부에 단어로 나오지 않는 이 장면 글자: 장면 2 お, 장면 3 そ う め, 장면 5 み あ は, 장면 6 む さ に な, 장면 7 ぬ る を(ぬ는 たぬき로 나옴), 장면 8 よ ほ へ. 이 글자들도 1부와 3부에는 반드시 나온다.

## 4. 오답 보기 규칙

### 4.1 헷갈리는 글자 쌍

두 글자를 모두 배운 뒤(L에 둘 다 있을 때)에만 쓴다. 쌍은 양방향이다(ね의 짝은 れ, れ의 짝은 ね).

| 번호 | 쌍 | 늦게 배우는 글자의 단계 | 쓸 수 있게 되는 장면 | 근거 |
|---|---|---|---|---|
| 1 | い – こ | 1b | 1 | [지식] 90도 돌린 모양 |
| 2 | し – つ | 2a | 2 | [지식] 획 방향만 다름 |
| 3 | ね – れ | 3b | 3 | PM 지정(わ/ね의 같은 무리), [지식] |
| 4 | い – り | 4a | 4 | [지식] |
| 5 | ち – ら | 4b | 4 | [지식] 아래 둥근 부분이 같은 모양. 1획만 다름(ち 긴 가로획, ら 짧은 점) |
| 6 | け – は | 5b | 5 | [지식] |
| 7 | あ – お | 5b | 5 | [지식] |
| 8 | ま – も | 5a | 5 | [지식] |
| 9 | ね – わ | 6a | 6 | PM 지정, [지식] |
| 10 | れ – わ | 6a | 6 | [지식] |
| 11 | す – む | 6a | 6 | [지식] 고리가 있는 세로획 |
| 12 | さ – き | 6b | 6 | PM 지정, [지식] |
| 13 | さ – ち | 6b | 6 | [지식] 좌우 대칭에 가까움 |
| 14 | た – な | 6b | 6 | [지식] |
| 15 | ぬ – め | 7b | 7 | PM 지정. 여행 채팅에서 학습자가 직접 언급 (`travel-chat-analysis.md` 63행) |
| 16 | は – ほ | 8a | 8 | PM 지정, [지식] |
| 17 | ま – ほ | 8a | 8 | [지식] |
| 18 | る – ろ | 8b | 8 | [지식] 고리 유무 |
| 19 | く – へ | 8b | 8 | [지식] 90도 돌린 모양 |

- 장면별로 쓸 수 있는 쌍의 수(누적): 1, 2, 3, 5, 8, 14, 15, 19.
- [지식] 쌍은 학습자 오답 자료로 확인하지 않은 작성자 판단이다. 오답 고르기의 우선순위에만 쓰므로 틀려도 문항이 잘못되지는 않는다. 조사 결과가 나오면 이 표만 고친다(10.3).
- 이 표는 데이터로 둔다(파일 이름과 형식은 developer가 정한다). 가타카나 쌍(ソ/ン, シ/ツ 등)은 가타카나 배정 때 따로 만든다.
- 혼동 쌍만 모아 연습하는 모드는 2차 기능(PLAN.md 7번)이고, 여기서는 오답 보기의 우선순위로만 쓴다.

### 4.2 1부 (가)의 오답

글자 c의 문항. 보기 = c의 로마자 + 오답 3개. 오답 후보는 L에서 c를 뺀 글자이고, 아래 등급 순서로 채운다. 같은 등급 안에서는 무작위.

1. c의 헷갈리는 짝 (4.1, L에 있는 것 전부).
2. Q의 다른 글자 (이 장면의 새 글자 + 복습 글자).
3. L의 나머지 글자.

- 로마자가 같은 보기가 두 번 나오지 않게 한다. お(o)와 を(wo)는 서로의 오답으로 쓰지 않는다(지금 쓰는 소리가 같다).
- 칸 위치는 문항마다 섞는다.
- 지금 Q1의 10.1(이 단계 → 이 장면 다른 단계 → 앞 장면 → 다음 장면)을 대신한다. 퀴즈가 장면 끝으로 옮겨져 장면 1도 L이 6자라 아직 안 배운 글자를 오답으로 쓸 일이 없다. 다음 장면 글자를 쓰는 4번째 단계는 없앤다.
- 장면 1의 L은 6자, 오답 후보 5자라 늘 채워진다. L이 4자 미만이면(히라가나에는 없음) 오류로 본다.

### 4.3 2부 (라)의 오답

단어 w의 칸이 u₁ … uₘ, 칸 로마자가 r₁ … rₘ일 때 정답은 r₁ … rₘ을 이은 값(E3에 따라 `reading`과 같다). 오답은 **칸 하나만 다른 글자로 바꾼 로마자**로 만든다. 그래서 오답을 고르면 어느 글자를 잘못 읽었는지 정확히 정해진다(5.3).

바꿀 칸의 순서:

1. 헷갈리는 짝이 L에 있는 글자의 칸.
2. Q에 드는 글자의 칸.
3. 나머지 칸.

같은 등급 안에서는 왼쪽부터. 이 순서로 칸을 늘어놓고 오답 3개를 돌아가며 배정한다(칸이 2개면 첫째, 둘째, 첫째 칸).

바꿔 넣을 글자 s(칸 uₚ의 글자가 k일 때):

1. k의 헷갈리는 짝 (L에 있는 것).
2. Q의 글자.
3. L의 나머지 글자.

같은 등급 안에서는 무작위. 같은 칸에 두 번째 오답을 만들 때는 앞에서 쓴 글자를 빼고 다시 고른다.

제약:

- s는 L의 기본 글자이고 k와 로마자가 다르다. お ↔ を는 바꾸지 않는다.
- s로 ん을 쓰지 않는다. 앞 칸이 ん이면 s로 あ い う え お や ゆ よ를 쓰지 않는다(n + 모음은 읽기가 두 가지가 된다).
- 만든 로마자가 정답이나 이미 만든 오답과 같으면 버리고 같은 등급에서 다시 고른다. 등급이 다 떨어지면 다음 등급으로.
- 오답이 실제 일본어 단어여도 상관없다(いか → shika, たこ → tai).

2부 정답을 맞힌 뒤 단어의 뜻을 함께 보여 줄지는 designer가 정한다. 데이터에 뜻이 있다.

## 5. 통과, 다시 내기, 틀린 글자, 복습

### 5.1 다시 내기와 통과

- 부마다 따로: 틀린 문항은 그 부의 남은 문항이 끝난 뒤 틀린 순서대로 다시 낸다. 다시 낸 문항을 또 틀리면 줄 끝에 다시 붙는다. 그 부의 모든 문항을 맞혀야 다음 부로 넘어간다(지금 Q1, Q2와 같다).
- (가), (라)의 다시 내기는 같은 보기 4개를 칸 위치만 다시 섞는다.
- (다)는 가이드를 본 글자를 3부 끝에 다시 내고, 가이드 없이 완성할 때까지 반복한다. 가이드가 켜지는 조건은 PLAN.md 3번 그대로("가이드 보기"를 누르거나 한 글자에서 획을 3번 틀림). 가이드 없이 완성했으면 도중에 획을 1~2번 틀렸어도 맞힌 것으로 본다.
- **통과 = 세 부를 모두 끝냄.** 첫 시도 정답률 기준은 두지 않는다. 틀린 글자는 복습 대기 목록(5.4)으로 다음 장면에서 다시 확인한다. 통과하면 장면 완료.

### 5.2 저장과 이어 하기

- 문항 목록(순서, 보기, 각 오답이 바꾼 칸)은 세션을 처음 시작할 때 한 번 만들어 저장한다. 이어서 할 때 다시 만들지 않는다.
- 항목 단위 저장은 지금 규칙(scene-flow.md 2.5)과 같다. 항목은 1부 한 문항, 2부 한 문항, 3부 한 글자.
- 끝낸 종합 퀴즈를 다시 하면: R은 비우고(복습 글자 없음), 2부는 같은 규칙으로 R 없이 고른다. 진행, 틀린 글자 기록, 복습 대기 목록을 바꾸지 않는다(끝낸 단계 다시 하기와 같은 규칙).

### 5.3 틀린 글자의 정의

종합 퀴즈에서 다음 중 하나라도 해당하는 글자를 그 장면의 "틀린 글자"로 기록한다. 다시 낸 문항에서 틀린 것도 포함한다.

| 부 | 틀린 글자로 기록하는 것 |
|---|---|
| 1부 (가) | 오답을 고른 문항의 글자 (문제로 보여 준 글자. 고른 오답의 글자는 기록하지 않는다) |
| 2부 (라) | 고른 오답이 바꾼 칸의 **원래 글자**. 예: いか에서 koka(い → こ)를 고르면 い |
| 3부 (다) | 가이드를 본 글자 |

- 2부에서 기록되는 글자는 이 장면 글자가 아닐 수도 있다(직전·지난 장면 단어의 글자). 그래도 기록하고 복습 대기 목록에 넣는다.
- 장면별 틀린 글자 목록은 장면 id → 글자 집합으로 저장한다(지금 `장면별 틀린 글자`와 같은 자리. 단계 세션에는 퀴즈가 없으므로 이 목록은 종합 퀴즈만 채운다). 이 목록을 어느 화면에 어떻게 보여 줄지는 designer가 정한다.

### 5.4 복습 대기 목록과 복습 글자 고르기

PLAN.md 3번 "복습: 다음 장면 퀴즈에 이전에 틀린 글자를 자동으로 섞음"을 장면 끝 퀴즈 구조에 맞춰 구체화한 것이다.

- **복습 대기 목록**: 글자 → 들어온 장면 번호. 히라가나와 가타카나는 따로 둔다.
- 장면 k의 종합 퀴즈를 **통과할 때** 한 번에 고친다(도중에 나가면 고치지 않고, 틀린 글자 기록만 항목 단위로 저장해 둔다):
  1. 이번 R의 글자 가운데 이번 퀴즈에서 틀린 글자로 기록되지 않은 것은 목록에서 뺀다.
  2. 이번 퀴즈의 틀린 글자(5.3)는 모두 목록에 넣고, 들어온 장면 번호를 k로 바꾼다(이미 있던 글자도).
- 장면 k의 R 고르기: 목록에서 들어온 장면 번호가 k보다 작은 글자를 아래 순서로 정렬해 앞에서 최대 3자(임시값, PLAN.md 8번).
  1. 들어온 장면 번호가 작은 것(오래 기다린 것) 먼저.
  2. 배우는 순서(hiragana-allocation.md 3.1의 1a → 8b, 단계 안 배우기 순서)가 빠른 것 먼저.
- 3자를 넘어 못 고른 글자는 목록에 남아 다음 장면에서 다시 후보가 된다. 지금 PLAN.md 문구의 "다음 장면"이 "다시 맞힐 때까지 다음 장면들"로 넓어진다(10번).
- 2부 단어에 우연히 나온 대기 글자를 맞혀도 목록에서 빼지 않는다. 목록에서 빠지는 길은 R로 뽑혀 1부·2부·3부에서 한 번도 틀리지 않는 것 하나뿐이다.
- 장면 8을 끝낸 뒤 남은 히라가나 대기 글자는 가타카나 장면에 섞지 않는다. 처리는 6.2의 제안.
- 지금 설계의 "복습 글자는 다음 장면 단계 a 퀴즈에만"(hiragana-allocation.md 7.1의 2)은 단계 퀴즈가 없어져 "다음 장면 종합 퀴즈"로 바뀐다.

## 6. 난이도 장치

### 6.1 장면이 뒤로 갈수록 바뀌는 것

| 장치 | 장면 1 | 장면 2~4 | 장면 5~8 |
|---|---|---|---|
| 지난 장면 단어 (2부) | 0개 | 1개 (직전 장면) | 2개 (직전 장면 + 네 장면 전) |
| 복습 글자 (1부·3부) | 없음 | 최대 3자 | 최대 3자 |
| 쓸 수 있는 헷갈리는 쌍 (누적) | 1 | 2 → 5 | 8 → 19 |
| 오답 후보가 되는 글자 L | 6자 | 12 → 23자 | 29 → 46자 |
| 새로 읽히는 옛 단어 | | | おかわり, たぬき, おろし 같은 단어가 (3)에 나옴 |

- 사용자 피드백("너무 쉽다")의 원인은 배운 직후 2~4자만 묻는 것이었다고 본다. 이 구조에서는 (1) 단계 a 글자를 단계 b를 지난 뒤에 묻고, (2) 장면의 5~6자를 한 번에 섞어 묻고, (3) 단어 단위로 읽게 하고, (4) 뒤 장면일수록 헷갈리는 짝과 옛 단어가 섞인다.
- 장면 2~4와 5~8의 경계(지난 장면 단어 1개 → 2개)는 장면 5부터 쓸 수 있는 헷갈리는 쌍이 크게 늘고(5 → 8 → 14) 옛 단어 가운데 새로 읽히는 단어가 생기기 시작하는 시점에 맞췄다.

### 6.2 히라가나 총정리 (제안, 확정 아님)

필요하다고 본다. 이유: 장면 8에서 틀린 글자와 대기 목록에 남은 글자는 다음 히라가나 장면이 없어 다시 나올 자리가 없다. 가타카나 장면에 섞으면 두 글자 체계가 한 퀴즈에 섞여 3번 "문자 순서"의 취지와 어긋난다.

제안 내용:

- 장면 8을 끝내면 홈의 히라가나 끝에 "히라가나 총정리" 행이 열린다. 하지 않아도 가타카나 첫 장면은 열린다(진도를 막지 않는다).
- 구성: 1부 (가) 10문항 = 대기 목록의 글자 전부(상한 없음) + 모자라면 헷갈리는 쌍의 글자. 2부 (라) 4문항 = 장면 1~8의 자격 있는 단어 가운데 종합 퀴즈에 한 번도 안 나온 단어(いくら, いなり, わかめ, しいたけ, ささみ, なんこつ, むね, ふとん, おへや 등). 3부 (다) = 대기 목록의 글자 + 모자라면 1부에서 틀린 글자, 최대 6자. 약 2.5~3분.
- 통과하면 대기 목록을 비운다. 다시 할 수 있다.
- 리워드(장면 8 완료 때 600엔 추가)와 겹치는지, 총정리에도 엔을 주는지는 리워드 조정 항목과 함께 정한다.

PM이 PLAN.md 8번에 "히라가나 총정리 세션을 둘지"로 올리기를 권한다.

## 7. 세션 길이 추정

측정값이 아니라 추정이다. 식은 flow-restructure-proposal.md 1.2를 나눠 썼다: (가) 문항당 5초, (다) 글자당 10초(앞의 "퀴즈 글자당 15초" = 사지선다 5 + 쓰기 10), (라) 단어당 8초(단어 읽기 단어당 8초와 같게 봄), 부 안내 화면 5초. 완료 화면은 넣지 않았다. "두 번 틀림"은 (가) 다시 내기 5초 + (다) 가이드를 보고 다시 쓰기 15초를 더한 값이다.

| 장면 | n | 단어 | r = 0 | r = 3 | r = 3 + 두 번 틀림 |
|---|---|---|---|---|---|
| 1 | 6 | 3 | 2.0분 (119초) | (복습 없음) | 2.3분 (r = 0 + 두 번 틀림) |
| 2, 3 | 6 | 3 | 2.0분 | 2.7분 (164초) | 3.1분 |
| 4 | 5 | 3 | 1.7분 | 2.5분 | 2.8분 |
| 5, 6, 8 | 6 | 4 | 2.1분 | 2.9분 (172초) | 3.2분 (192초) |
| 7 | 5 | 4 | 1.9분 | 2.6분 | 3.0분 |

- 복습 글자가 3자이고 몇 문항을 틀리면 3분을 조금 넘는다(장면 2, 3, 5, 6, 8에서 최대 약 3.2분, 네 번 틀리면 약 3.5분). 복습 글자가 많은 사용자일수록 퀴즈가 길어지는 구조다.
- 이 문서는 이 길이를 받아들인다. 장면의 유일한 확인 세션이고, 넘는 경우는 복습이 가장 필요한 경우다.
- 줄여야 한다면 쓸 대안(이 문서에서는 쓰지 않음):
  - (A) 복습 글자를 3부(쓰기)에만 넣고 1부에서 뺀다: 15초 줄어든다. 복습 글자의 인식 확인은 2부 단어(5.4의 R 우선)로 일부 대신한다.
  - (B) 장면 5~8의 단어 문항을 3개로 둔다(지난 장면 단어를 뺀다): 8초 줄어든다. 누적 복습 장치 하나가 빠진다.
  - (C) 복습 글자 상한을 2자로: 15초 줄어든다. PLAN.md 8번의 미정 항목에서 정한다.
- 단계 세션은 퀴즈가 빠져 0.9~2.3분이 된다(9.2). 단계 세션이 2분 아래로 내려가는 경우가 많아 "한 세션 2~3분"의 아래쪽도 맞지 않는다. PLAN.md 3번 "사용 장면" 문구 제안은 10.1.

## 8. 문항 예시

무작위가 들어가는 자리(섞는 순서, 같은 등급 안의 오답)는 한 가지 결과를 적었다. 각 오답 옆에 어느 등급에서 왔는지 적었으니 developer는 값이 아니라 등급과 칸이 규칙대로인지 검증한다. 보기는 정답을 맨 앞에 적었지만 화면에서는 칸 위치를 섞는다.

등급 표시: 짝 = 헷갈리는 짝(4.1), Q = 이 퀴즈의 글자, L = L의 나머지.

### 8.1 장면 1 스시집 (복습 없음)

- L = N = Q = す し い か た こ (6자). 쓸 수 있는 헷갈리는 쌍: い – こ 하나.
- 2부 단어: (1) すし, いか, たこ. 각 단어가 새 글자 2자씩을 담아 첫째 키가 같고 데이터 순서로 정해진다.

| 1 | 1부 | か | ka | ta (Q), shi (Q), ko (Q) | か |
| 2 | 1부 | す | su | shi (Q), i (Q), ka (Q) | す |
| 3 | 1부 | こ | ko | i (짝), ta (Q), su (Q) | こ |
| 4 | 1부 | い | i | ko (짝), shi (Q), ka (Q) | い |
| 5 | 1부 | し | shi | su (Q), ta (Q), i (Q) | し |
| 6 | 1부 | た | ta | ka (Q), ko (Q), su (Q) | た |
| 7 | 2부 | すし | sushi | tashi (1칸 す→た, Q), suko (2칸 し→こ, Q), kashi (1칸 す→か, Q) | 고른 오답의 바꾼 칸: す 또는 し |
| 8 | 2부 | いか | ika | koka (1칸 い→こ, 짝), ita (2칸 か→た, Q), shika (1칸 い→し, Q) | い 또는 か |
| 9 | 2부 | たこ | tako | tai (2칸 こ→い, 짝), suko (1칸 た→す, Q), taka (2칸 こ→か, Q) | こ 또는 た |

바꿀 칸 순서 확인:

- すし: 짝이 L에 있는 칸 없음(す – む, し – つ는 아직). 두 칸 모두 Q → 왼쪽부터 1, 2, 1.
- いか: い는 짝 こ가 L에 있음 → 1칸 먼저. か는 Q → 2칸. 순서 1, 2, 1.
- たこ: こ는 짝 い가 L에 있음 → 2칸 먼저. た는 Q → 1칸. 순서 2, 1, 2.

틀린 경우를 넣은 진행 예 (developer 검증용):

- 3번 こ에서 i를 고름 → こ 기록. 1부 끝(6번 뒤)에 3번을 다시 냄(3'). 3'을 맞힘 → 2부로.
- 8번 いか에서 koka를 고름 → い 기록(1칸의 원래 글자). 2부 끝(9번 뒤)에 8'. 맞힘 → 3부로.
- 12번 す에서 "가이드 보기"를 누름 → す 기록. 3부 끝(15번 뒤)에 12'. 가이드 없이 완성 → 통과.
- 실제 순서: 1 2 3 4 5 6 3' 7 8 9 8' 10 11 12 13 14 15 12'. 처음 문항 수 15, 다시 낸 문항 3.
- 통과할 때 장면 1 틀린 글자 = {こ, い, す}. 복습 대기 목록 = {す: 1, い: 1, こ: 1}.
- 장면 2의 R: 셋 다 장면 1에서 들어옴 → 배우는 순서 す(1a), い(1b), こ(1b) → R = す い こ.

### 8.2 장면 3 소바·우동집 (복습 3자)

앞 진행 가정: 장면 2 종합 퀴즈에서 R = す い こ를 모두 맞혀 목록에서 빠졌다. 장면 2 퀴즈의 2부 (2) 단어는 すし(R의 す를 담은 단어가 すし, いか, たこ로 하나씩 같아 데이터 순서)였고, 여기서 sutsu(2칸 し→つ)를 골라 し가 기록됐다. 1부·3부에서 お, ひ, れ를 틀렸다.

- 장면 3 시작 때 복습 대기 목록 = {し: 2, お: 2, ひ: 2, れ: 2}. 모두 장면 2에서 들어옴 → 배우는 순서 し(1a), お(2b), ひ(2b), れ(2b) → **R = し お ひ**, れ는 남아 장면 4의 후보가 된다.
- L (18자) = す し い か た こ と ん つ お ひ れ そ う き ね け め.
- N = そ う き ね け め, Q = N + し お ひ (9자).
- 쓸 수 있는 헷갈리는 쌍: い – こ, し – つ, ね – れ.
- 1부 순서: N 섞기 ね き め そ け う, R 섞기 し お ひ → 새 글자 1, 3, 4개 뒤에 끼움 → ね [し] き め [お] そ [ひ] け う.
- 3부 순서: N 섞기 け そ ね う め き, R 섞기 ひ し お → け [ひ] そ ね [し] う [お] め き.
- 2부 단어: (1) きつね(き ね 2자) → かけ(け 1자, おかめ와 같은데 데이터 순서). (2) 장면 2 후보 とんかつ, ひれかつ 가운데 R의 ひ를 담은 ひれかつ.

|---|---|---|---|---|---|

| 2 | 1부 | し (복습) | shi | tsu (짝), so (Q), ke (Q) | し |
| 3 | 1부 | き | ki | hi (Q), ke (Q), so (Q) | き |
| 4 | 1부 | め | me | ne (Q), o (Q), u (Q) | め |
| 5 | 1부 | お (복습) | o | u (Q), so (Q), ke (Q) | お |
| 6 | 1부 | そ | so | me (Q), ki (Q), shi (Q) | そ |
| 7 | 1부 | ひ (복습) | hi | ki (Q), ne (Q), u (Q) | ひ |
| 8 | 1부 | け | ke | so (Q), me (Q), o (Q) | け |

| 12 | 2부 | ひれかつ | hirekatsu | hinekatsu (2칸 れ→ね, 짝), hirekashi (4칸 つ→し, 짝), kirekatsu (1칸 ひ→き, Q) | れ, つ, ひ 중 바꾼 칸 |

바꿀 칸 순서 확인:

- きつね: 짝이 L에 있는 칸 = つ(2칸, 짝 し), ね(3칸, 짝 れ). き(1칸)는 짝 さ가 아직 없고 Q에 듦. 순서 2, 3, 1.
- かけ: 짝이 있는 칸 없음(け – は는 아직). Q에 드는 칸 = け(2칸). か(1칸)는 나머지. 순서 2, 1, 2.
- ひれかつ: 짝이 있는 칸 = れ(2칸, 짝 ね), つ(4칸, 짝 し). Q에 드는 칸 = ひ(1칸, 복습). か(3칸)는 나머지. 오답이 3개라 순서 2, 4, 1에서 끝나고 3칸은 바꾸지 않는다.
- 1부 4번 め: 짝 ぬ가 아직 없어 모두 Q 등급.

틀린 경우를 넣은 진행 예:

- 1번 ね에서 re를 고름 → ね 기록. 1부 끝(9번 뒤)에 1'.
- 10번 きつね에서 kishine를 고름 → **つ** 기록(2칸의 원래 글자. 장면 2 글자지만 기록한다). 2부 끝(12번 뒤)에 10'.
- 19번 お에서 획을 3번 틀려 가이드가 켜짐 → お 기록. 3부 끝(21번 뒤)에 19'.
- 실제 순서: 1~9, 1', 10~12, 10', 13~21, 19'. 처음 문항 수 21, 다시 낸 문항 3.
- 통과할 때 장면 3 틀린 글자 = {ね, つ, お}.
- 복습 대기 목록 고치기: R 가운데 안 틀린 し, ひ는 뺀다. お는 틀렸으므로 남고 들어온 장면이 3으로 바뀐다. ね, つ를 장면 3으로 넣는다. れ(장면 2)는 그대로. → {れ: 2, つ: 3, お: 3, ね: 3}.
- 장면 4의 R: れ(장면 2) 먼저, 그다음 장면 3의 셋을 배우는 순서 つ(2a), お(2b), ね(3b)로 → R = れ つ お. ね는 남는다.
- 장면 4의 2부 (2)는 장면 3 후보 きつね, かけ, おかめ에서 R(れ つ お)을 많이 담은 단어: きつね(つ 1), おかめ(お 1)가 같고, N(え り の ち ら)은 둘 다 0, 새로 읽힘 아님, 장면 3 (1)에서 안 쓴 단어 → おかめ.

### 9.1 퀴즈가 빠진 단계 세션이 얕아지는가

| 확인 대상 | 이전 단계 세션 | 지금 단계 세션 | 판단 |
|---|---|---|---|
| 모양 보기 | L1 | L1 그대로 | 같음 |
| 손으로 익히기 | 따라 쓰기 2번 | 그대로 (PLAN.md 3번) | 같음 |

판단: 단계 세션의 배우기 자체는 얕아지지 않는다. 다만 단계 a의 글자를 단계 b에서 한 번 다시 꺼내 볼 자리가 없어, 아래 보완 하나를 넣는다.

### 9.2 보완: 단계 b 단어 읽기의 "앞 단계 다시 읽기" (확정)

- 단계 b의 단어 읽기 맨 앞에 단계 a의 단어 하나를 넣는다. 고르는 단어는 **단계 a 단어의 데이터 순서 첫 단어**다(데이터 순서는 전부 읽히는 단어가 앞이다).
- 발음 표기 규칙은 단계 b 시점 기준(scene-flow.md 12번)을 그대로 쓴다.
- 이 단어는 단계 b의 단어 목록에 넣지 않는다(데이터는 바꾸지 않는다). 화면에서 "앞 단계 단어"임을 어떻게 알릴지, 단계 완료 화면의 "단어 N개" 셈에 넣을지는 designer가 정한다.

| 장면 | 단계 b 맨 앞에 넣는 단어 | 발음 표기 |
|---|---|---|
| 1 | すし | 없음 |
| 2 | とんかつ | 없음 |
| 3 | うどん | ど |
| 4 | えき | 없음 |

| 8 | ようこそ | 없음 (장음 안내는 단어의 보조 설명) |

단계 세션 길이 추정(배우기 글자당 20초, 단어당 8초, 안내 화면 5초, 단계 b는 다시 읽기 단어 1개 포함):

| 6 | 1.6분 | 1.9분 |

장면 하나의 합계는 복습 글자가 없을 때 약 4.7~5.6분, 복습 3자일 때 최대 약 6.5분(장면 5: 1.6 + 2.0 + 2.9)이다. 장면 1은 0.9 + 2.3 + 2.0 = 5.2분으로, 이전 구조(1.3 + 3.1 = 4.4분)보다 약 0.8분 길다.

## 11. 구현 체크리스트 (developer)

1. L, N, R, Q를 1번 정의대로 계산한다. R은 5.4로 고른다. 다시 하기면 R은 빈 집합.
2. 1부·3부 순서는 3.2의 끼우기 식으로 만든다. 복습 글자가 첫·마지막 문항이 아닌지 확인한다.
3. 2부 단어는 3.3 자격 → 3.4 정렬 키로 고른다. R이 비었을 때 결과가 3.5 표와 같은지 테스트한다.
4. (가) 오답은 4.2 등급, (라) 오답은 4.3의 칸 순서와 바꿔 넣을 글자 등급으로 만든다. 각 오답에 "바꾼 칸 번호"를 저장한다.
5. 문항 목록은 처음 시작할 때 만들어 저장하고 이어 하기 때 그대로 쓴다.
6. 다시 내기는 부 단위(5.1). 다시 낸 (가)·(라)는 같은 보기, 칸 위치만 다시 섞기.
7. 틀린 글자는 5.3대로 항목마다 저장하고, 통과할 때 5.4대로 복습 대기 목록을 고친다.
8. 무작위 자리는 시드를 줄 수 있게 만들어 8번 예시의 등급과 칸 순서를 테스트로 확인한다.
