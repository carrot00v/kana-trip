## 2. 모든 화면에 공통인 규칙

### 2.1 화면을 띄우는 방식

- 홈, 장면 진입, 기리 꾸미기는 `NavigationStack` 안에 둔다. 장면 진입에서 왼쪽 가장자리 스와이프로 홈에 돌아갈 수 있다.
- 세션 화면(L1, L2, P2, Q1, Q2, P3, W, C1, C2)은 단계 하나에 `fullScreenCover` 하나로 띄운다. 쓰기 캔버스가 화면 왼쪽 가장자리에서 16pt 떨어져 있어, 내비게이션 스택에 넣으면 획을 긋다가 뒤로 가기 스와이프가 걸린다. 전체 화면 덮개에는 가장자리 스와이프가 없다.
- 덮개 안에서는 화면을 밀지 않고 내용만 바꾼다. 구간이 바뀔 때(배우기 → P2 → 퀴즈 → P3 → 단어 읽기 → 완료)도, C1에서 다음 단계로 넘어갈 때도 같다. 전환은 0.2초 페이드. "동작 줄이기"가 켜져 있으면 전환 없이 바로 바꾼다.

### 2.2 세션 화면의 공통 뼈대

위에서 아래 순서.

| 영역 | 높이 | 내용 |
|---|---|---|
| 상단 바 | 44pt | 왼쪽: 닫기 버튼(`xmark`, 44×44pt). 가운데: 3칸 진행 막대. 오른쪽: 지금 구간 이름. 자세한 것은 7.2 |
| 내용 영역 | 남는 높이 | 화면마다 다름. 보기만 하는 정보는 위, 누르거나 쓰는 대상은 아래 |
| 아래 버튼 영역 | 56pt + 위 12pt + 아래 8pt | 주 버튼 하나. 보조 버튼이 있으면 주 버튼 왼쪽에 둔다 |

- 닫기 버튼은 엄지가 닿기 어려운 왼쪽 위에 둔다. 자주 쓰는 조작이 아니고, 아래에 두면 쓰다가 잘못 누르기 쉽다.
- 아래 버튼 영역은 모든 세션 화면에서 같은 자리에 둔다. 주 버튼의 위치가 화면마다 바뀌지 않아야 보지 않고 누를 수 있다.
- C1, C2에는 상단 바가 없다(13, 14번).

### 2.3 발음 표기

발음은 로마자(`romaji`)를 쓴다: す su, し shi, い i, か ka, た ta, こ ko.

### 2.4 발음 소리

- 기본값은 꺼짐. 홈 오른쪽 위 메뉴(`ellipsis.circle`)의 "발음 소리" 토글로 켠다.
- 켜져 있을 때만 소리를 낼 수 있는 글자 옆에 `speaker.wave.2.fill` 아이콘(15pt, `InkSecondary`)을 붙인다. 꺼져 있으면 아이콘이 없고 글자를 눌러도 아무 일도 없다.
- 소리가 답을 알려 주는 자리에서는 답하기 전에 재생하지 않는다. 화면별로 적었다.

### 2.5 도중에 나갔을 때

닫기 버튼을 누르거나, 앱이 백그라운드로 가거나, 종료된 경우 모두 같은 규칙이다.

- 진행은 **단계마다** 항목 단위로 저장한다. 항목은 배우기의 글자 하나(소개 + 따라 쓰기 2번), 사지선다 한 문항, 기억으로 쓰기 한 글자, 단어 하나다.
- 끝낸 항목은 남고, 하던 항목은 처음으로 돌아간다. 예: か의 따라 쓰기 2번째를 쓰다가 나가면, 다시 들어왔을 때 か의 L1부터 시작한다.
- 닫기 버튼은 확인 창 없이 바로 닫는다. 닫으면 장면 진입(S)으로 간다.
- 다시 들어가는 자리는 S의 해당 단계 행과 홈의 아래 주 버튼이다. 둘 다 "이어서 하기"로 바뀐다.
- 다시 들어갔을 때의 첫 화면:

| 나간 자리 | 다시 들어가면 |
|---|---|
| 배우기 도중 | 끝내지 않은 첫 글자의 L1 |
| 배우기를 다 끝내고 P2에서 | P2 |
| 퀴즈 도중 (한 문항이라도 답함) | 남은 문항부터. 사지선다가 남았으면 Q1, 다 맞혔으면 Q2. P2는 다시 보여 주지 않는다 |
| 퀴즈를 다 끝내고 P3에서 | P3 |
| 단어 읽기 도중 | 끝내지 않은 첫 단어의 읽기 전 상태 |
| C1, C2 | 이미 완료 상태다. 다시 보여 주지 않고 S(또는 홈)에 결과가 반영돼 있다 |

- 퀴즈에서 이미 틀린 글자 기록과 다시 낼 문항 목록도 함께 저장한다.
- 끝낸 단계를 다시 하는 중에는 진행을 저장하지 않는다(17번 결정 6). 닫으면 다시 할 때 처음부터 시작한다. 완료 상태와 틀린 글자 기록은 바뀌지 않는다.

## 4. 장면, 단계, 구간

### 4.1 낱말

| 낱말 | 뜻 | 화면에 쓰는 이름 |
|---|---|---|
| 장면 | 스테이지 하나. 단계 2개. 새 글자 5~6자 | 데이터의 장면 이름 (스시집) |
| 단계 | 장면 안의 동선 한 칸. 새 글자 2~4자와 단어. 단계 하나 = 세션 하나 | 데이터의 단계 이름 (간판, 메뉴) |
| 구간 | 세션 안의 배우기, 퀴즈, 단어 읽기 | 배우기 / 퀴즈 / 단어 읽기 |

화면 문구에는 "세션", "단계", "구간"이라는 말을 쓰지 않는다. 단계는 이름("간판", "메뉴")으로, 구간은 구간 이름으로 부른다(visual-rules.md 6.3). VoiceOver 레이블은 예외로 "1단계"를 쓴다.

### 4.2 데이터에 필요한 것

장면 데이터에 단계 층을 둔다(flow-restructure-proposal.md 5번). 이름과 형식은 개발 담당이 정한다. 화면이 필요로 하는 값만 적었다.

| 항목 | 예 (1b) | 쓰는 화면 |
|---|---|---|
| 단계 id | `sushi-b` (17번 결정 11) | 저장, 보상 지급 키 |
| 단계 순서 | 2 | H, S, 잠금 |
| 단계 이름 | 메뉴 | H 주 버튼, S, C1, L1 단어 카드 |
| 새 글자 (배우는 순서) | い か た こ | 전부 |
| 단어 (데이터 순서) | いか, たこ, いくら, まぐろ, えび, いなり | S, L1, W, C1, C2 |

장면의 `kana`는 단계 글자를 순서대로 이은 것과 같다(す し い か た こ). 장면에 따로 두지 않고 단계에서 계산해도 된다.

### 4.3 열리는 순서

- 장면 1의 단계 a는 처음부터 열려 있다.
- 단계 b는 같은 장면의 단계 a를 끝내면 열린다.
- 다음 장면의 단계 a는 이 장면의 단계 b를 끝내면 열린다. 장면 완료 = 단계 2개를 모두 끝냄.
- 단계 안의 구간은 배우기 → 퀴즈 → 단어 읽기 순서로만 진행한다. 구간을 골라 들어가는 길은 없다.
- 끝낸 단계는 다시 할 수 있다. 다시 하면 배우기의 첫 글자부터 시작한다.

### 4.4 배운 글자와 읽히는 단어의 계산

새로 저장하는 값은 없다. 데이터와 4.3의 진행 상태에서 계산한다.

| 이름 | 계산 | 1b의 값 |
|---|---|---|
| 이 단계까지의 글자 | 앞 장면들의 새 글자 전부 + 이 장면의 앞 단계 글자 + 이 단계 글자 | す し い か た こ |
| 배운 글자 | 앞 장면들의 새 글자 전부 + 이 장면에서 배우기를 끝낸 단계의 글자 전부 + 배우기 도중인 단계의 끝낸 글자(`learnDone`) | 진행에 따라 す し ~ す し い か た こ |
| 단계의 목표 단어 | 이 단계 단어 가운데 가나 칸(`kanaUnits`)이 모두 "이 단계까지의 글자"에 드는 단어. 데이터 순서 | いか, たこ |
| 단계의 못 읽는 단어 | 이 단계의 나머지 단어. 데이터 순서 | いくら, まぐろ, えび, いなり |
| 장면의 목표 단어 | 두 단계의 목표 단어를 단계 순서대로 이은 것 | すし, いか, たこ |

- 글자 하나를 "배웠다"고 보는 시점은 배우기에서 그 글자의 2번째 따라 쓰기를 완성하고 "다음"을 누른 때다.
- 배우기 구간을 끝낸 단계(완료한 단계 포함)는 글자 전부를 배운 것으로 본다. 끝낸 단계를 다시 하는 동안에도 단어가 도로 흐려지지 않는다.
- 탁음·반탁음 글자(ぐ, び)와 가르치지 않는 한자(丼 등)는 언제나 배운 글자가 아니다.
- 목표 단어 여부를 데이터에 적지 않는다. 위 계산으로 정해진다.

## 5. H 홈(장면 목록)

목적: 지금 어디까지 했는지 보여 주고, 다음 단계를 한 번 눌러 시작하게 한다.

구성 요소(위에서 아래):

1. 내비게이션 바. 큰 제목 "니혼go". 오른쪽 위에 `ellipsis.circle` 메뉴(기본 `Menu`). 항목은 "발음 소리" 토글.
2. 기리 행. 보상 브랜치의 reward-flow.md 4번 그대로. 이 개정에서 바꾸지 않는다.
3. 섹션 머리글 "히라가나". 밥집 3장면을 묶는 제목은 두지 않는다(17번 결정 1).
4. 장면 행 8개. `List`의 `insetGrouped`. 행 높이 76pt 이상.
   - 왼쪽: 장면 그림 52×52pt와 상태 배지. 규격과 상태는 scene-art/brief.md 2번. 그림이 없으면 대체 그림, 그것도 없으면 SF Symbol 상태 아이콘(28pt 폭).
   - 그림 오른쪽 12pt. 윗줄: 순서 번호와 장면 이름("1  스시집", `.headline`). 아랫줄: 새 글자를 단계별로 나눠 놓는다. 글자는 20pt, 글자 사이 한 칸, 단계 사이에 가운뎃점 "·"(`InkSecondary`, 좌우 8pt). 예: "す し · い か た こ".
   - 오른쪽: 끝낸 단계 수("0/2", "1/2", `monospacedDigit`)와 `chevron.right`. 잠긴 장면에는 둘 다 없다. 끝낸 장면에는 숫자 대신 "완료".
5. 아래 고정 주 버튼. `safeAreaInset(edge: .bottom)`, 좌우 여백 16pt. 문구는 "{장면} · {단계} {시작|이어서 하기}".

폭 확인(375pt): 행 내용 폭 311pt − 그림 52 − 간격 12 = 247pt. 오른쪽 "1/2 ›"(약 50pt)를 빼면 글자 줄에 약 197pt. 가장 긴 줄은 6자 + 가운뎃점("ま み も · あ や は"): 글자 6 × 20 + 글자 사이 4칸 × 5 + 가운뎃점 묶음 약 22 = 약 162pt로 들어간다. 장면 이름 중 가장 긴 "3  소바·우동집"도 `.headline`으로 약 110pt.

주 버튼 폭: 가장 긴 문구 "소바·우동집 · 메뉴 이어서 하기"와 "역 · 개찰구·승강장 이어서 하기"가 17pt 굵게 약 250pt로 343pt 안에 들어간다. 단계 이름이 길어 넘치면 한 줄을 유지하고 글자를 0.85까지 줄인다(`minimumScaleFactor(0.85)`).

상태(장면 1 행과 주 버튼):

| 상태 | 장면 1 행 오른쪽 | 아래 주 버튼 문구 |
|---|---|---|
| 처음 | 0/2 | 스시집 · 간판 시작 |
| 간판 도중에 나감 | 0/2 | 스시집 · 간판 이어서 하기 |
| 간판 끝 | 1/2 | 스시집 · 메뉴 시작 |
| 메뉴 도중에 나감 | 1/2 | 스시집 · 메뉴 이어서 하기 |
| 장면 1 완료 | 완료 (체크 배지) | 돈카츠집 · 간판 시작 (장면 2 행이 열림으로 바뀜) |

장면 2의 내용이 아직 없는 빌드: 장면 2 행은 열림으로 표시하되 누르면 "준비 중이에요" 알림만 띄우고 아래 주 버튼은 숨긴다(개발 중 임시 규칙, 전과 같음).

잠긴 행: 이름과 글자를 `InkSecondary`로 낮추고 그림을 흑백으로, 자물쇠 배지를 붙인다. 눌러도 반응하지 않는다(`disabled`). 새 글자는 잠겨 있어도 보여 준다.

VoiceOver: 행 하나를 하나의 요소로 읽는다. "1번 스시집, 간판 す し, 메뉴 い か た こ, 단계 2개 중 1개 완료" / "2번 돈카츠집, 잠김". 그림과 배지는 읽지 않는다.

전환:

- 열린 장면 행 또는 끝낸 장면 행 탭 → S 장면 진입(push).
- 아래 주 버튼 탭 → 문구에 적힌 단계의 세션(fullScreenCover). 세션을 닫으면 그 장면의 S가 아래에 깔려 있도록, 덮개를 띄우기 전에 S를 먼저 push한다.

## 6. S 장면 진입

목적: 이 장면의 단계 두 개와 각 단계에서 읽게 될 단어를 보여 주고, 다음 단계를 시작하게 한다.

```

┌──────────────────────────────────────┐
│ ‹ 니혼go                             │  내비게이션 바(뒤로)
│ 스시집                               │  큰 제목
│ ┌──────────────────────────────────┐ │
│ │ ✓  간판                    완료 ›│ │  단계 행 (1a, 완료)
│ │    す し                         │ │
│ ├──────────────────────────────────┤ │
│ │ すし                        초밥 │ │  목표 단어
│ │                 ✓ 읽을 수 있어요 │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ ②  메뉴                        › │ │  단계 행 (1b, 할 차례)
│ │    い か た こ                   │ │
│ ├──────────────────────────────────┤ │
│ │ いか                      오징어 │ │  목표 단어
│ │                  배운 글자 0 / 2 │ │
│ ├──────────────────────────────────┤ │
│ │ たこ                        문어 │ │
│ │                  배운 글자 0 / 2 │ │
│ ├──────────────────────────────────┤ │
│ │ 아직 못 읽는 글자가 있는 단어    │ │  못 읽는 단어 줄
│ │ いくら  まぐろ  えび  いなり     │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │            메뉴 시작             │ │  아래 고정 주 버튼
│ └──────────────────────────────────┘ │
```

구성 요소(위에서 아래):

1. 내비게이션 바. 뒤로 버튼(기본), 큰 제목은 장면 이름.
2. 단계 섹션 2개. `List`의 `insetGrouped` 섹션 하나가 단계 하나다. 섹션 머리글은 없다. 섹션 안의 행 순서: 단계 행 → 목표 단어 행(단어마다) → 못 읽는 단어 줄.
3. 아래 고정 주 버튼. 다음에 할 단계를 시작한다.

섹션 사이 간격 16pt(`listSectionSpacing(16)`). `List`의 맨 위 여백 8pt.

### 6.1 단계 행

| 요소 | 값 |
|---|---|
| 높이 | 72pt (행 내용 최소 높이 50pt) |
| 왼쪽 | 상태 아이콘, 28pt 폭 (6.2 표) |
| 가운데 (아이콘 오른쪽 12pt) | 윗줄: 단계 이름(`.headline`, `Ink`). 4pt 아래 아랫줄: 단계의 새 글자(20pt, 글자 사이 한 칸, 일본어 로캘). 글자는 배웠는지와 상관없이 `Ink`. 잠긴 단계만 `InkSecondary` |
| 오른쪽 | 상태 글자(`.subheadline`, `InkSecondary`)와 `chevron.right`. 6.2 표 |
| 누르기 | 행 전체. 잠긴 단계는 `disabled` |

이전 설계의 "새 글자 줄"(글자 34pt + 로마자, 눌러서 발음 듣기)은 단계 행의 아랫줄로 합쳤다. 로마자와 발음 소리는 L1에서 본다(17번 결정 7).

### 6.2 단계 행의 상태

| 상태 | 아이콘 | 오른쪽 | 탭 |
|---|---|---|---|
| 할 차례 | 번호 원(`1.circle.fill`, `2.circle.fill`, `AccentColor`) | `chevron.right`만 | 세션 시작 |
| 하던 중 | 번호 원(`AccentColor`) | "이어서" + `chevron.right` | 2.5의 자리에서 이어서 |
| 완료 | `checkmark.circle.fill`(`Correct`) | "완료" + `chevron.right` | 처음부터 다시 (진행 저장 안 함) |
| 잠김 | `lock.fill`(`InkSecondary`) | 없음 | 반응 없음 |

- 색 밖의 구분: 아이콘 모양(번호, 체크, 자물쇠)과 오른쪽 글자.
- VoiceOver: "1단계 간판, 새 글자 す し, 완료, 다시 하기" / "2단계 메뉴, 새 글자 い か た こ, 할 차례" / "2단계 메뉴, 잠김, 간판을 끝내면 열려요".

### 6.3 목표 단어 행과 못 읽는 단어 줄

배치는 전과 같다.

| 요소 | 높이 | 내용 |
|---|---|---|
| 목표 단어 행 | 52pt (위아래 안쪽 여백 6 + 내용 40) | 왼쪽: 단어(시스템 글꼴 28pt, 일본어 로캘, 글자 사이 2pt, 글자마다 6.4의 모양). 오른쪽(오른쪽 정렬, 두 줄): 뜻(15pt, `InkSecondary`), 상태(13pt). 단어와 오른쪽 묶음 사이 최소 12pt |
| 못 읽는 단어 줄 | 60pt (위아래 안쪽 여백 8 + 내용 44) | 윗줄 "아직 못 읽는 글자가 있는 단어"(13pt, `InkSecondary`). 4pt 아래 단어들을 한 줄로(17pt, 일본어 로캘, 단어 사이 16pt, 글자마다 6.4의 모양). 뜻과 발음 표기는 싣지 않는다 |

- 목표 단어 행의 상태 줄: 배운 글자 수가 전체보다 적으면 "배운 글자 1 / 2"(`InkSecondary`, `monospacedDigit`). 모두 배웠으면 `checkmark`(13pt, `Correct`) + "읽을 수 있어요"(`Ink`).
- 배운 글자 수는 가나 칸 가운데 "배운 글자"(4.4)에 드는 칸의 수. 같은 글자가 두 번 나오면 두 번 센다. 한자 칸은 세지 않는다.
- 잠긴 단계의 단어도 그린다. 앞으로 무엇을 읽게 되는지가 이 화면의 내용이다(PLAN.md 3번 "장면 연결").
- 단어 행과 줄은 누를 수 없다. 발음 소리가 켜져 있어도 재생하지 않는다.
- 못 읽는 단어가 0개인 단계(1a 간판, 6a 등)는 줄을 그리지 않는다. 목표 단어가 0개인 단계는 지금 데이터에 없다(flow-restructure-proposal.md 4.2, 모든 단계에 1개 이상).
- 폭(375pt): 행 내용 폭 311pt. 가장 넓은 목표 단어는 4자(28×4 + 2×3 = 118pt) + 12 + "읽을 수 있어요"(약 105pt) = 235pt. 가장 긴 못 읽는 단어 줄은 1b "いくら まぐろ えび いなり"(11자 × 17 + 16 × 3 = 235pt)와 5b "やきそば はずれ りんごあめ"(12자 × 17 + 16 × 2 = 236pt). 모두 들어간다. 넘치는 데이터가 생기면 줄을 바꾼다(줄당 +22pt).
- VoiceOver: 목표 단어 행은 "いか, 오징어, 글자 2개 중 1개 배움" 또는 "いか, 오징어, 읽을 수 있어요". 못 읽는 단어 줄은 "아직 못 읽는 글자가 있는 단어, いくら, まぐろ, えび, いなり".

### 6.4 단어 속 글자의 모양

| 글자 상태 | 조건 | 모양 |
|---|---|---|
| 배운 글자 | 4.4의 "배운 글자"에 든다 | `Ink`, 굵게 |
| 안 배운 글자 | 그 밖 (탁음, 한자 포함) | `InkSecondary`, 보통 굵기 |

스시집에서 나올 수 있는 모양(굵게 = 배운 글자, ✓ = 읽을 수 있어요):

| 진행 | すし | いか | たこ | 못 읽는 단어 줄 |
|---|---|---|---|---|
| 처음 | すし 0 / 2 | いか 0 / 2 | たこ 0 / 2 | いくら まぐろ えび いなり |
| 간판에서 す | **す**し 1 / 2 | 0 / 2 | 0 / 2 | 그대로 |
| 간판 끝 | **すし** ✓ | 0 / 2 | 0 / 2 | 그대로 |
| 메뉴에서 い | **すし** ✓ | **い**か 1 / 2 | 0 / 2 | **い**くら まぐろ えび **い**なり |
| 메뉴에서 い か | **すし** ✓ | **いか** ✓ | 0 / 2 | **い**くら まぐろ えび **い**なり |
| 메뉴에서 い か た | **すし** ✓ | **いか** ✓ | **た**こ 1 / 2 | 그대로 |
| 메뉴 배우기 끝 이후 | **すし** ✓ | **いか** ✓ | **たこ** ✓ | **い**くら まぐろ えび **い**なり |

메뉴의 배우기 순서 い → か가 いか의 글자 순서와 같고, た → こ가 たこ의 순서와 같아서 두 번째·네 번째 글자에서 단어가 하나씩 완성된다.

- 상태가 바뀌는 애니메이션은 없다. 세션을 닫고 돌아왔을 때 바뀐 모양이 그대로 보인다.
- 색만으로 구분하지 않기: 글자는 굵기도 다르고, 행마다 상태 줄의 숫자나 문구가 함께 바뀐다.

### 6.5 아래 주 버튼

| 상태 | 문구 |
|---|---|
| 다음 단계가 할 차례 | {단계} 시작 (예: 메뉴 시작) |
| 다음 단계를 하던 중 | {단계} 이어서 하기 |
| 장면 완료 | 장면 목록으로 (누르면 홈으로 pop) |

### 6.6 세로 계산과 스크롤

이 화면은 `List`라서 스크롤된다. 아래 주 버튼은 `safeAreaInset`으로 고정이다.

375×667pt, 스시집:

| 영역 | 높이(pt) |
|---|---|
| 상태 바 20 + 내비게이션 바 44 + 큰 제목 52 | 116 |
| 목록 맨 위 여백 | 8 |
| 1a 섹션 (단계 행 72 + 단어 52) | 124 |
| 섹션 간격 | 16 |
| 1b 섹션 (단계 행 72 + 단어 52 × 2 + 못 읽는 단어 줄 60) | 236 |
| 아래 주 버튼(8 + 56 + 8) | 72 |
| 합계 | 572 (화면 667, 95 남음) |

- 스시집은 375×667pt에서 스크롤 없이 들어간다(전의 밥집 간판 780pt에서 줄었다).
- 가장 긴 장면은 이자카야다(6a 목표 단어 4개, 못 읽는 단어 없음 = 280pt / 6b 목표 단어 3개 + 못 읽는 단어 줄 = 288pt). 375×667pt에서 합계 780pt로 113pt를 스크롤한다. 402×874pt에서는 62 + 96 + 8 + 584 + 72 + 34 = 856pt로 들어간다.
- 화면이 처음 나타날 때 "할 차례" 또는 "하던 중"인 단계의 단계 행이 보이는 영역 밖이면, 그 행이 목록 맨 위에 오도록 스크롤한다(`ScrollViewReader`, 애니메이션 없이). 다음 단계는 항상 아래 주 버튼으로도 시작할 수 있다.
- 섹션 간격, 큰 제목 영역은 `List`의 기본 배치를 가정한 값이다. 기기에서 확인한다.

### 6.7 전환

- 단계 행 또는 주 버튼 탭 → 그 단계의 세션(fullScreenCover).
- 뒤로 버튼 또는 가장자리 스와이프 → 홈.
- 세션에서 닫고 나오면 이 화면으로 온다. 끝낸 글자와 단계가 반영돼 있다.

## 7. 세션 하나의 흐름

### 7.1 순서와 항목 수

| 구간 | 화면 | 항목 수 | 1a 간판 | 1b 메뉴 |
|---|---|---|---|---|
| 배우기 | L1 → L2 ×2, 글자마다 | 새 글자 수 n | 2 | 4 |
| (안내) | P2 | 항목 아님 | | |
| 퀴즈 | Q1 n문항 (+ 복습 r) → Q2 n자 (+ 복습 r) | 2(n + r) | 4 | 8 |
| (안내) | P3 | 항목 아님 | | |
| 단어 읽기 | W | 단계의 단어 수 | 1 | 6 |
| 완료 | C1 또는 C2 | | | |

- 복습 r: 장면 2부터, 그 장면의 **단계 a 퀴즈에만** 앞 장면에서 틀린 글자를 최대 3자 섞는다(PLAN.md 3번 "복습", 개수는 PLAN.md 8번 미정, 임시 3). 단계 b에는 섞지 않는다. 장면 1에는 없다.
- 세션 길이 추정(flow-restructure-proposal.md 1.2의 식): 1a 약 1.3분, 1b 약 3.1분. 1b가 히라가나 단계 중 가장 길다.

### 7.2 상단 바

```
┌──────────────────────────────────────┐
│ ✕   ━━━━━━━━ ━━━━──── ────────  퀴즈 │
└──────────────────────────────────────┘
      배우기    퀴즈      단어 읽기
```

| 요소 | 값 |
|---|---|
| 닫기 | `xmark`, 44×44pt, 왼쪽 여백 4pt |
| 진행 막대 | 닫기 버튼 오른쪽 8pt부터 구간 이름 왼쪽 8pt까지. 칸 3개를 같은 폭으로, 칸 사이 4pt. 높이 4pt, 모서리 2pt. 빈 부분 `InkSecondary` 0.2, 찬 부분 `AccentColor` |
| 칸이 차는 정도 | 배우기: 끝낸 글자 수 / n. 퀴즈: 맞힌 항목 수 / 2(n + r), 다시 나오는 문항은 분모를 늘리지 않는다. 단어 읽기: 끝낸 단어 수 / 단어 수. 끝낸 구간의 칸은 꽉 찬다 |
| 구간 이름 | 오른쪽, 폭 72pt 오른쪽 정렬, 오른쪽 여백 16pt. "배우기" / "퀴즈" / "단어 읽기", `.subheadline`, `InkSecondary`. P2는 "퀴즈", P3은 "단어 읽기" |

- 375pt 폭에서 막대 폭은 375 − 4 − 44 − 8 − 8 − 72 − 16 = 223pt, 칸 하나 약 72pt.
- 칸을 같은 폭으로 둔 이유: 지금 어느 구간인지를 위치로 알리는 것이 목적이다. 항목 수 비율로 나누면 1a의 단어 읽기 칸(1항목)이 너무 좁아진다.
- 이전의 "2 / 6" 숫자는 뺐다. 구간마다 단위가 달라(글자, 문항, 단어) 한 숫자로 보이면 헷갈린다(17번 결정 3).
- VoiceOver: 막대와 이름을 하나의 요소로 "퀴즈, 8개 중 3개".

### 7.3 P2, P3 구간 안내

목적: 다음 구간에서 할 일이 바뀐다는 것(가이드가 사라짐, 이제 단어를 읽음)을 한 번 알린다. 축하하지 않는다.

```
P2 퀴즈 안내                                P3 단어 읽기 안내 (틀린 글자가 있었을 때)
┌──────────────────────────────────────┐   ┌──────────────────────────────────────┐
│ ✕   ━━━━━━━━ ──────── ────────  퀴즈 │   │ ✕   ━━━━━━━━ ━━━━━━━━ ──── 단어 읽기 │
│                                      │   │                                      │
│                                      │   │                                      │
│                퀴즈                  │   │              단어 읽기               │  제목

│                                      │   │                                      │
│        い    か    た    こ          │   │        い    か    た    こ          │  단계 글자
│                                      │   │              ・         ・           │  틀린 글자 점
```

구성 요소(위에서 아래):

1. 상단 바(7.2).
2. 제목(`.title2` 굵게, 가운데). 제목의 위쪽 끝을 내용 영역 높이의 위에서 4분의 1 지점에 둔다.
3. 8pt 아래 설명 한 줄(`.body`, `InkSecondary`, 가운데).
4. 24pt 아래 단계 글자 줄(34pt, 글자 사이 16pt, `Ink`). 4자 폭 34 × 4 + 16 × 3 = 184pt.
5. (P3에서 틀린 글자가 있을 때만) 글자 줄 아래 4pt에 틀린 글자 밑 점(지름 6pt, `HighlightStrong`), 16pt 아래 안내 한 줄(`.subheadline`, `Ink`).
6. 아래 버튼 영역: 주 버튼 하나. 보조 버튼 없음.

문구:

| 화면 | 제목 | 설명 | 주 버튼 |
|---|---|---|---|
| P2 | 퀴즈 | 방금 배운 글자를 기억으로 맞혀요 | 퀴즈 시작 |
| P2, 복습 글자가 있을 때 | 퀴즈 | 지난 장면에서 헷갈린 글자 {r}자도 함께 나와요 | 퀴즈 시작 |
| P3 | 단어 읽기 | {단계}에서 보는 단어 {N}개를 읽어요 | 단어 읽기 시작 |
| P3, 틀린 글자 있음 | 단어 읽기 | 위와 같음 + 안내 "{글자들}는 다음 장면 퀴즈에 다시 나와요" | 단어 읽기 시작 |

- P2의 복습 글자는 글자 줄에 넣지 않는다. 글자 줄은 이 단계의 새 글자만이다.
- P3의 "틀린 글자"는 이 단계의 퀴즈에서 생긴 것만이다(복습 글자를 다시 틀린 것 포함).
- 단계의 단어가 1개(1a)면 "간판에서 보는 단어 1개를 읽어요".
- 햅틱 없음. 캐릭터 없음(visual-rules.md 7.2: 캐릭터는 C1, C2에만).
- 375×667pt: 내용 영역 647 − 44 − 76 = 527pt. 위 여백 132 + 제목 28 + 8 + 22 + 24 + 34 + 4 + 6 + 16 + 20 = 294pt로 들어간다.
- 중간에 나갔을 때: 2.5 표대로 다시 P2·P3부터 보여 준다.
- 끝낸 단계를 다시 할 때도 P2, P3을 보여 준다.

## 8. L1 배우기: 글자 소개

목적: 새 글자 하나의 모양, 발음, 그 글자가 나오는 단어, 쓰기 포인트를 쓰기 전에 보여 준다. 보기만 한다.

단계의 새 글자 순서(1a: す → し, 1b: い → か → た → こ)로 글자마다 L1 → L2(따라 쓰기 2번)를 반복한다.

```
┌──────────────────────────────────────┐
│ ✕   ━━━━──── ──────── ──────  배우기 │  상단 바
│                                      │
│ 새 글자                              │
│          ┌──────────────┐            │
│          │      か      │            │  획 데이터로 그린 글자, 200×200pt
│          └──────────────┘            │
│                 ka                   │  발음
│                3획                   │
│ ┌──────────────────────────────────┐ │
│ │ 🍴 스시집 메뉴 단어              │ │  단어 카드
│ │ いか                      오징어 │ │  い 굵게, か 강조
│ │   ▔▔                             │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ 💡 1획은 가로로 긋다 아래로 꺾고 │ │  쓰기 포인트
│ │    끝을 왼쪽으로 살짝 올려요. …  │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │             써 보기              │ │  주 버튼
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(7.2).
2. 머리글 "새 글자"(`InkSecondary`).
3. 글자 표시. 200×200pt, 획 데이터(`Kana.strokes`)를 `Ink`로 그린다. 획마다 시작점 번호 원, 고리가 있는 획에는 고리 점선 원. 누르거나 쓸 수 없다. 발음 소리가 켜져 있으면 눌러서 들을 수 있다.
4. 발음(28pt). 그 아래 "{N}획"(`InkSecondary`).
5. 단어 카드(8.1, 8.2). 보여 줄 단어가 없으면 그리지 않는다.
6. 쓰기 포인트 상자. `lightbulb.fill`과 문구. 문구가 없는 글자(た 등)에는 그리지 않는다.
7. 주 버튼 "써 보기".

### 8.1 단어를 고르는 규칙

글자 하나에 단어 하나. 데이터만으로 정해지므로 처음과 다시 할 때 같은 단어가 나온다.

1. 아는 글자 = 앞 장면들의 새 글자 + 이 장면의 앞 단계 글자 + 이 단계의 새 글자 가운데 지금 글자까지(지금 글자 포함).
2. 후보 = **이 단계의 단어** 가운데 가나 칸에 지금 글자가 있는 단어. 없으면 이 장면의 다른 단계 단어에서 같은 조건으로 찾는다. 탁음 글자는 다른 글자로 본다.
3. 후보마다 점수 = 가나 칸 가운데 아는 글자에 드는 칸 수 ÷ 가나 칸 수.
4. 점수가 가장 높은 후보. 같으면 데이터에서 앞 단어.
5. 후보가 없으면 카드를 그리지 않는다.

스시집의 결과([ ]는 지금 글자, 굵게는 앞에서 배운 글자):

| 글자 | 후보와 점수 | 고른 단어 | 카드의 모양 | 뜻 |
|---|---|---|---|---|
| す | すし 1/2 | すし | [す]し | 초밥 |
| し | すし 2/2 | すし | **す**[し] | 초밥 |
| い | いか 1/2, いくら 1/3, いなり 1/3 | いか | [い]か | 오징어 |
| か | いか 2/2 | いか | **い**[か] | 오징어 |
| た | たこ 1/2 | たこ | [た]こ | 문어 |
| こ | たこ 2/2 | たこ | **た**[こ] | 문어 |

### 8.2 단어 카드의 배치

- 자리: 획 수 줄 아래 12pt, 쓰기 포인트 상자 위 8pt. 좌우 여백 16pt.
- 바탕 `CardBackground`, 모서리 12pt, `Outline` 2pt, 안쪽 여백 12pt.
- 윗줄(18pt): 장면 아이콘(13pt, `InkSecondary`) + 4pt + "{장면} {단계} 단어"(13pt, `InkSecondary`). 예: "스시집 메뉴 단어". 밥집 3장면의 아이콘은 `fork.knife`.
- 4pt 아래 아랫줄(34pt): 왼쪽 단어(28pt, 일본어 로캘, 글자 사이 2pt), 오른쪽 끝 뜻(15pt, `Ink`). 기준선을 맞춘다.
- 카드 높이 80pt.

| 글자 | 조건 | 모양 |
|---|---|---|
| 지금 글자 | 지금 배우는 글자와 같은 칸 | `AccentColor`, 굵게, `Highlight` 0.45 형광펜 바탕, 글자 아래 2pt에 밑줄(2pt) |
| 앞에서 배운 글자 | 8.1의 아는 글자이고 지금 글자가 아님 | `Ink`, 굵게 |
| 안 배운 글자 | 그 밖 | `InkSecondary`, 보통 굵기 |

- 로마자와 단어 읽기는 싣지 않는다. 카드는 누를 수 없다.
- VoiceOver: "스시집 메뉴 단어, いか의 か, 오징어".
- L2에는 카드를 넣지 않는다(캔버스 크기 우선).

## 9. L2 배우기: 따라 쓰기

목적: 가이드 획 위에 한 획씩 따라 써서 획순과 모양을 익힌다. 글자마다 2번, 두 번 모두 가이드가 보인다.

```
┌──────────────────────────────────────┐

│ │    끝을 왼쪽으로 살짝 올려요. …  │ │
│ └──────────────────────────────────┘ │
│  번호가 있는 점에서 시작해 따라 쓰세요│  판정 줄(높이 28pt)
```

구성 요소(위에서 아래):

2. 글자 정보 줄(52pt). 왼쪽 글자(34pt)와 발음, 오른쪽 "따라 쓰기 1/2"(`InkSecondary`). 발음 소리가 켜져 있으면 글자를 눌러 들을 수 있다.

5. 쓰기 캔버스. 좌우 여백 16pt, 정사각형, 아래 버튼 영역 바로 위. 남는 세로 공간은 쓰기 포인트 상자와 판정 줄 사이에 둔다. 캔버스 안의 표시는 visual-rules.md 5번.

상태:

| 상태 | 판정 줄 | 캔버스 | 버튼 | 햅틱 |
|---|---|---|---|---|
| 처음 | "번호가 있는 점에서 시작해 따라 쓰세요" (`InkSecondary`) | 가이드 획 전체, 1번 시작점, 1번 획의 고리 점선 원 | 다시 쓰기·다음 비활성 | 없음 |
| 쓰는 중 | 직전 문구 유지 | 손가락을 따라 `Ink` 0.6 선 | 변화 없음 | 없음 |
| 획 맞음 | `checkmark.circle.fill` "좋아요" | 맞은 획이 기준 획 모양의 `Ink` 선으로. 다음 획의 시작점 번호와 고리 표시 | 다시 쓰기 활성 | 가볍게 |
| 획 틀림 | `xmark.circle.fill` + 아래 문구 | 그은 선이 0.9초 `Wrong` 선으로 남았다 사라짐. 고리를 빼먹었으면 그 자리에 `Wrong` 점선 원 | 다시 쓰기 활성 | 오류 |
| 글자 완성 | `checkmark.seal.fill` "완성, 한 번에 썼어요" / "완성, 틀린 획 {N}번" | 모든 획 `Ink`. 표시 없음. 더 그어도 반응 없음 | 다음 활성 | 성공 |

획이 틀렸을 때의 문구(`StrokeVerdict`):

| 판정 | 문구 |
|---|---|
| `reversed` | 방향이 반대예요 |
| `wrongOrder` | 지금은 {N}번째 획 차례예요 |
| `tooShort` | 너무 짧아요 |
| `missingLoop` | 점선 자리에서 고리를 만들어야 해요 |
| `extraLoop` | 이 획에는 고리가 없어요 |
| `offTarget` | 위치나 모양이 달라요 |

- "다시 쓰기": 이번 회차를 첫 획부터 다시. 틀린 횟수도 0으로. 완성 뒤에도 누를 수 있다.
- 따라 쓰기에서는 틀려도 막지 않고 맞을 때까지 같은 획을 긋는다. 틀린 횟수는 "틀린 글자" 기록에 넣지 않는다.

전환:

- 1번째 완성 후 "다음" → 같은 글자의 2번째. 캔버스가 비워지고 "따라 쓰기 2/2".
- 2번째 완성 후 "다음" → 다음 글자의 L1. 배우기 칸이 한 글자만큼 찬다.
- 단계의 마지막 글자(1a는 し, 1b는 こ)의 2번째 완성 후 "다음" → P2.

중간에 나갔을 때: 이 글자는 끝내지 않은 것으로 남고, 다시 들어오면 이 글자의 L1부터.

## 10. Q1 퀴즈: 사지선다

목적: 글자를 보고 발음을 고른다.

퀴즈는 1부 사지선다(n + r문항) → 2부 기억으로 쓰기(n + r자) 순서다. 각 부 안에서 글자 순서는 섞는다.

```
┌──────────────────────────────────────┐
│ ✕   ━━━━━━━━ ━━━───── ────────  퀴즈 │  상단 바
│ 이 글자의 발음은?                    │  질문
│          ┌──────────────┐            │
│          │      た      │            │  획 데이터로 그린 글자, 160×160pt
│          └──────────────┘            │
│                                      │  판정 줄(28pt)
│ ┌───────────────┐ ┌───────────────┐  │
│ │      ka       │ │      ta       │  │  선택지 2×2, 칸 높이 72pt
│ └───────────────┘ └───────────────┘  │
│ ┌───────────────┐ ┌───────────────┐  │
│ │      i        │ │      ko       │  │
│ └───────────────┘ └───────────────┘  │
│ ┌──────────────────────────────────┐ │
│ │               다음               │ │  주 버튼(답하기 전 비활성)
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래): 상단 바, 질문 "이 글자의 발음은?", 글자 표시 160×160pt(번호·고리 표시 없음), 판정 줄 28pt, 선택지 4개(2열 2행, 칸 높이 72pt, 사이 12pt, 좌우 여백 16pt, 로마자), 주 버튼 "다음".

### 10.1 오답 선택지 고르기

단계의 글자가 2자인 단계(1a, 4a, 7a)가 있어서 같은 단계 글자만으로는 오답 3개를 채우지 못한다. 아래 순서로 채운다(17번 결정 8).

1. 이 단계의 다른 새 글자 전부(섞은 순서).
2. 모자라면 이 장면의 다른 단계 글자에서 무작위.
3. 모자라면 앞 장면의 새 글자에서 무작위.
4. 그래도 모자라면(장면 1) 다음 장면의 새 글자에서 무작위.

- 같은 로마자가 두 번 나오지 않게 한다.
- 복습 글자 문항도 같은 규칙인데, 1번의 "이 단계"를 그 글자가 원래 배정된 단계로 본다.
- 결과: 1a의 す 문항은 shi + (i, ka, ta, ko 중 2개). 1b의 문항은 i, ka, ta, ko 넷이 늘 나온다(전 설계에서 장면 글자 6자 중 넷이 나오던 것과 비슷하다).
- 네 칸의 자리는 문항마다 섞는다.

### 10.2 상태

| 상태 | 판정 줄 | 선택지 | 주 버튼 | 햅틱 |
|---|---|---|---|---|
| 처음 | 비어 있음 | 네 칸 기본 모양, 누를 수 있음 | 다음 비활성 | 없음 |
| 정답 | `checkmark.circle.fill` "맞아요" | 고른 칸 `Correct` 3pt 외곽선 + 오른쪽 위 `checkmark.circle.fill` 20pt. 나머지 0.4. 더 누를 수 없음 | 다음 활성 | 성공 |
| 오답 | `xmark.circle.fill` "정답은 ta예요" (ん이면 "정답은 n이에요") | 고른 칸 `Wrong` 3pt + `xmark.circle.fill`. 정답 칸 `Correct` 3pt + `checkmark.circle.fill`. 나머지 0.4 | 다음 활성 | 오류 |

- 발음 소리: 답하기 전에는 재생하지 않고 스피커 아이콘도 없다. 답한 뒤 나타난다.
- 틀린 문항은 1부의 남은 문항이 끝난 뒤 다시 나오고, 맞힐 때까지 반복한다. 한 번이라도 틀린 글자는 "틀린 글자"로 기록한다(장면별 기록, 다음 장면 단계 a의 퀴즈에 섞을 대상).

전환: "다음" → 다음 문항. 1부를 모두 맞힌 뒤 "다음" → Q2의 첫 글자.

중간에 나갔을 때: 답하고 "다음"을 누르기 전에 나가도 그 문항의 결과는 저장한다. 답하기 전이면 그 문항이 다시 나온다.

## 11. Q2 퀴즈: 기억으로 쓰기

목적: 발음만 보고 가이드 없이 글자를 쓴다.

```
┌──────────────────────────────────────┐
│ ✕   ━━━━━━━━ ━━━━━━── ────────  퀴즈 │  상단 바
│ 이 발음의 글자를 쓰세요              │  질문
│                 ka                   │  발음(48pt)
│     기억나는 대로 한 획씩 쓰세요     │  판정 줄(28pt)
│ ┌──────────────────────────────────┐ │
│ │       캔버스(십자 점선만)        │ │
│ └──────────────────────────────────┘ │
│ ┌───────────┐ ┌────────────────────┐ │
│ │가이드 보기│ │        다음        │ │
│ └───────────┘ └────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래): 상단 바, 질문, 발음(로마자 48pt, 발음 소리가 켜져 있으면 눌러서 들을 수 있음), 판정 줄, 캔버스(가이드 획·시작점 번호·고리 원 없음, 십자 점선만, 쓰기 포인트 상자 없음), 아래 버튼 영역(왼쪽 "가이드 보기" 112pt, 오른쪽 "다음").

상태:

| 상태 | 판정 줄 | 캔버스 | 버튼 | 햅틱 |
|---|---|---|---|---|
| 처음 | "기억나는 대로 한 획씩 쓰세요" (`InkSecondary`) | 십자 점선만 | 가이드 보기 활성, 다음 비활성 | 없음 |
| 획 맞음 | `checkmark.circle.fill` "좋아요" | 맞은 획이 `Ink` 기준 획으로 | 변화 없음 | 가볍게 |
| 획 틀림 | `xmark.circle.fill` + 9번 문구 | 0.9초 `Wrong` 선. 고리를 빼먹었으면 `Wrong` 점선 원 | 변화 없음 | 오류 |
| 가이드 켜짐 | `lightbulb.fill` "가이드를 보고 따라 쓰세요" | 따라 쓰기와 같은 가이드. 맞게 쓴 획은 그대로 | 가이드 보기 비활성 | 없음 |
| 완성(가이드 없이) | `checkmark.seal.fill` "완성, 기억으로 썼어요" | 모든 획 `Ink` | 다음 활성 | 성공 |
| 완성(가이드를 봄) | `checkmark.seal.fill` "완성, 이 글자는 뒤에 한 번 더 나와요" | 모든 획 `Ink` | 다음 활성 | 성공 |

- 가이드가 켜지는 경우: "가이드 보기"를 누를 때, 한 글자에서 획을 3번 틀렸을 때(3번째 빨간 표시가 사라진 뒤).
- 가이드를 본 글자는 틀린 것으로 보고 2부 끝에 다시 내며, 가이드 없이 완성할 때까지 반복한다. "틀린 글자"로 기록한다.
- 가이드 없이 완성했으면 도중에 획을 1~2번 틀렸어도 맞힌 것으로 본다.

전환: "다음" → 다음 글자. 2부를 모두 가이드 없이 완성한 뒤 "다음" → P3.

중간에 나갔을 때: 완성하고 "다음" 전에 나가도 결과는 저장한다. 완성 전이면 그 글자를 처음부터 다시 낸다. 이미 가이드를 봤다면 "틀린 글자" 기록은 남긴다.

## 12. W 단어 읽기

목적: 이 단계에서 실제로 보는 단어를 배운 글자로 읽어 본다. 읽고 나서 스스로 확인하고, 채점하지 않는다.

단어 순서: 이 단계의 목표 단어(데이터 순서) → 못 읽는 단어(데이터 순서). S의 그 단계 섹션과 같은 순서다.

- 1a: すし
- 1b: いか → たこ → いくら → まぐろ → えび → いなり

```
읽기 전                                     확인 후
┌──────────────────────────────────────┐   ┌──────────────────────────────────────┐
│ ✕   ━━━━━━━━ ━━━━━━━━ ━━━──── 단어 읽기│ │ ✕   ━━━━━━━━ ━━━━━━━━ ━━━──── 단어 읽기│
│ 소리 내어 읽어 보세요                │   │ 소리 내어 읽어 보세요                │
│                                      │   │                                      │
│        ma          gu    ro          │   │        ma          gu    ro          │  발음 표기(작게)
│        ま          ぐ    ろ          │   │        ま          ぐ    ろ          │  단어(크게)
│                                      │   │               maguro                 │  읽기
│                                      │   │                참치                  │  뜻
│                                      │   │                                      │  보조 설명(있는 단어만)
│ ┌──────────────────────────────────┐ │   │ ┌──────────────────────────────────┐ │
│ │            읽기 확인             │ │   │ │               다음               │ │
│ └──────────────────────────────────┘ │   │ └──────────────────────────────────┘ │
└──────────────────────────────────────┘   └──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(7.2).
2. 안내 "소리 내어 읽어 보세요".
3. 단어. 글자마다 두 칸을 쌓는다: 위 발음 표기(로마자 15pt, `InkSecondary`, 높이 20pt), 아래 글자(56pt). 글자 칸 폭 64pt, 사이 4pt. 5자까지 336pt로 375pt에 들어간다. 6자 이상은 글자 48pt·칸 52pt로 줄이고, 그래도 넘치면 두 줄. 스시집의 가장 긴 단어는 3자(いくら, まぐろ, いなり).
4. 확인 후에만 보이는 줄: 읽기(로마자 22pt), 뜻(17pt), 보조 설명(15pt, `InkSecondary`, `note`가 있는 단어만).
5. 주 버튼. 읽기 전 "읽기 확인", 확인 후 "다음", 마지막 단어의 확인 후 "완료".

발음 표기 규칙:

- "이 단계까지의 글자"(4.4)에는 붙이지 않는다. 위 칸은 비워 두되 높이는 유지한다.
- 그 밖의 글자, 탁음·반탁음 글자, 한자 칸에는 붙인다.
- 읽기 전부터 보인다.

스시집 단어별 내용:

| 단계 | 단어 | 글자 위 발음 표기 | 읽기 | 뜻 |
|---|---|---|---|---|
| 1a | すし | 없음 | sushi | 초밥 |
| 1b | いか | 없음 | ika | 오징어 |
| 1b | たこ | 없음 | tako | 문어 |
| 1b | いくら | ku · ra | ikura | 연어알 |
| 1b | まぐろ | ma · gu · ro | maguro | 참치 |
| 1b | えび | e · bi | ebi | 새우 |
| 1b | いなり | na · ri | inari | 유부초밥 |

상태:

| 상태 | 화면 | 주 버튼 | 햅틱 |
|---|---|---|---|
| 읽기 전 | 단어와 발음 표기 | 읽기 확인 | 없음 |
| 확인 후 | 읽기, 뜻, 보조 설명이 0.2초 페이드로 나타남 | 다음 (마지막 단어는 완료) | 가볍게 |

발음 소리: 켜져 있으면 글자를 누를 때 그 글자, 확인 후 읽기 줄을 누르면 단어 전체를 읽는다. 읽기 전에도 막지 않는다.

전환:

- "읽기 확인" → 확인 후 상태. "다음" → 다음 단어.
- 마지막 단어에서 "완료" → 단계 완료를 저장하고:
  - 단계 a를 처음 끝냄 → C1.
  - 단계 b를 처음 끝냄 → C2 (C1은 건너뜀, 17번 결정 5).
  - 끝낸 단계를 다시 함 → C1 (다시 한 모양).

중간에 나갔을 때: 확인 후 "다음"을 누른 단어까지 저장한다. 다시 들어오면 그다음 단어의 읽기 전 상태부터.

## 13. C1 단계 완료

목적: 단계 하나가 끝났음을 알리고, 같은 장면의 다음 단계로 바로 이어 가게 한다. 점수와 통계는 싣지 않는다.

나오는 때: 단계 a를 처음 끝냈을 때, 그리고 끝낸 단계(a, b 모두)를 다시 했을 때.

```
┌──────────────────────────────────────┐
│              ┌────────┐              │
│              │ (기리) │              │  캐릭터(웃는 표정) 120pt
│              └──────(✓)              │  체크 배지 32pt
│           스시집 간판 완료           │  제목
│   새 글자 2자를 배우고 단어 1개를 읽었어요│  요약
│                                      │
│               す    し               │  단계 글자 (틀린 글자 밑에 점)
│                                      │
│        이제 읽을 수 있는 단어        │  목표 단어 묶음
│                すし                  │
│                                      │
│  ¥ {받은 엔}엔을 받았어요 · 가진 엔 …│  받은 엔 줄 (처음 끝낸 단계만)
│ ┌──────────────────────────────────┐ │
│ │            메뉴 시작             │ │  주 버튼
│ └──────────────────────────────────┘ │
│            여기까지 하기             │  글자 버튼
└──────────────────────────────────────┘
```

구성 요소(위에서 아래). 상단 바는 없다.

1. 캐릭터(웃는 표정, 120×120pt)와 체크 배지(`checkmark.circle.fill` 32pt, `Correct`). 모양, 자리, 등장 움직임은 보상 브랜치의 visual-rules.md 7.2와 reward-flow.md 7번. 캐릭터 아래 끝을 내용 영역의 위에서 3분의 1 지점에 둔다(위 여백 = 내용 ÷ 3 − 120, 최소 24pt). 보상 브랜치가 들어오기 전 구현에서는 이 자리에 `checkmark.circle.fill` 64pt를 둔다.
2. 24pt 아래 제목(`.title2` 굵게) "{장면} {단계} 완료", 8pt 아래 요약 한 줄(`.body`, `InkSecondary`).
3. 24pt 아래 단계 글자 줄(34pt, 글자 사이 16pt). 이 단계 퀴즈에서 틀린 글자 밑에 점(지름 6pt, `HighlightStrong`, 글자 아래 4pt). 점의 뜻은 P3에서 이미 문구로 알렸다.
4. 24pt 아래 목표 단어 묶음: "이제 읽을 수 있는 단어"(15pt, `InkSecondary`) + 8pt + 단계의 목표 단어를 한 줄로(22pt, 일본어 로캘, `Ink` 굵게, 단어 사이 16pt). 누를 수 없다. 넘치면 줄을 바꾼다.
5. (처음 끝낸 단계만) 24pt 아래 받은 엔 줄. reward-flow.md 5번의 부품 그대로. 다시 한 단계에는 그리지 않는다.
6. 버튼 영역: 주 버튼 + 4pt + 글자 버튼 "여기까지 하기"(`.headline`, `AccentColor`, 높이 44pt). 다시 한 단계는 글자 버튼이 없다.

문구:

| 경우 | 제목 | 요약 | 주 버튼 | 글자 버튼 |
|---|---|---|---|---|
| 단계 a 처음 끝냄 | 스시집 간판 완료 | 새 글자 {n}자를 배우고 단어 {N}개를 읽었어요 | {다음 단계} 시작 (메뉴 시작) | 여기까지 하기 |
| 끝낸 단계를 다시 함 | 같은 형식 | 같은 형식 | 장면으로 돌아가기 | 없음 |

375×667pt 세로 계산(처음 끝낸 단계 a, 버튼 영역 12 + 56 + 4 + 44 + 8 = 124, 내용 영역 523pt):

| 영역 | 높이(pt) |
|---|---|
| 위 여백 (523 ÷ 3 − 120) | 54 |
| 캐릭터 | 120 |
| 간격 24 + 제목 28 + 간격 8 + 요약 22 | 82 |
| 간격 24 + 글자 줄 34 + 점 자리 10 | 68 |
| 간격 24 + 목표 단어 묶음(20 + 8 + 28) | 80 |
| 간격 24 + 받은 엔 줄 22 | 46 |
| 합계 | 450 (사용 가능 523) |

- 요약 "새 글자 4자를 배우고 단어 6개를 읽었어요"는 17pt로 약 290pt라 343pt 안에 한 줄로 들어간다.
- 목표 단어가 가장 많은 단계(6a 4개, やきとり つくね かわ むね = 11자 × 22 + 16 × 3 = 290pt)도 한 줄이다.

상태: 나타날 때 성공 햅틱 한 번과 캐릭터 등장 움직임(visual-rules.md 6.2). 그 밖의 상태는 없다.

전환:

- "{다음 단계} 시작" → 같은 덮개 안에서 다음 단계의 첫 글자 L1. 진행 막대가 비워지고 새로 시작한다.
- "여기까지 하기" → 덮개를 닫고 S로.
- "장면으로 돌아가기" → 덮개를 닫고 S로.

중간에 나갔을 때: 단계 완료와 보상 지급은 이 화면이 뜨기 전(W의 마지막 "완료")에 저장한다. 이 화면을 다시 보여 주지 않는다.

## 14. C2 장면 완료

목적: 장면 하나를 끝냈고 다음 장면이 열렸음을 알린다.

나오는 때: 단계 b를 처음 끝냈을 때. 이때는 C1을 보여 주지 않는다.

```
┌──────────────────────────────────────┐
│              ┌────────┐              │
│              │ (기리) │              │  캐릭터 120pt + 체크 배지
│              └──────(✓)              │
│           스시집 장면 완료           │  제목
│     히라가나 6자를 읽고 쓸 수 있어요 │  요약
│                                      │
│   이제 읽을 수 있는 스시집 단어      │  목표 단어 (장면 전체)
│          すし   いか   たこ          │
│                                      │
│  ¥ {받은 엔}엔을 받았어요 · 가진 엔 …│  리워드 묶음 (reward-flow.md 6)
│        새 아이템 2개가 열렸어요      │
│         [썸네일]     [썸네일]        │
│                                      │
│   다음 장면 '돈카츠집'이 열렸어요    │
│ ┌──────────────────────────────────┐ │
│ │           장면 목록으로          │ │  주 버튼
│ └──────────────────────────────────┘ │
│              기리 꾸미기             │  글자 버튼 (조건부)
└──────────────────────────────────────┘
```

구성 요소는 보상 브랜치의 reward-flow.md 6.2와 같고, 이 개정에서 바뀌는 값만 적는다.

| 요소 | 값 |
|---|---|
| 제목 | "{장면} 장면 완료" (스시집 장면 완료) |
| 요약 | "히라가나 {N}자를 읽고 쓸 수 있어요". N은 장면의 새 글자 수(두 단계 합, 스시집 6) |
| 목표 단어 묶음 | 머리 "이제 읽을 수 있는 {장면} 단어", 단어는 4.4의 "장면의 목표 단어"(두 단계, 단계 순서). 스시집: すし, いか, たこ (6자 × 22 + 16 × 2 = 164pt, 한 줄) |
| 받은 엔 줄 | 단계 b 지급분(과 장면 완료 지급분이 있으면 합친 값). 금액은 PLAN.md 8번 미정. 화면은 `{받은 엔}` |
| 열린 아이템 | 그 장면의 아이템. 장면별 배정은 PLAN.md 8번 미정 |
| 다음 장면 줄 | "다음 장면 '{장면}'이 열렸어요". 마지막 장면(료칸)은 줄 없음 |
| 단계 b의 글자 줄 | 넣지 않는다. 전 설계에서 C2의 배운 글자 줄을 뺀 이유(reward-flow.md 6.2의 4)와 같다. 이 단계의 틀린 글자는 P3에서 알렸다 |

- 세로 계산은 reward-flow.md 6.4 그대로다(375×667pt, 글자 버튼 있음 523/523pt). 목표 단어가 두 줄이 되는 장면(이자카야 7개 = 22자, 약 580pt)은 375×667pt에서 내용이 스크롤된다. 버튼은 고정이라 누르는 데는 지장이 없다.
- 전환: "장면 목록으로" → 덮개를 닫고 스택을 홈까지 되돌린다. "기리 꾸미기" → 덮개를 닫고 홈 위에 K(reward-flow.md 2.2).
- 중간에 나갔을 때: 단계 b 완료, 장면 완료, 다음 장면 열림, 보상 지급은 W의 마지막 "완료"에서 한 번에 저장한다. 이 화면은 다시 보여 주지 않는다.

## 16. 저장해야 하는 상태

저장 방식은 개발 담당이 정한다. 저장 형식 버전을 4로 올리고 예전 진도는 비운다(flow-restructure-proposal.md 5번).

| 항목 | 값 | 쓰는 화면 |
|---|---|---|
| 단계별 완료 여부 | 단계 id → 완료/미완료 | H, S, 잠금, C1·C2 분기 |
| 단계별 구간 진행 | 배우기에서 끝낸 글자(`learnDone`), 퀴즈 진행(사지선다·기억으로 쓰기의 남은 큐와 끝낸 목록, 손댄 적 있는지), 단어 읽기에서 끝낸 단어 | S의 "이어서", 2.5의 다시 들어갈 자리, 4.4 |
| 장면별 틀린 글자 | 장면 id → 글자 목록 (두 단계 합침) | P3, C1의 점, 다음 장면 단계 a의 퀴즈 |
| 발음 소리 | 켜짐/꺼짐, 기본 꺼짐 | H 메뉴, 글자를 누를 수 있는 모든 화면 |

- 지금 구현의 `SceneProgress`를 단계 단위로 옮긴 것이다. `completed: Set<SessionKind>`는 단계마다 "배우기·퀴즈·단어 읽기를 끝냈는지"로 쓰거나, 구간 진행에서 계산한다(배우기 = `learnDone`이 단계 글자 전부, 퀴즈 = 두 큐가 비고 끝낸 목록이 찼음).
- 다시 하는 단계의 진행은 저장하지 않는다(2.5). 메모리에만 두고, 덮개를 닫으면 버린다.
- 화면이 새로 요구하는 저장 값은 없다. P2·P3을 다시 보여 줄지는 구간 진행에서 계산한다(2.5 표).

## 17. 결정이 필요한 것

위 화면은 모두 권장안대로 그렸다. **2026-11-14 PM이 1~13번 모두 권장안대로 채택했다** (PLAN.md 9번). 12번 か 문구는 hiragana-allocation.md 10번의 2줄 문구로 정했다.

| 번호 | 정해야 하는 것 | 권장안 | 이유와 다른 선택지 |
|---|---|---|---|
| 1 | 홈에 밥집 3장면(스시집, 돈카츠집, 소바·우동집)을 묶는 제목을 둘지 | 두지 않는다. "히라가나" 섹션 하나에 8행 | 장면 이름이 이미 "~집"이고 장면 그림(음식)이 밥집임을 보여 준다. 묶음 제목은 3장면에만 생겨 나머지 5장면에 대응하는 제목이 없고, 섹션을 나누면 머리글과 간격으로 약 38pt가 늘어 375×667pt에서 보이는 장면 행이 약 4.5개에서 4개로 준다. 다른 선택지: "밥집" / "여행길" 두 섹션(가타카나가 들어오면 히라가나·가타카나 구분과 층이 겹친다) |
| 2 | 구간 사이에 안내 화면(P2, P3)을 둘지 | 퀴즈 앞과 단어 읽기 앞에 둔다. 버튼 하나, 축하 없음 | 따라 쓰기에서 기억으로 쓰기로 넘어가면 가이드가 사라지는데, 안내 없이 바로 Q1이 나오면 같은 화면이 이어지는 것처럼 보인다. 전에는 C1이 이 구분을 맡았다. 탭이 세션당 2번 는다. 다른 선택지: 안내 화면 없이 상단 바의 구간 이름만 바꾼다(탭이 줄지만 구간이 바뀐 것을 놓치기 쉽다) |
| 3 | 세션 상단 바의 진행 표시 | 같은 폭 3칸 막대 + 구간 이름. 숫자는 뺀다 | 한 세션에 단위가 다른 구간 셋이 있어 "5 / 18" 같은 숫자는 무엇을 센 것인지 알기 어렵다. 다른 선택지: 단계 전체를 막대 하나로 + "5 / 18" |
| 4 | 단계 a를 끝낸 C1의 주 버튼 | "{다음 단계} 시작"(메뉴 시작), 글자 버튼 "여기까지 하기" | 간판 → 메뉴가 같은 가게의 동선이라 이어 하기 좋고, 2~3분 단위로 끊고 싶은 사람은 아래 글자 버튼으로 멈춘다. 다른 선택지: 주 버튼을 "장면으로 돌아가기"로 두어 단계마다 멈추게 한다 |
| 5 | 단계 b를 처음 끝냈을 때 C1과 C2를 둘 다 보여 줄지 | C2만 보여 준다 | 완료 화면이 연달아 두 장이면 탭만 늘고, C2가 목표 단어와 보상을 모두 보여 준다. 단계 b의 틀린 글자는 P3에서 이미 알렸다. 다른 선택지: C1 → C2 (단계 b의 글자 줄과 받은 엔을 따로 보여 준다) |
| 6 | 끝낸 단계를 다시 할 때 진행을 저장할지 | 저장하지 않는다. 닫으면 다음에 처음부터 | 이미 끝낸 단계라 잃을 것이 적고, "이어서"와 "다시 하기"가 한 단계에 겹치지 않아 S의 상태가 4개로 끝난다. 다른 선택지: 다시 하는 중에도 저장하고 "이어서"를 보여 준다(상태가 5개가 되고 완료 표시와 함께 보여야 한다) |
| 7 | S의 새 글자 줄(글자 34pt + 로마자, 눌러서 발음 듣기)을 뺄지 | 뺀다. 단계 행 아랫줄에 글자(20pt)만 둔다 | 단계마다 글자가 나뉘어 한 줄로 모아 보여 줄 자리가 단계 행이 됐다. 줄을 빼서 스시집이 375×667pt에서 스크롤 없이 들어간다. 로마자와 발음은 세션 첫 화면(L1)에서 바로 나온다. 다른 선택지: 단계 행 아래에 글자 + 로마자 줄을 단계마다 둔다(섹션마다 64pt, 스시집이 375×667pt에서 약 33pt 넘침) |
| 8 | 사지선다 오답 선택지를 어디서 채울지 | 이 단계 → 이 장면의 다른 단계 → 앞 장면 → 다음 장면 순서(10.1) | 2자 단계(1a, 4a, 7a)는 같은 단계 글자만으로 오답 3개를 못 채운다. 1a에서는 아직 안 배운 い か た こ의 로마자가 오답으로 나온다. 고르는 것은 보이는 글자의 발음이라 안 배운 글자의 로마자가 오답이어도 풀 수 있다. 다른 선택지: 선택지를 3개로 줄인다(화면 배치가 바뀌고 단계마다 선택지 수가 달라진다) |
| 9 | 틀린 글자 안내("と, か는 다음 장면 퀴즈에 다시 나와요")를 둘 자리 | P3(퀴즈 바로 뒤) | 전에는 퀴즈의 C1이 알렸다. 퀴즈가 세션 중간이 되어 바로 뒤의 P3이 가장 가까운 자리다. C1·C2에는 글자 밑 점만 남긴다(C2는 자리가 없어 점도 없다) |
| 10 | 홈 장면 행의 둘째 줄 | 단계별 새 글자를 가운뎃점으로 나눔("す し · い か た こ"), 오른쪽은 "0/2" | 단계 이름("간판 · 메뉴")을 넣으면 글자가 빠지는데, 글자가 이 목록의 내용이다. 단계 이름은 S와 주 버튼 문구("스시집 · 메뉴 시작")에 나온다 |
| 11 | 장면 id와 단계 id | 장면 `sushi`, `tonkatsu`, `soba`, `station`, `shrine`, `izakaya`, `onsen`, `ryokan`. 단계 `{장면 id}-a`, `{장면 id}-b` | 장면 그림 파일 이름(`thumb-{장면 id}`, scene-art/brief.md 5.1)과 보상 지급 키가 이 값을 쓴다. 신사·축제는 이름이 바뀌어도 그림(도리이)이 같아 `shrine`을 유지한다. 데이터를 만드는 planner·developer와 맞춘다 |
| 12 | か의 쓰기 포인트 문구 길이 | planner가 3줄(약 55자) 안으로 줄인다 | 지금 약 68자로 4줄로 추정돼 L2에서 끝이 잘린다. 장면 1에 들어오면서 처음 화면에 나오는 문구다. た는 문구가 없어 상자가 그려지지 않는다(PLAN.md 8번의 기존 항목) |
| 13 | C1에 단계의 목표 단어 묶음을 넣을지 | 넣는다 | 단계마다 "새 글자 → 그 글자로 읽은 실제 단어"가 한 번씩 도는 것이 B의 목적이라(flow-restructure-proposal.md 1.3), 단계 끝에 읽게 된 단어를 보여 준다. 375×667pt에서 450/523pt로 들어간다 |

PLAN.md 8번의 기존 항목 가운데 이 개정으로 풀리거나 바뀌는 것:

- "작은 화면의 장면 진입 화면 … 세션 행이 1개만 온전히 보인다": 스시집은 375×667pt에서 스크롤 없이 들어간다(6.6). 이자카야는 113pt 스크롤하며, 할 차례 단계로 자동 스크롤한다.
- "단어 읽기 세션의 설명 문구 '밥집 간판에서 보는 단어 6개를 읽어요'": 세션 행이 없어져 S에서는 쓰지 않는다. P3의 "{단계}에서 보는 단어 {N}개를 읽어요"(가장 긴 "개찰구·승강장에서 보는 단어 5개를 읽어요" 약 270pt)는 P3이 화면 폭 343pt를 쓰므로 한 줄에 들어간다.
- "장면 2~8의 아이콘": 홈은 장면 그림이 대신하고, SF Symbol은 L1 단어 카드(13pt)와 큰 글자 크기의 홈에서만 쓴다. 밥집 3장면은 `fork.knife`.

### 17.1 이미 채택돼 그대로 쓰는 권장안

2026-11-12 채택된 권장안(PLAN.md 9번) 가운데 이 문서가 그대로 따르는 것: 첫 실행 안내 없음, 로마자 표기, 발음 소리 토글은 홈 메뉴, 항목 단위 저장과 확인 창 없는 닫기, 가타카나 장면은 홈에 아직 없음, 장면 2 내용이 없는 빌드의 "준비 중이에요", 끝낸 것은 다시 할 수 있음, 따라 쓰기 2번, 틀린 문항은 부 끝에 다시 내고 다 맞혀야 끝, 틀린 글자의 정의, 가이드가 켜지는 조건, 자기 확인 방식의 단어 읽기, 장음 안내는 단어별 보조 설명, L1 단어 고르기 규칙(단계 단위로 바꿈, 8.1), S와 L1에서 뜻은 보여 주고 읽기는 숨김.

바뀐 것: "세션 3개를 순서대로"는 "단계 2개를 순서대로, 단계 안의 구간은 고정 순서"(4.3)로. "375×667pt의 S 스크롤"과 "세션 행 설명 문구"는 위 목록대로 풀렸다.
