# 장면 1(밥집 간판) 화면 흐름과 와이어프레임

- 작성일: 2026-11-12
- 상태: 초안. 맨 끝 "PM 확인 필요" 절의 항목은 권장안 기준으로 그렸고 확정 전이다
- 기준 문서: `PLAN.md` 3번·4번·5번, `docs/content/hiragana-reorder-proposal.md` 5.1·7번, `KanaTrip/Writing/`의 스파이크 코드
- 함께 보는 문서: [visual-rules.md](visual-rules.md) (색, 글자 크기, 간격, 캔버스 선, 피드백, 접근성)

이 문서의 예시는 모두 장면 1의 글자(す し と ん か つ, 배우기 순서도 이 순서)와 밥집 간판 단어 6개(すし, とんかつ, かつ丼, そば, うどん, とんこつ, 데이터 순서도 이 순서로 가정)로 채웠다. 본문에서 "(권장안 N)"이라고 적은 곳은 PLAN.md에 근거가 없어 15번 절의 N번 항목으로 올린 것이다.

## 1. 전체 흐름

```
앱 실행
  └─ [H] 홈(장면 목록)
        ├─ 장면 행 탭 ──────────────► [S] 장면 진입(세션 3개)
        └─ 아래 주 버튼 ─────────────► 지금 할 세션으로 바로 진입

[S] 장면 진입
  ├─ 1 배우기 ─► [L1] 글자 소개 ─► [L2] 따라 쓰기 ×2 ─┐ (す→し→と→ん→か→つ, 글자마다 반복)
  │                    ▲───────────────────────────────┘
  │             └─ 6자 끝 ─► [C1] 세션 완료 ─► 2 퀴즈 또는 [S]
  ├─ 2 퀴즈 ──► [Q1] 사지선다 6문항 ─► [Q2] 기억으로 쓰기 6자 ─► [C1] 세션 완료 ─► 3 단어 읽기 또는 [S]
  └─ 3 단어 읽기 ─► [W] 단어 6개 ─► [C2] 장면 완료 ─► [H] 홈 (장면 2 역이 열림)
```

화면 목록:

| 기호 | 화면 | 절 |
|---|---|---|
| H | 홈(장면 목록) | 4 |
| S | 장면 진입 | 5 |
| L1 | 배우기: 글자 소개 | 6 |
| L2 | 배우기: 따라 쓰기 | 7 |
| Q1 | 퀴즈: 사지선다 | 8 |
| Q2 | 퀴즈: 기억으로 쓰기 | 9 |
| W | 단어 읽기 | 10 |
| C1 | 세션 완료 | 11 |
| C2 | 장면 완료 | 12 |

앱을 처음 켰을 때도 안내 화면 없이 홈으로 바로 간다(권장안 1).

## 2. 모든 화면에 공통인 규칙

### 2.1 화면을 띄우는 방식

- 홈과 장면 진입은 `NavigationStack` 안에 둔다. 장면 진입에서 왼쪽 가장자리 스와이프로 홈에 돌아갈 수 있다.
- 세션 화면(L1, L2, Q1, Q2, W, C1, C2)은 `fullScreenCover`로 띄운다. 쓰기 캔버스가 화면 왼쪽 가장자리에서 16pt 떨어져 있어, 내비게이션 스택에 넣으면 획을 긋다가 뒤로 가기 스와이프가 걸린다. 전체 화면 덮개에는 가장자리 스와이프가 없다.
- 세션 안에서 다음 항목으로 넘어갈 때는 화면 전체를 밀지 않고 내용만 바꾼다. 전환은 0.2초 페이드. "동작 줄이기"가 켜져 있으면 전환 없이 바로 바꾼다.

### 2.2 세션 화면의 공통 뼈대

위에서 아래 순서. 수치의 근거는 visual-rules.md 3번·4번.

| 영역 | 높이 | 내용 |
|---|---|---|
| 상단 바 | 44pt | 왼쪽: 닫기 버튼(`xmark`, 44×44pt). 가운데: 진행 막대(`ProgressView`, 높이 4pt). 오른쪽: 진행 숫자("2 / 6", 폭 56pt 오른쪽 정렬) |
| 내용 영역 | 남는 높이 | 화면마다 다름. 보기만 하는 정보는 위, 누르거나 쓰는 대상은 아래 |
| 아래 버튼 영역 | 56pt + 위 12pt + 아래 8pt | 주 버튼 하나. 보조 버튼이 있으면 주 버튼 왼쪽에 둔다 |

- 닫기 버튼은 엄지가 닿기 어려운 왼쪽 위에 둔다. 자주 쓰는 조작이 아니고, 아래에 두면 쓰다가 잘못 누르기 쉽다.
- 아래 버튼 영역은 모든 세션 화면에서 같은 자리에 둔다. 주 버튼의 위치가 화면마다 바뀌지 않아야 보지 않고 누를 수 있다.

### 2.3 발음 표기

발음은 스파이크 데이터의 로마자(`romaji`)를 그대로 쓴다: す su, し shi, と to, ん n, か ka, つ tsu (권장안 2).

### 2.4 발음 소리

- 기본값은 꺼짐. 홈 오른쪽 위 메뉴에서 켠다(4번 절, 권장안 3).
- 켜져 있을 때만 소리를 낼 수 있는 글자 옆에 `speaker.wave.2.fill` 아이콘(15pt, 보조 색)을 붙인다. 꺼져 있으면 아이콘이 없고 글자를 눌러도 아무 일도 없다.
- 소리가 답을 알려 주는 자리에서는 답하기 전에 재생하지 않는다. 화면별로 적었다.

### 2.5 중간에 나갔을 때 (권장안 4)

닫기 버튼을 누르거나, 앱이 백그라운드로 가거나, 종료된 경우 모두 같은 규칙이다.

- 진행 위치는 항목 단위로 저장한다. 항목은 배우기의 글자 하나(소개 + 따라 쓰기 2번), 사지선다 한 문항, 기억으로 쓰기 한 글자, 단어 하나다.
- 끝낸 항목은 남고, 하던 항목은 처음으로 돌아간다. 예: と의 따라 쓰기 2번째를 쓰다가 나가면, 다시 들어왔을 때 と의 글자 소개부터 시작한다.
- 저장되므로 닫기 버튼은 확인 창 없이 바로 닫는다. 닫으면 장면 진입 화면으로 간다.
- 다시 들어가는 자리는 장면 진입의 해당 세션 행과 홈의 아래 주 버튼이다. 둘 다 "이어서 하기"로 문구가 바뀐다.
- 퀴즈에서 이미 틀린 글자 기록과 다시 낼 문항 목록도 함께 저장한다.

## 3. 기준 화면 크기

- 기준: 402×874pt (iPhone 17 Pro, 빌드 대상 시뮬레이터). 안전 영역은 위 62pt, 아래 34pt.
- 가장 작은 화면: 375×667pt (iPhone SE 2·3세대, iOS 18 지원 기기). 안전 영역은 위 20pt, 아래 0pt.
- 쓰기 캔버스의 한 변은 `min(화면 폭 − 32, 내용 영역에서 남는 높이)`다. 402pt 폭에서 370pt, 375pt 폭에서 343pt. 300pt보다 작아지면 캔버스를 줄이지 않고 그 위의 쓰기 포인트 문구를 2줄로 자른다(7번 절).

375×667pt에서 따라 쓰기 화면의 세로 계산(문구 2줄 기준):

| 영역 | 높이(pt) |
|---|---|
| 상단 바 | 44 |
| 글자·발음·획 수 줄 | 52 |
| 쓰기 포인트 문구(2줄 + 안쪽 여백) | 64 |
| 판정 줄 | 28 |
| 영역 사이 간격 8pt × 4 | 32 |
| 캔버스 | 343 |
| 아래 버튼 영역(12 + 56 + 8) | 76 |
| 합계 | 639 (사용 가능 647) |

## 4. H 홈(장면 목록)

목적: 지금 어디까지 했는지 보여 주고, 다음 세션을 한 번 눌러 시작하게 한다.

```
┌──────────────────────────────────────┐
│                                  (…) │  내비게이션 바, 오른쪽 위 메뉴
│ 니혼go                               │  큰 제목
│                                      │
│ 히라가나                             │  섹션 머리글
│ ┌──────────────────────────────────┐ │
│ │ 🍴 1  밥집 간판             0/3 ›│ │  열림(시작 전)
│ │       す し と ん か つ          │ │
│ ├──────────────────────────────────┤ │
│ │ 🔒 2  역                         │ │  잠김
│ │       え き の り お             │ │
│ ├──────────────────────────────────┤ │
│ │ 🔒 3  거리                       │ │
│ │       い ち ま れ く こ          │ │
│ ├──────────────────────────────────┤ │
│ │ 🔒 4  신사                       │ │
│ │       み も む さ せ な          │ │
│ ├──────────────────────────────────┤ │
│ │ … 5 축제, 6 이자카야, 7 온천, 8 료칸│ │  스크롤
│ └──────────────────────────────────┘ │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │     밥집 간판 · 배우기 시작      │ │  아래 고정 주 버튼
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 내비게이션 바. 큰 제목 "니혼go"(PLAN.md의 작업명). 오른쪽 위에 `ellipsis.circle` 메뉴(기본 `Menu`). 항목은 "발음 소리" 토글 하나다. 켜면 체크 표시가 붙는다.
2. 섹션 머리글 "히라가나".
3. 장면 행 8개. `List`의 `insetGrouped` 모양. 행 높이 76pt 이상.
   - 왼쪽: 상태 아이콘(28pt 폭). 열린 장면은 장면 아이콘, 잠긴 장면은 `lock.fill`, 끝낸 장면은 `checkmark.circle.fill`.
   - 가운데 윗줄: 순서 번호와 장면 이름("1  밥집 간판"). 아랫줄: 새 글자("す し と ん か つ", 글자 사이 한 칸).
   - 오른쪽: 진행 숫자("0/3", "2/3")와 `chevron.right`. 잠긴 장면에는 둘 다 없다. 끝낸 장면에는 숫자 대신 "완료".
4. 아래 고정 주 버튼. `safeAreaInset(edge: .bottom)`으로 목록 위에 띄운다. 좌우 여백 16pt.

장면 아이콘(SF Symbols): 밥집 간판 `fork.knife`. 그림에서는 🍴로 그렸다. 장면 데이터의 `icon` 값을 지금의 `airplane.arrival`에서 이 값으로 바꾼다. 고른 이유: 스시·소바·우동·돈가스 가게를 한 번에 가리키는 모양이 식당 표시이고, 28pt 폭과 13pt(L1 단어 카드)에서도 알아볼 수 있다. `fork.knife`에는 채워진 모양(`.fill`)이 따로 없지만 선이 두꺼운 모양이라 그대로 쓴다. 다른 선택지: `storefront.fill`(간판·가게 쪽을 강조하지만 13pt에서 편의점·상점과 구분이 약하다). 나머지 장면의 아이콘은 그 장면을 설계할 때 정한다. 잠긴 동안에는 `lock.fill`만 보이므로 장면 1 구현에는 필요 없다.

가타카나 8장면은 이 단계의 홈에 넣지 않는다(권장안 5).

상태:

| 상태 | 장면 1 행 | 아래 주 버튼 문구 |
|---|---|---|
| 처음(아무것도 안 함) | 장면 아이콘, "0/3" | 밥집 간판 · 배우기 시작 |
| 배우기 도중에 나감 | "0/3" | 밥집 간판 · 배우기 이어서 하기 |
| 배우기 끝 | "1/3" | 밥집 간판 · 퀴즈 시작 |
| 퀴즈 도중에 나감 | "1/3" | 밥집 간판 · 퀴즈 이어서 하기 |
| 퀴즈 끝 | "2/3" | 밥집 간판 · 단어 읽기 시작 |
| 단어 읽기 도중에 나감 | "2/3" | 밥집 간판 · 단어 읽기 이어서 하기 |
| 장면 1 완료 | `checkmark.circle.fill`, "완료" | 역 · 배우기 시작 (장면 2 행이 열림 상태로 바뀜) |

장면 2의 내용이 아직 없는 빌드에서 장면 1을 끝낸 뒤의 모습은 권장안 6을 따른다.

잠긴 행: 글자와 이름을 보조 색으로 낮추고 `lock.fill`을 붙인다. 눌러도 반응하지 않는다(`disabled`). 새 글자는 잠겨 있어도 보여 준다. 앞으로 무엇을 배우는지가 목록의 내용이기 때문이다.

전환:

- 열린 장면 행 또는 끝낸 장면 행 탭 → S 장면 진입(push).
- 아래 주 버튼 탭 → 문구에 적힌 세션으로 바로 진입(fullScreenCover). 세션을 닫으면 그 장면의 S 화면이 아래에 깔려 있도록, 덮개를 띄우기 전에 S를 먼저 push한다.

## 5. S 장면 진입

목적: 이 장면의 글자를 배우면 어떤 밥집 간판 단어를 읽게 되는지 먼저 보여 주고, 새 글자와 세션 3개의 상태를 보여 주고, 다음 세션을 시작하게 한다.

아래 그림은 배우기 전 상태다. 목표 단어 카드의 다른 상태는 5.3에 있다.

```
┌──────────────────────────────────────┐
│ ‹ 니혼go                             │  내비게이션 바(뒤로)
│                                      │
│ 밥집 간판                            │  큰 제목
│                                      │
│ 글자를 배우면 읽는 밥집 간판 단어    │  목표 단어 카드의 머리글
│ ┌──────────────────────────────────┐ │
│ │ すし                        초밥 │ │  목표 단어 1 (2자 모두 흐리게)
│ │                  배운 글자 0 / 2 │ │
│ ├──────────────────────────────────┤ │
│ │ とんかつ                  돈가스 │ │  목표 단어 2 (4자 모두 흐리게)
│ │                  배운 글자 0 / 4 │ │
│ ├──────────────────────────────────┤ │
│ │ かつ丼                돈가스덮밥 │ │  목표 단어 3 (가나 2자 흐리게, 丼는 늘 흐리게)
│ │                  배운 글자 0 / 2 │ │
│ ├──────────────────────────────────┤ │
│ │ 아직 못 읽는 글자가 있는 단어    │ │  못 읽는 단어 줄(작게, 흐리게)
│ │ そば   うどん   とんこつ         │ │
│ └──────────────────────────────────┘ │
│                                      │
│ 새 글자 6자                          │
│   す   し   と   ん   か   つ       │  새 글자
│   su   shi  to   n    ka   tsu      │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ ①  배우기                      › │ │  할 차례
│ │    새 글자를 보고 따라 써요      │ │
│ ├──────────────────────────────────┤ │
│ │ 🔒 퀴즈                          │ │  잠김
│ │    배우기를 끝내면 열려요        │ │
│ ├──────────────────────────────────┤ │
│ │ 🔒 단어 읽기                     │ │  잠김
│ │    퀴즈를 끝내면 열려요          │ │
│ └──────────────────────────────────┘ │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │           배우기 시작            │ │  아래 고정 주 버튼
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 내비게이션 바. 뒤로 버튼(기본), 큰 제목 "밥집 간판".
2. 목표 단어 카드. `List`의 첫 번째 섹션이다. 자세한 배치는 5.2, 상태는 5.3.
3. 부제 "새 글자 6자"와 새 글자 줄. 글자 6개를 같은 폭으로 나눠 놓고 아래에 발음을 붙인다. 글자 34pt, 발음은 보조 색. 발음 소리가 켜져 있으면 글자를 눌러 들을 수 있다(글자 칸 하나가 누르는 영역, 높이 64pt 이상). 375pt 화면에서 칸 폭은 행 내용 폭 311pt ÷ 6 ≈ 51pt로 44pt 이상이고, 가장 긴 발음 "shi", "tsu"(15pt로 약 25pt)도 칸 안에 들어간다. 이 줄의 글자는 배웠는지와 상관없이 항상 본문 색이다. 부제와 글자 줄 사이 간격은 8pt(구현의 16pt에서 줄인다).
4. 세션 행 3개. 행 높이 72pt. 왼쪽 상태 아이콘, 가운데 이름과 한 줄 설명, 오른쪽 `chevron.right`(누를 수 있을 때만). 구현은 행 내용의 최소 높이가 56pt라 행이 약 78pt다. 최소 높이를 50pt로 낮춰 72pt에 맞춘다(5.4의 세로 계산 때문).
5. 아래 고정 주 버튼. 다음에 할 세션을 시작한다.

섹션 사이 간격은 16pt로 고정한다(`listSectionSpacing(16)`). `List`의 맨 위 여백은 8pt.

### 5.1 "배운 글자"와 단어 묶음의 기준

새로 저장하는 값은 없다. 모두 지금의 데이터와 저장 상태에서 계산한다.

| 이름 | 계산 | 장면 1의 값 |
|---|---|---|
| 이 장면까지의 글자 | 순서가 이 장면 이하인 모든 장면의 새 글자. 구현의 `ContentLibrary.learnedKana(through:)` | す し と ん か つ |
| 배운 글자 | 이전 장면들의 새 글자 전부 + 이 장면에서 배우기를 끝낸 글자. 이 장면의 배우기가 완료 상태(`completed`에 `learn`이 있음)면 이 장면의 새 글자 전부, 아니면 `learnDone`에 든 글자 | 진행에 따라 0~6자 |
| 목표 단어 | 이 장면의 단어 가운데 모든 글자(`units`의 `kana`)가 "이 장면까지의 글자"에 드는 단어. 데이터 순서를 유지한다 | すし, とんかつ, かつ |
| 못 읽는 글자가 있는 단어 | 이 장면의 나머지 단어. 데이터 순서를 유지한다 | そば, うどん, とんこつ |

- 글자 하나를 "배웠다"고 보는 시점은 배우기에서 그 글자의 2번째 따라 쓰기를 완성하고 "다음"을 누른 때다. 구현의 `markLearnDone`이 불리는 시점과 같다. 글자 소개만 보고 나간 글자는 배운 글자가 아니다.
- 배우기 완료 여부를 먼저 보는 이유: 끝낸 배우기를 다시 하면 구현이 `learnDone`을 비운다. `learnDone`만 보면 다시 하는 동안 단어가 도로 흐려진다. 한 번 배운 글자는 다시 흐려지지 않는다.
- 탁음·반탁음 글자(ば, ど)는 어느 장면의 새 글자도 아니므로 언제나 "배운 글자"가 아니다. 그래서 そば와 うどん은 따로 표시해 두지 않아도 못 읽는 글자가 있는 단어로 분류된다. とんこつ는 こ가 3번 장면(거리)의 글자라서 이 장면에서는 못 읽는 글자가 있는 단어다.
- 단어에 "목표 단어 여부" 같은 항목을 데이터에 더하지 않는다. 위 계산으로 정해진다.

글자 하나의 모양은 단어 묶음과 상관없이 같은 규칙을 쓴다(visual-rules.md 2.5).

| 글자 상태 | 조건 | 모양 |
|---|---|---|
| 배운 글자 | 글자가 "배운 글자"에 든다 | 본문 색, 굵게 |
| 안 배운 글자 | 그 밖 | 보조 색, 보통 굵기 |

### 5.2 목표 단어 카드의 배치

`List`의 `insetGrouped` 섹션 하나. 머리글 한 줄, 목표 단어 행(단어마다 하나), 못 읽는 단어 줄 하나로 이뤄진다.

| 요소 | 높이 | 내용 |
|---|---|---|
| 머리글 | 28pt | 섹션 머리글. 13pt, 보조 색, 대문자 변환 없음. 문구는 5.3 |
| 목표 단어 행 | 52pt (위아래 안쪽 여백 6pt + 내용 40pt) | 왼쪽: 단어. 시스템 글꼴 28pt, 일본어 로캘, 글자 사이 2pt, 글자마다 5.1의 모양. 오른쪽(오른쪽 정렬, 두 줄): 윗줄 뜻(15pt, 보조 색, 한 줄), 아랫줄 상태(13pt). 단어와 오른쪽 묶음 사이 최소 12pt |
| 못 읽는 단어 줄 | 60pt (위아래 안쪽 여백 8pt + 내용 44pt) | 윗줄 "아직 못 읽는 글자가 있는 단어"(13pt, 보조 색). 4pt 아래에 단어들을 한 줄로. 시스템 글꼴 17pt, 일본어 로캘, 단어 사이 16pt, 글자마다 5.1의 모양(장면 1에서는 そ, こ, 탁음 글자는 늘 보조 색, 보통 굵기이고 と, ん, つ는 배운 뒤 본문 색, 굵게. 5.3). 뜻과 발음 표기는 싣지 않는다 |

- 목표 단어 행의 상태 줄: 배운 글자 수가 전체보다 적으면 "배운 글자 2 / 4"(보조 색, 숫자는 `monospacedDigit`). 모두 배웠으면 `checkmark` 아이콘(13pt, 초록)과 "읽을 수 있어요"(본문 색).
- 배운 글자 수는 단어의 `units` 가운데 "배운 글자"에 드는 칸의 수다. 같은 글자가 두 번 나오면 두 번 센다. 장면 1의 목표 단어에는 같은 글자가 두 번 나오는 단어가 없다.
- 단어를 눌렀을 때: 아무 동작도 없다. 목표 단어 행과 못 읽는 단어 줄 모두 버튼이 아니고, 눌림 표시와 `chevron.right`가 없다. 발음 소리가 켜져 있어도 재생하지 않는다. 단어를 읽어 보는 자리는 단어 읽기 세션이고, 여기서 읽기(tonkatsu)를 들려주면 그 세션의 자기 확인이 뜻을 잃는다.
- 읽기(로마자)는 이 카드에 싣지 않는다. 뜻은 싣는다(권장안 19).
- 폭 확인(375pt): 행의 내용 폭은 375 − 16×2(목록 여백) − 16×2(행 안쪽 여백) = 311pt. 가장 넓은 조합은 단어 4자(とんかつ, 28×4 + 2×3 = 118pt) + 12pt + "읽을 수 있어요" 줄(약 105pt) = 235pt. かつ의 뜻이 데이터에서 "커틀릿 (かつ丼의 かつ)"처럼 길어져도 단어 2자(58pt) + 12pt + 뜻(15pt로 약 155pt) = 225pt다. 못 읽는 단어 줄은 9자 × 17pt + 16pt × 2 = 185pt. 모두 들어간다.
- 못 읽는 단어 줄이 없는 장면(해당 단어 0개)에서는 줄을 그리지 않는다. 목표 단어가 0개인 장면에서는 머리글과 못 읽는 단어 줄만 그린다. 현재 히라가나 8장면에는 두 경우 모두 없다.
- VoiceOver: 목표 단어 행은 하나의 요소로 "とんかつ, 돈가스, 글자 4개 중 2개 배움" 또는 "とんかつ, 돈가스, 읽을 수 있어요". 못 읽는 단어 줄은 하나의 요소로 "아직 못 읽는 글자가 있는 단어, そば, うどん, とんこつ". 가나는 일본어로 읽게 한다.

### 5.3 목표 단어 카드의 상태

머리글은 두 가지다.

| 조건 | 머리글 |
|---|---|
| 이 장면의 새 글자 중 안 배운 글자가 있다 | 글자를 배우면 읽는 밥집 간판 단어 |
| 이 장면의 새 글자를 모두 배웠다(배우기 완료) | 이제 읽을 수 있는 밥집 간판 단어 |

배우기는 す → し → と → ん → か → つ 순서로만 진행되므로 장면 1에서 나올 수 있는 모양은 아래 7가지다. 굵게 적은 글자가 "배운 글자" 모양(본문 색, 굵게)이고 나머지는 "안 배운 글자" 모양(보조 색, 보통 굵기)이다. ✓는 "읽을 수 있어요"다.

| 상태 | 배운 글자 | すし | とんかつ | かつ | 못 읽는 단어 줄 |
|---|---|---|---|---|---|
| 배우기 전 | 없음 | すし 0 / 2 | とんかつ 0 / 4 | かつ 0 / 2 | そば うどん とんこつ |
| 일부 배움 | す | **す**し 1 / 2 | とんかつ 0 / 4 | かつ 0 / 2 | そば うどん とんこつ |
| 일부 배움 | す し | **すし** ✓ | とんかつ 0 / 4 | かつ 0 / 2 | そば うどん とんこつ |
| 일부 배움 | す し と | **すし** ✓ | **と**んかつ 1 / 4 | かつ 0 / 2 | そば うどん **と**んこつ |
| 일부 배움 | す し と ん | **すし** ✓ | **とん**かつ 2 / 4 | かつ 0 / 2 | そば うど**ん** **とん**こつ |
| 일부 배움 | す し と ん か | **すし** ✓ | **とんか**つ 3 / 4 | **か**つ 1 / 2 | そば うど**ん** **とん**こつ |
| 다 배움 | す し と ん か つ | **すし** ✓ | **とんかつ** ✓ | **かつ** ✓ | そば うど**ん** **とん**こ**つ** |

```
일부 배움(す し と ん을 배운 뒤)          다 배움, 장면 완료
 글자를 배우면 읽는 밥집 간판 단어         이제 읽을 수 있는 밥집 간판 단어
┌──────────────────────────────────┐     ┌──────────────────────────────────┐
│ すし                        초밥 │     │ すし                        초밥 │
│ ▔▔▔▔            ✓ 읽을 수 있어요│     │ ▔▔▔▔            ✓ 읽을 수 있어요│
├──────────────────────────────────┤     ├──────────────────────────────────┤
│ とんかつ                  돈가스 │     │ とんかつ                  돈가스 │
│ ▔▔▔▔             배운 글자 2 / 4 │     │ ▔▔▔▔▔▔▔▔        ✓ 읽을 수 있어요│
├──────────────────────────────────┤     ├──────────────────────────────────┤
│ かつ                      커틀릿 │     │ かつ                      커틀릿 │
│                  배운 글자 0 / 2 │     │ ▔▔▔▔            ✓ 읽을 수 있어요│
├──────────────────────────────────┤     ├──────────────────────────────────┤
│ 아직 못 읽는 글자가 있는 단어    │     │ 아직 못 읽는 글자가 있는 단어    │
│ そば   うどん   とんこつ         │     │ そば   うどん   とんこつ         │
│          ▔▔   ▔▔▔▔               │     │          ▔▔   ▔▔▔▔  ▔▔           │
└──────────────────────────────────┘     └──────────────────────────────────┘
 (▔는 그림에서 굵은 글자를 가리키는 표시일 뿐이고 화면에는 그리지 않는다)
```

배우기 순서 す → し가 すし의 글자 순서와 같아서 두 번째 글자에서 첫 단어를 읽을 수 있게 되고, と → ん → か → つ가 とんかつ의 글자 순서와 같아서 마지막 글자에서 とんかつ와 かつ가 함께 완성된다.

- 장면 완료(세 세션을 모두 끝냄) 뒤의 카드는 "다 배움"과 같다. 따로 바뀌는 것이 없다.
- 끝낸 배우기를 다시 하는 동안에도 "다 배움" 모양을 유지한다(5.1).
- 못 읽는 단어 줄의 글자도 5.1의 규칙을 그대로 따르므로, 이 장면의 글자(と, ん, つ)는 배운 뒤 진해진다. 그 밖의 글자(そ, こ, う)는 뒤 장면의 글자라 이 장면 안에서는 진해지지 않는다. そば와 うどん은 탁음 글자가 있어 어느 장면에서도 전부 진해지지 않으므로, 이 줄에 "나중에 읽게 돼요" 같은 약속하는 문구는 쓰지 않는다.
- 상태가 바뀌는 것을 보여 주는 애니메이션은 없다. 세션을 닫고 이 화면에 돌아왔을 때 바뀐 모양이 그대로 보인다.
- 색만으로 구분하지 않기: 글자는 색과 함께 굵기가 다르고, 단어마다 상태 줄의 숫자 또는 문구가 함께 바뀐다.

### 5.4 375×667pt에서의 세로 계산

이 화면은 `List`라서 세로로 스크롤된다. 아래 주 버튼은 `safeAreaInset`으로 고정돼 있어 스크롤과 상관없이 항상 보인다.

| 영역 | 높이(pt) |
|---|---|
| 상태 바 | 20 |
| 내비게이션 바(44) + 큰 제목(52) | 96 |
| 목록 맨 위 여백 | 8 |
| 목표 단어 카드(머리글 28 + 행 52 × 3 + 못 읽는 단어 줄 60) | 244 |
| 섹션 간격 | 16 |
| 부제(20) + 간격(8) + 새 글자 줄(64) | 92 |
| 섹션 간격 | 16 |
| 세션 행 72 × 3 | 216 |
| 아래 주 버튼(8 + 56 + 8) | 72 |
| 합계 | 780 (화면 667) |

- 375×667pt에서는 113pt가 넘쳐서 스크롤을 허용한다(권장안 20). 목록이 보이는 아래 끝은 667 − 72 = 595pt다. 스크롤하지 않은 상태에서 목표 단어 카드(124~368pt), 새 글자 줄(384~476pt), 1번째 세션 행(492~564pt)이 온전히 보이고, 2번째 세션 행은 위쪽 31pt만 보이며, 3번째 세션 행은 가려진다. 걸친 행이 아래에 내용이 더 있음을 알려 준다.
- 할 일은 스크롤 없이 할 수 있다. 다음 세션은 항상 아래 고정 주 버튼으로 시작한다. 가려지는 2번째 행(퀴즈)이나 3번째 행(단어 읽기)이 "할 차례"일 때도 주 버튼 문구가 "퀴즈 시작", "단어 읽기 시작"이다.
- 기준 화면 402×874pt에서는 상태 바 62 + 96 + 내용 592 + 버튼 72 + 아래 안전 영역 34 = 856pt로 스크롤 없이 전부 들어간다(18pt 남음).
- 목표 단어가 4개 이상인 장면(신사 4개, 이자카야 4개, 온천 5개, 료칸 5개. hiragana-reorder-proposal.md 5번의 못 읽는 글자 수 0인 단어)에서는 카드가 52pt씩 더 길어진다. 4개면 402×874pt에서도 34pt 넘친다. 그 장면을 설계할 때 다시 본다.
- 섹션 머리글 28pt, 섹션 간격 16pt, 큰 제목 영역 96pt는 `List`의 기본 배치를 가정한 값이다. 기기에서 확인이 필요하다(visual-rules.md 9번).

### 5.5 세션 행, 주 버튼, 전환

세션은 1 → 2 → 3 순서로 열린다(권장안 7). 끝낸 세션은 다시 할 수 있다(권장안 8).

세션 행의 상태:

| 상태 | 아이콘 | 설명 줄 문구 | 탭 |
|---|---|---|---|
| 할 차례 | 번호 원(`1.circle.fill` 등, 강조색) | 배우기: "새 글자를 보고 따라 써요" / 퀴즈: "발음을 고르고 기억으로 써요" / 단어 읽기: "밥집 간판에서 보는 단어 6개를 읽어요" | 세션 시작 |
| 하던 중 | 번호 원(강조색) | "이어서 하기 · 3 / 6" (끝낸 항목 수 / 전체) | 이어서 시작 |
| 잠김 | `lock.fill`(보조 색) | 퀴즈: "배우기를 끝내면 열려요" / 단어 읽기: "퀴즈를 끝내면 열려요" | 반응 없음 |
| 완료 | `checkmark.circle.fill`(초록) | "완료 · 다시 하기" | 처음부터 다시 시작 |

설명 줄 폭(375pt): 행 내용 폭 311pt에서 아이콘 칸(28 + 간격 12)과 `chevron.right` 칸(약 20)을 빼면 약 251pt다. "밥집 간판에서 보는 단어 6개를 읽어요"는 15pt로 약 254pt라 한 줄에 들어가지 않을 수 있다. 이 문구를 어떻게 할지는 15번 권장안 21에 올렸고, 배치는 아직 바꾸지 않았다.

아래 주 버튼 문구: "배우기 시작", "배우기 이어서 하기", "퀴즈 시작", "퀴즈 이어서 하기", "단어 읽기 시작", "단어 읽기 이어서 하기". 세 세션을 모두 끝낸 뒤에는 "장면 목록으로"가 되고 누르면 홈으로 돌아간다.

전환:

- 세션 행 또는 주 버튼 탭 → 해당 세션(fullScreenCover).
- 뒤로 버튼 또는 가장자리 스와이프 → 홈.

중간에 나갔을 때: 이 화면에는 저장할 진행이 없다. 세션에서 닫고 나오면 이 화면으로 온다. 배우기 도중에 닫았으면 그때까지 끝낸 글자가 목표 단어 카드에 반영돼 있다.

## 6. L1 배우기: 글자 소개

목적: 새 글자 하나의 모양, 발음, 그 글자가 나오는 밥집 간판 단어, 쓰기 포인트를 쓰기 전에 보여 준다. 이 화면에서는 보기만 한다.

배우기 세션은 す → し → と → ん → か → つ 순서(PLAN.md 4번의 표기 순서)로, 글자마다 L1 → L2(따라 쓰기 2번)를 반복한다. 진행 숫자는 글자 기준이다("1 / 6").

```
┌──────────────────────────────────────┐
│ ✕   ━━──────────────────────  1 / 6 │  상단 바
│                                      │
│ 새 글자                              │
│                                      │
│          ┌──────────────┐            │
│          │              │            │
│          │      す      │            │  획 데이터로 그린 글자, 200×200pt
│          │              │            │
│          └──────────────┘            │
│                 su                   │  발음
│                2획                   │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ 🍴 밥집 간판 단어                │ │  단어 카드
│ │ すし                        초밥 │ │  す만 강조, し는 흐리게
│ │ ▔▔                               │ │  (▔는 강조 글자 아래의 밑줄)
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ 💡 세로획 가운데에서 고리를 만든 │ │  쓰기 포인트
│ │    뒤 왼쪽 아래로 빼요.          │ │
│ └──────────────────────────────────┘ │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │             써 보기              │ │  주 버튼
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(2.2).
2. 머리글 "새 글자"(보조 색).
3. 글자 표시. 200×200pt 정사각형, 가운데 정렬. 글꼴이 아니라 획 데이터(`Kana.strokes`)를 본문 색으로 그린다. 캔버스에서 쓰게 될 모양과 정확히 같아야 하기 때문이다(visual-rules.md 2.3). 획마다 시작점에 번호 원을 붙여 획순을 한눈에 보여 준다. 고리가 있는 획에는 캔버스와 같은 주황 점선 원을 붙인다. 이 표시는 누르거나 쓸 수 없다. 발음 소리가 켜져 있으면 눌러서 들을 수 있다.
4. 발음 "su". 그 아래 "2획"(보조 색).
5. 단어 카드. 이 글자가 나오는 밥집 간판 단어 하나를 보여 준다. 고르는 규칙은 6.1, 배치와 모양은 6.2. 보여 줄 단어가 없는 글자에는 카드를 그리지 않는다.
6. 쓰기 포인트 상자. `lightbulb.fill` 아이콘과 문구. 문구가 없는 글자에는 상자를 그리지 않는다.
7. 주 버튼 "써 보기".

### 6.1 단어를 고르는 규칙

글자 하나에 단어 하나를 보여 준다. 저장된 진행을 보지 않고 데이터만으로 정해지므로, 처음 배울 때와 다시 할 때 같은 단어가 나온다.

1. 아는 글자 = 이전 장면들의 새 글자 전부 + 이 장면의 새 글자 가운데 지금 글자까지(지금 글자 포함, `scene.kana`의 순서 기준).
2. 후보 = 이 장면의 단어 가운데 `units`에 지금 글자와 같은 `kana`가 있는 단어. 탁음 글자는 다른 글자로 본다(は를 배울 때 ば가 든 단어는 후보가 아니다).
3. 후보마다 점수 = `units` 가운데 아는 글자에 드는 칸의 수 ÷ `units`의 칸 수. 같은 글자가 두 번 나오면 두 번 센다.
4. 점수가 가장 높은 후보 하나를 고른다. 점수가 같으면 데이터(`words`)에서 앞에 있는 단어를 고른다.
5. 후보가 없으면 단어 카드를 그리지 않는다.

장면 1의 결과:

| 글자 | 아는 글자 | 후보와 점수 | 고른 단어 | 카드의 단어 모양 | 뜻 |
|---|---|---|---|---|---|
| す | す | すし 1/2 | すし | [す]し | 초밥 |
| し | す し | すし 2/2 | すし | **す**[し] | 초밥 |
| と | す し と | とんかつ 1/4, とんこつ 1/4 (동점, 앞 단어) | とんかつ | [と]んかつ | 돈가스 |
| ん | す し と ん | とんかつ 2/4, とんこつ 2/4 (동점, 앞 단어), うどん 1/3 | とんかつ | **と**[ん]かつ | 돈가스 |
| か | す し と ん か | とんかつ 3/4, かつ 1/2 | とんかつ | **とん**[か]つ | 돈가스 |
| つ | す し と ん か つ | とんかつ 4/4, かつ 2/2 (동점, 앞 단어), とんこつ 3/4 | とんかつ | **とんか**[つ] | 돈가스 |

표에서 [ ]는 지금 글자, 굵은 글자는 앞에서 배운 글자, 나머지는 아직 안 배운 글자다. うどん의 ど는 탁음이라 ん을 배울 때 1/3이다.

배우기 순서 す → し가 すし의 글자 순서와 같아서 し에서 すし가 완성되고, と → ん → か → つ가 とんかつ의 글자 순서와 같아서 글자를 하나 배울 때마다 とんかつ가 한 칸씩 채워지고 つ에서 완성된다. かつ는 L1에 한 번도 나오지 않는다(か, つ 모두 とんかつ와 점수가 같거나 낮고 데이터에서 뒤에 있다). 장면 진입의 목표 단어 카드와 단어 읽기에서는 나온다. 네 글자가 같은 단어를 보여 주는 점은 권장안 18에 올렸다.

### 6.2 단어 카드의 배치와 모양

- 자리: 획 수 줄 아래 12pt, 쓰기 포인트 상자 위 8pt. 좌우 여백 16pt.
- 바탕: `secondarySystemBackground`, 모서리 반지름 12pt, 안쪽 여백 12pt. 쓰기 포인트 상자(주황 바탕)와 색이 달라 두 상자가 구분된다.
- 윗줄(높이 18pt): 장면 아이콘(`fork.knife`, 13pt, 보조 색), 4pt 띄우고 "밥집 간판 단어"(13pt, 보조 색).
- 4pt 아래 아랫줄(높이 34pt): 왼쪽에 단어(시스템 글꼴 28pt, 일본어 로캘, 글자 사이 2pt), 오른쪽 끝에 뜻(15pt, 본문 색, 한 줄). 기준선을 맞춘다.
- 카드 높이: 12 + 18 + 4 + 34 + 12 = 80pt.

단어의 글자 모양(visual-rules.md 2.5):

| 글자 | 조건 | 모양 |
|---|---|---|
| 지금 글자 | 지금 배우는 글자와 같은 칸. 단어에 두 번 나오면 둘 다 | 강조색, 굵게, 글자 아래 2pt 띄우고 밑줄(강조색, 굵기 2pt, 글자 폭) |
| 앞에서 배운 글자 | 6.1의 아는 글자에 들고 지금 글자가 아닌 칸 | 본문 색, 굵게 |
| 안 배운 글자 | 그 밖 | 보조 색, 보통 굵기 |

- 지금 글자는 색 말고도 밑줄로 구분된다.
- 발음 표기(로마자)와 읽기(tonkatsu)는 카드에 싣지 않는다. 지금 글자의 발음은 바로 위에 크게 있고, 단어의 읽기는 단어 읽기 세션에서 확인한다.
- 카드는 누를 수 없다. 발음 소리가 켜져 있어도 재생하지 않는다.
- VoiceOver: 카드 전체를 하나의 요소로 "밥집 간판 단어, すし의 す, 초밥". 가나는 일본어로 읽게 한다.
- L2(따라 쓰기)에는 이 카드를 넣지 않는다. 캔버스 크기를 지키기 위해서다.

### 6.3 375×667pt에서의 세로 계산

쓰기 포인트가 3줄인 글자 기준이다. 장면 1의 6자는 모두 2줄 이하로 추정되지만(6.4), 뒤 장면의 そ(5 축제), う(6 이자카야)는 3줄이라 이 화면의 상한은 3줄로 잡는다.

| 영역 | 높이(pt) |
|---|---|
| 상단 바 | 44 |
| 머리글(위 여백 8 + 22) | 30 |
| 간격 | 16 |
| 글자 표시 | 200 |
| 간격 8 + 발음(28pt 글자, 줄 높이 34) | 42 |
| 간격 8 + 획 수 | 26 |
| 간격 12 + 단어 카드 80 | 92 |
| 간격 8 + 쓰기 포인트 상자(3줄 60 + 안쪽 여백 24) | 92 |
| 아래 버튼 영역(12 + 56 + 8) | 76 |
| 합계 | 618 (사용 가능 647) |

- 3줄이어도 29pt가 남아 스크롤 없이 들어간다. 장면 1의 글자는 쓰기 포인트가 2줄(す, と, ん, か, つ)이면 598pt(49pt 남음), 1줄(し)이면 578pt다.
- 구현은 머리글과 글자 표시 사이가 24pt, 획 수와 쓰기 포인트 사이가 24pt다. 그대로 두고 카드만 넣으면 3줄 기준 합계가 642pt로 5pt밖에 남지 않는다(장면 1의 2줄 기준은 622pt). 위 표대로 16pt, 12pt, 8pt로 줄인다.
- 이 화면의 내용 영역은 지금도 `ScrollView`다. 글자 크기를 키운 설정에서 넘치면 내용만 스크롤되고 "써 보기"는 고정된다(visual-rules.md 8.1).
- 쓰기 포인트의 줄 수는 문구 길이로 추정한 값이다. 기기에서 확인이 필요하다.

### 6.4 장면 1의 글자별 내용, 상태, 전환

상태: 이 화면에는 기본 상태 하나뿐이다. 단어 카드의 모양은 글자마다 6.1의 표대로 정해져 있고 진행에 따라 바뀌지 않는다.

전환: "써 보기" → 같은 글자의 L2(1번째 따라 쓰기).

중간에 나갔을 때: 이 글자는 끝내지 않은 것으로 남는다. 다시 들어오면 이 화면부터 시작한다.

획순을 움직여 보여 주는 애니메이션은 넣지 않는다. 번호와 따라 쓰기의 가이드로 획순을 알 수 있고, 새로 만들어야 하는 요소라서 이 단계의 범위에서 뺐다.

## 7. L2 배우기: 따라 쓰기

목적: 가이드 획 위에 한 획씩 따라 써서 획순과 모양을 익힌다.

글자마다 2번 쓴다(권장안 10). 1번째와 2번째 모두 가이드가 보인다.

```
│ └──────────────────────────────────┘ │
│ ┌───────────┐ ┌────────────────────┐ │
│ │ 다시 쓰기 │ │        다음        │ │  보조 버튼 / 주 버튼(완성 전 비활성)
│ └───────────┘ └────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(2.2).
2. 글자 정보 줄(높이 52pt). 왼쪽에 글자(시스템 글꼴 34pt)와 발음, 오른쪽에 "따라 쓰기 1/2"(보조 색). 발음 소리가 켜져 있으면 글자를 눌러 들을 수 있다.
3. 쓰기 포인트 상자. L1과 같은 문구. 최대 3줄. 캔버스가 300pt보다 작아지는 화면에서는 2줄로 자르고 끝을 말줄임표로 처리한다.
4. 판정 줄. 높이 28pt 고정, 한 줄, 가운데 정렬. 아이콘과 문구. 높이를 고정해서 문구가 바뀌어도 캔버스가 움직이지 않게 한다.
5. 쓰기 캔버스. 좌우 여백 16pt, 정사각형, 아래 버튼 영역 바로 위에 붙인다. 남는 세로 공간은 쓰기 포인트 상자와 판정 줄 사이에 둔다. 캔버스 안의 표시는 visual-rules.md 5번.
6. 아래 버튼 영역. 왼쪽 보조 버튼 "다시 쓰기"(폭 112pt), 오른쪽 주 버튼 "다음"(남는 폭 전부). 사이 간격 12pt.

상태:

| 상태 | 판정 줄 | 캔버스 | 버튼 | 햅틱 |
|---|---|---|---|---|
| 처음 | "번호가 있는 점에서 시작해 따라 쓰세요" (보조 색, 아이콘 없음) | 가이드 획 전체, 1번 시작점, 1번 획의 고리 점선 원 | 다시 쓰기 비활성, 다음 비활성 | 없음 |
| 쓰는 중 | 직전 문구 유지 | 손가락을 따라 파란 선 | 변화 없음 | 없음 |
| 획 맞음 | `checkmark.circle.fill` "좋아요" | 맞은 획이 기준 획 모양의 본문 색 선으로 바뀜. 다음 획의 시작점 번호와 고리 표시가 나타남 | 다시 쓰기 활성 | 가볍게 한 번 |
| 획 틀림 | `xmark.circle.fill` + 아래 표의 문구 | 그은 선이 0.9초 동안 빨간 선으로 남았다가 사라짐. 고리를 빼먹었으면 그 자리에 빨간 점선 원이 같은 시간 동안 보임 | 다시 쓰기 활성 | 오류 |
| 글자 완성 | `checkmark.seal.fill` "완성, 한 번에 썼어요" 또는 "완성, 틀린 획 2번" (숫자는 실제 값) | 모든 획이 본문 색. 시작점 번호와 고리 표시 없음. 더 그어도 반응 없음 | 다음 활성 | 성공 |

획이 틀렸을 때의 문구(판정 종류는 `StrokeVerdict` 그대로):

| 판정 | 문구 |
|---|---|
| `reversed` | 방향이 반대예요 |
| `wrongOrder` | 지금은 1번째 획 차례예요 (숫자는 지금 쓸 획의 번호) |
| `tooShort` | 너무 짧아요 |
| `missingLoop` | 점선 자리에서 고리를 만들어야 해요 |
| `extraLoop` | 이 획에는 고리가 없어요 |
| `offTarget` | 위치나 모양이 달라요 |

`wrongOrder`만 스파이크의 문구("2번째 획이에요. 지금은 1번째 차례")에서 줄였다. 판정 줄이 한 줄이라 375pt 폭에서 넘치지 않게 하기 위해서다. 나머지는 스파이크와 같다.

"다시 쓰기": 이 글자의 이번 회차를 첫 획부터 다시 쓴다. 틀린 횟수도 0으로 돌린다. 완성한 뒤에도 누를 수 있다.

따라 쓰기에서는 획이 틀려도 넘어가지 못하게 막지 않는다. 맞을 때까지 같은 획을 다시 긋는다. 틀린 횟수는 완성 문구에만 쓰고 "틀린 글자" 기록에는 넣지 않는다(틀린 글자의 정의는 권장안 12).

전환:

- 1번째 완성 후 "다음" → 같은 글자의 2번째 따라 쓰기. 캔버스가 비워지고 오른쪽 표시가 "따라 쓰기 2/2"로 바뀐다.
- 2번째 완성 후 "다음" → 다음 글자의 L1. 진행 막대가 한 칸 찬다.
- つ(장면의 마지막 글자)의 2번째 완성 후 "다음" → C1 세션 완료(배우기).

중간에 나갔을 때: 이 글자는 끝내지 않은 것으로 남고, 다시 들어오면 이 글자의 L1부터 시작한다. 앞 글자들은 끝낸 것으로 남는다.

## 8. Q1 퀴즈: 사지선다

목적: 글자를 보고 발음을 고른다.

퀴즈 세션은 1부 사지선다 6문항 → 2부 기억으로 쓰기 6자 순서다(문항 수는 장면의 새 글자 수). 각 부 안에서 글자 순서는 섞는다. 진행 숫자는 두 부를 합쳐 12를 분모로 하고, 맞힌 항목 수를 분자로 한다("3 / 12"). 틀려서 다시 나오는 문항은 분모를 늘리지 않는다.

```
┌──────────────────────────────────────┐
│ ✕   ━━━━━───────────────────  2 / 12│  상단 바
│                                      │
│ 이 글자의 발음은?                    │  질문
│                                      │
│          ┌──────────────┐            │
│          │              │            │
│          │      と      │            │  획 데이터로 그린 글자, 160×160pt
│          │              │            │
│          └──────────────┘            │
│                                      │
│                                      │  판정 줄(높이 28pt)
│ ┌───────────────┐ ┌───────────────┐  │
│ │      ka       │ │      to       │  │  선택지 2×2
│ └───────────────┘ └───────────────┘  │  칸 높이 72pt
│ ┌───────────────┐ ┌───────────────┐  │
│ │      su       │ │      tsu      │  │
│ └───────────────┘ └───────────────┘  │
│ ┌──────────────────────────────────┐ │
│ │               다음               │ │  주 버튼(답하기 전 비활성)
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(2.2).
2. 질문 "이 글자의 발음은?".
3. 글자 표시. 160×160pt, 획 데이터로 그린다. 번호와 고리 표시는 없다.
4. 판정 줄(높이 28pt).
5. 선택지 4개. 2열 2행, 칸 높이 72pt, 칸 사이 간격 12pt, 좌우 여백 16pt. 선택지 글자는 로마자.
6. 주 버튼 "다음".

선택지 만들기: 정답 하나와 오답 셋. 오답은 같은 장면의 나머지 글자(장면 1에서는 5개)의 발음에서 3개를 고른다. 장면 1에서는 su, shi, to, n, ka, tsu 중 넷이 나온다. 네 칸의 자리는 문항마다 섞는다.

상태:

| 상태 | 판정 줄 | 선택지 | 주 버튼 | 햅틱 |
|---|---|---|---|---|
| 처음 | 비어 있음 | 네 칸 모두 기본 모양, 누를 수 있음 | 다음 비활성 | 없음 |
| 정답 | `checkmark.circle.fill` "맞아요" | 고른 칸: 초록 테두리 2pt + 칸 오른쪽 위 `checkmark.circle.fill`. 나머지 세 칸은 흐리게. 네 칸 모두 더 누를 수 없음 | 다음 활성 | 성공 |
| 오답 | `xmark.circle.fill` "정답은 to예요" (발음은 실제 정답. ん이면 "정답은 n이에요", 13번) | 고른 칸: 빨간 테두리 2pt + `xmark.circle.fill`. 정답 칸: 초록 테두리 2pt + `checkmark.circle.fill`. 나머지 두 칸은 흐리게 | 다음 활성 | 오류 |

발음 소리: 답하기 전에는 글자를 눌러도 소리가 나지 않고 스피커 아이콘도 없다. 답한 뒤에는 아이콘이 나타나고 누르면 재생한다.

오답 처리(권장안 11, 12):

- 틀린 문항은 1부의 남은 문항이 끝난 뒤 다시 나온다. 맞힐 때까지 반복한다.
- 한 번이라도 틀린 글자는 "틀린 글자"로 기록한다. 다음 장면 퀴즈에 섞을 복습 대상이 된다(PLAN.md 3번의 복습 규칙).

전환:

- "다음" → 다음 문항. 진행 숫자는 정답일 때만 오른다.
- 6문항을 모두 맞힌 뒤 "다음" → Q2의 첫 글자.

중간에 나갔을 때: 답하고 "다음"을 누르기 전에 나가도 그 문항의 결과(정답 또는 오답)는 저장한다. 답하기 전에 나갔으면 그 문항은 다시 나온다. 다시 들어오면 남은 문항부터 이어진다.

## 9. Q2 퀴즈: 기억으로 쓰기

목적: 발음만 보고 가이드 없이 글자를 쓴다.

```
┌──────────────────────────────────────┐
│ ✕   ━━━━━━━━━━━━────────────  7 / 12│  상단 바
│                                      │
│ 이 발음의 글자를 쓰세요              │  질문
│                                      │
│                 ka                   │  발음(크게)
│                                      │
│                                      │
│     기억나는 대로 한 획씩 쓰세요     │  판정 줄(높이 28pt)
│ ┌──────────────────────────────────┐ │
│ │                ┊                 │ │
│ │                ┊                 │ │
│ │                ┊                 │ │  캔버스(가이드 없음, 십자 점선만)
│ │ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ │ │
│ │                ┊                 │ │
│ │                ┊                 │ │
│ │                ┊                 │ │
│ └──────────────────────────────────┘ │
│ ┌───────────┐ ┌────────────────────┐ │
│ │가이드 보기│ │        다음        │ │  보조 버튼 / 주 버튼(완성 전 비활성)
│ └───────────┘ └────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(2.2).
2. 질문 "이 발음의 글자를 쓰세요".
3. 발음. 로마자 48pt, 가운데 정렬. 글자 자체는 보여 주지 않는다. 발음 소리가 켜져 있으면 눌러서 들을 수 있다(소리가 답을 알려 주지 않는다).
4. 판정 줄(높이 28pt).
5. 쓰기 캔버스. 가이드 획, 시작점 번호, 고리 점선 원이 없다. 십자 점선만 있다. 쓰기 포인트 상자도 없다.
6. 아래 버튼 영역. 왼쪽 보조 버튼 "가이드 보기"(폭 112pt), 오른쪽 주 버튼 "다음".

상태:

| 상태 | 판정 줄 | 캔버스 | 버튼 | 햅틱 |
|---|---|---|---|---|
| 처음 | "기억나는 대로 한 획씩 쓰세요" (보조 색) | 십자 점선만 | 가이드 보기 활성, 다음 비활성 | 없음 |
| 획 맞음 | `checkmark.circle.fill` "좋아요" | 맞은 획이 기준 획 모양의 본문 색 선으로 바뀜 | 변화 없음 | 가볍게 한 번 |
| 획 틀림 | `xmark.circle.fill` + 7번 절의 문구 | 그은 선이 0.9초 동안 빨간 선. 고리를 빼먹었으면 빨간 점선 원 | 변화 없음 | 오류 |
| 가이드 켜짐 | `lightbulb.fill` "가이드를 보고 따라 쓰세요" | 따라 쓰기와 같은 가이드 획, 시작점 번호, 고리 점선 원. 이미 맞게 쓴 획은 그대로 둠 | 가이드 보기 비활성 | 없음 |
| 완성(가이드 없이) | `checkmark.seal.fill` "완성, 기억으로 썼어요" | 모든 획이 본문 색 | 다음 활성 | 성공 |
| 완성(가이드를 봄) | `checkmark.seal.fill` "완성, 이 글자는 뒤에 한 번 더 나와요" | 모든 획이 본문 색 | 다음 활성 | 성공 |

가이드가 켜지는 경우(권장안 13):

- "가이드 보기"를 눌렀을 때.
- 한 글자에서 획을 3번 틀렸을 때. 3번째 틀린 획의 빨간 표시가 사라진 뒤 자동으로 켜진다.

`wrongOrder` 문구("지금은 1번째 획 차례예요")는 가이드가 없어도 그대로 쓴다. 획순을 알려 주는 것이 이 판정의 목적이다.

오답 처리(권장안 11, 12):

- 가이드를 본 글자는 틀린 것으로 본다. 2부의 남은 글자가 끝난 뒤 다시 나오고, 가이드 없이 완성할 때까지 반복한다. "틀린 글자"로 기록한다.
- 가이드 없이 완성했으면 도중에 획을 1~2번 틀렸어도 맞힌 것으로 본다.

전환:

- "다음" → 다음 글자. 진행 숫자는 가이드 없이 완성했을 때만 오른다.
- 6자를 모두 가이드 없이 완성한 뒤 "다음" → C1 세션 완료(퀴즈).

중간에 나갔을 때: 완성하고 "다음"을 누르기 전에 나가도 그 글자의 결과는 저장한다. 완성 전에 나갔으면 그 글자는 처음부터 다시 나온다. 그 글자에서 이미 가이드를 봤다면 "틀린 글자" 기록은 남긴다.

## 10. W 단어 읽기

목적: 밥집 간판에서 실제로 보는 단어를 배운 글자로 읽어 본다.

읽고 나서 스스로 확인하는 방식이다. 채점하지 않는다(권장안 14).

단어 순서는 S 화면의 목표 단어 카드와 같다. 앞의 세 단어가 목표 단어이고 뒤의 세 단어가 못 읽는 글자가 있는 단어다(5.1). 이 화면의 배치와 문구는 장면 연결 보강(2026-11-12)에서 바꾸지 않았다.

단어 순서(전부 읽을 수 있는 단어를 먼저): すし → とんかつ → かつ → そば → うどん → とんこつ. 진행 숫자는 단어 기준이다("5 / 6").

```
읽기 전                                     확인 후
┌──────────────────────────────────────┐   ┌──────────────────────────────────────┐
│ ✕   ━━━━━━━━━━━━━━━━────────  5 / 6 │   │ ✕   ━━━━━━━━━━━━━━━━────────  5 / 6 │
│                                      │   │                                      │
│ 소리 내어 읽어 보세요                │   │ 소리 내어 읽어 보세요                │
│                                      │   │                                      │
│                                      │   │                                      │
│            u     do                  │   │            u     do                  │  발음 표기(작게)
│            う    ど    ん            │   │            う    ど    ん            │  단어(크게)
│                                      │   │                                      │
│                                      │   │               udon                   │  읽기
│                                      │   │               우동                   │  뜻
│                                      │   │                                      │  어디서 보는지(없는 단어)
│                                      │   │                                      │
│ ┌──────────────────────────────────┐ │   │ ┌──────────────────────────────────┐ │
│ │            읽기 확인             │ │   │ │               다음               │ │
│ └──────────────────────────────────┘ │   │ └──────────────────────────────────┘ │
└──────────────────────────────────────┘   └──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(2.2).
2. 안내 "소리 내어 읽어 보세요".
3. 단어. 글자마다 세로로 두 칸을 쌓는다. 위 칸은 발음 표기(로마자 15pt, 보조 색, 높이 20pt), 아래 칸은 글자(시스템 글꼴 56pt). 글자 칸의 폭은 64pt, 글자 사이 간격 4pt. 5자 단어의 폭은 336pt로 375pt 화면에 들어간다. 6자 이상인 단어는 글자를 48pt, 칸 폭을 52pt로 줄이고, 그래도 넘치면 두 줄로 나눈다(장면 1의 가장 긴 단어는 とんかつ, とんこつ의 4자로 폭 268pt라 해당 단어 없음).
4. 확인 후에만 보이는 줄 3개: 읽기(로마자, 22pt), 뜻(17pt), 어디서 보는지(15pt, 보조 색, 있는 단어만).
5. 주 버튼. 읽기 전 "읽기 확인", 확인 후 "다음". 마지막 단어의 확인 후에는 "완료".

발음 표기 규칙(PLAN.md 3번·5번):

- 이 장면까지 배운 글자(장면 1에서는 す し と ん か つ)에는 붙이지 않는다. 위 칸은 비워 두되 높이는 유지해서 글자의 세로 위치가 단어마다 같게 한다.
- 아직 배우지 않은 글자와 탁음·반탁음 글자에는 붙인다. 두 경우의 모양은 같다.
- 읽기 전부터 보인다. 확인 버튼과 상관없다.

장면 1의 단어별 내용:

| 순서 | 단어 | 글자 위 발음 표기 | 읽기 | 뜻 | 어디서 보는지 |
|---|---|---|---|---|---|
| 1 | すし | 없음 | sushi | 초밥 | 없음 |
| 2 | とんかつ | 없음 | tonkatsu | 돈가스 | 없음 |
| 3 | かつ | 없음 | katsu | 커틀릿 | かつ丼처럼 한자와 붙여 써요 (초안) |
| 4 | そば | so · ba | soba | 메밀국수 | 없음 |
| 5 | うどん | u · do (ん은 없음) | udon | 우동 | 없음 |
| 6 | とんこつ | ko (こ에만) | tonkotsu | 돼지뼈 육수 (라멘) | 없음 |

읽기와 뜻은 hiragana-reorder-proposal.md 5.1의 읽기·뜻 열에서 가져왔다. 화면에 싣는 값은 단어 데이터(`reading`, `meaning`, `note`)에서 온다. 비고 열의 한자 표기(寿司 등), 출처, "탁음" 같은 분류는 싣지 않는다. かつ의 안내 줄은 hiragana-reorder-proposal.md 7번 결정 2의 권장("かつ丼처럼 써요"를 화면에 보여 준다)을 이 자리에 놓은 것이고, 문구는 디자인 담당의 초안이라 planner가 `note`에 넣을 때 확정한다. かつ의 뜻을 "커틀릿"으로 줄일지 "커틀릿 (かつ丼의 かつ)"로 둘지도 planner가 정한다. 둘 다 이 줄 폭에 들어간다.

장음 안내: 장면 1의 단어 6개에는 장음이 없어 이 장면에서는 장음 안내가 나오지 않는다. 확인 후의 읽기가 글자별 발음을 이은 것과 같다(う-ど-ん → udon). 장음 안내는 "어디서 보는지" 줄 자리에 단어별로 보여 주는 문구이고 단어 데이터에 둔다(권장안 15, 2026-11-12 기획 검토 반영). 히라가나에서 처음 쓰이는 곳은 8 료칸이다. ようこそ("よう는 yo, u로 끊지 않고 yō로 길게 읽어요")와 ほうじちゃ(hōjicha)의 문구가 필요하다. 원래 함께 있던 くうこう의 문구("くう는 kū, こう는 kō로 길게 읽어요")는 공항이 가타카나 장면으로 옮겨지면서 히라가나에서는 쓰이지 않는다.

상태:

| 상태 | 화면 | 주 버튼 | 햅틱 |
|---|---|---|---|
| 읽기 전 | 단어와 발음 표기만 | 읽기 확인 | 없음 |
| 확인 후 | 읽기, 뜻, 어디서 보는지가 나타남(0.2초 페이드) | 다음 (마지막 단어는 완료) | 가볍게 한 번 |

발음 소리: 켜져 있으면 글자 하나를 누를 때 그 글자를, 확인 후의 읽기 줄을 누르면 단어 전체를 읽어 준다. 채점이 없는 화면이라 읽기 전에도 글자 재생을 막지 않는다.

전환:

- "읽기 확인" → 같은 단어의 확인 후 상태.
- "다음" → 다음 단어의 읽기 전 상태.
- 마지막 단어에서 "완료" → 이 세션을 처음 끝낸 것이면 C2 장면 완료, 다시 한 것이면 C1 세션 완료.

중간에 나갔을 때: 확인 후 "다음"을 누른 단어까지 끝낸 것으로 저장한다. 다시 들어오면 그다음 단어의 읽기 전 상태부터 시작한다.

## 11. C1 세션 완료

목적: 세션 하나가 끝났음을 알리고, 다음 세션으로 바로 이어 가게 한다. 점수와 통계는 싣지 않는다.

```
┌──────────────────────────────────────┐
│                                      │
│                                      │
│                 ✓                    │  checkmark.circle.fill, 64pt
│                                      │
│            배우기 완료               │  제목
│       새 글자 6자를 따라 썼어요      │  한 줄 요약
│                                      │
│      す   し   と   ん   か   つ     │  이번 세션의 글자
│                                      │
│                                      │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │            퀴즈 시작             │ │  주 버튼
│ └──────────────────────────────────┘ │
│            여기까지 하기             │  보조 버튼(글자만)
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 아이콘 `checkmark.circle.fill`, 64pt, 초록. 화면 높이의 위에서 3분의 1 지점.
2. 제목과 한 줄 요약.
3. 이번 세션의 글자 줄(34pt, 글자 사이 16pt). 6자의 폭은 34×6 + 16×5 = 284pt로 375pt 화면의 좌우 여백 16pt 안(343pt)에 들어간다. 퀴즈에서 틀린 글자가 있었으면 그 글자 아래에 작은 점(지름 6pt, 주황)을 붙이고 요약 문구로 알린다.
4. 주 버튼(다음 세션 시작)과 보조 버튼 "여기까지 하기"(글자만 있는 버튼, 높이 44pt). 닫기 버튼은 없다.

세션별 문구:

| 끝낸 세션 | 제목 | 한 줄 요약 | 주 버튼 |
|---|---|---|---|
| 배우기 | 배우기 완료 | 새 글자 6자를 따라 썼어요 | 퀴즈 시작 |
| 퀴즈, 틀린 글자 없음 | 퀴즈 완료 | 6자를 모두 한 번에 맞혔어요 | 단어 읽기 시작 |
| 퀴즈, 틀린 글자 있음 | 퀴즈 완료 | と, か는 다음 장면 퀴즈에 다시 나와요 (글자는 실제 틀린 글자) | 단어 읽기 시작 |
| 다시 한 세션(이미 완료였던 것) | 배우기 완료 / 퀴즈 완료 / 단어 읽기 완료 | 처음 끝냈을 때와 같은 문구. 단어 읽기는 "밥집 간판 단어 6개를 읽었어요" | 장면으로 돌아가기 (보조 버튼 없음) |

상태: 화면이 나타날 때 성공 햅틱을 한 번 낸다. 그 밖의 상태는 없다.

전환:

- 주 버튼 → 다음 세션의 첫 화면(같은 fullScreenCover 안에서 내용을 바꾼다).
- "여기까지 하기" → 덮개를 닫고 S 장면 진입으로.

중간에 나갔을 때: 세션 완료는 이 화면이 뜨기 전, 마지막 항목을 끝낸 시점에 저장한다. 이 화면에서 앱을 닫아도 세션은 완료 상태다. 다시 켜면 홈에서 시작한다.

## 12. C2 장면 완료

목적: 장면 하나를 끝냈고 다음 장면이 열렸음을 알린다.

```
┌──────────────────────────────────────┐
│                                      │
│                                      │
│                 🍴                   │  장면 아이콘, 64pt
│                                      │
│        밥집 간판 장면 완료           │  제목
│     히라가나 6자를 읽고 쓸 수 있어요 │  한 줄 요약
│                                      │
│      す   し   と   ん   か   つ     │  배운 글자
│                                      │
│   이제 읽을 수 있는 밥집 간판 단어   │  목표 단어
│        すし   とんかつ   かつ        │
│                                      │
│      다음 장면 '역'이 열렸어요       │  열린 장면 알림
│            え き の り お            │  다음 장면의 새 글자
│                                      │
│ ┌──────────────────────────────────┐ │
│ │           장면 목록으로          │ │  주 버튼
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 장면 아이콘(`fork.knife`, 64pt, 강조색)과 그 오른쪽 아래에 겹친 `checkmark.circle.fill`(24pt, 초록).
2. 제목 "밥집 간판 장면 완료", 요약 "히라가나 6자를 읽고 쓸 수 있어요".
3. 배운 글자 줄(34pt). 6자는 C1과 같이 284pt로 한 줄에 들어간다.
4. 목표 단어 묶음. 윗줄 "이제 읽을 수 있는 밥집 간판 단어"(15pt, 보조 색), 8pt 아래에 목표 단어(5.1의 계산)를 데이터 순서대로 한 줄로 놓는다. 시스템 글꼴 22pt, 일본어 로캘, 본문 색, 굵게, 단어 사이 16pt. S 화면의 "다 배움" 머리글과 같은 문구다. 뜻과 읽기는 싣지 않는다. 못 읽는 글자가 있는 단어(そば 등)는 싣지 않는다. 누를 수 없다. 목표 단어가 0개인 장면에서는 묶음을 그리지 않는다. 한 줄에 다 들어가지 않으면 줄을 바꾼다(장면 1은 すし, とんかつ, かつ의 8자 × 22pt + 16pt × 2 = 208pt로 한 줄).
5. 열린 장면 알림 "다음 장면 '역'이 열렸어요"와 그 장면의 새 글자(구현은 20pt, 보조 색).
6. 주 버튼 "장면 목록으로". 보조 버튼은 없다.

375×667pt에서의 세로 계산(구현의 배치 기준. 내용 영역 높이는 647 − 버튼 영역 76 = 571pt):

| 영역 | 높이(pt) |
|---|---|
| 위 여백(571 ÷ 3 − 64) | 126 |
| 아이콘 | 64 |
| 간격 24 + 제목(28) + 간격 8 + 요약(22) | 82 |
| 간격 24 + 배운 글자 줄 | 75 |
| 간격 24 + 목표 단어 묶음(20 + 8 + 28) | 80 |
| 간격 24 + 열린 장면 알림(위 여백 24 + 22 + 8 + 25) | 103 |
| 합계 | 530 (사용 가능 571) |

스크롤 없이 들어간다. 세션 완료(C1)와 단어 읽기(W)에는 목표 단어 표시를 더하지 않는다. C1은 세션마다 한 줄 요약이 이미 있고, W는 단어 자체가 화면의 내용이다.

주 버튼을 "역 시작"이 아니라 "장면 목록으로"로 둔 이유: 한 세션이 2~3분이라 장면 하나를 끝낸 시점은 멈추기 좋은 자리이고, 홈에서 장면 1에 완료 표시가 붙고 장면 2의 자물쇠가 풀린 것을 직접 보게 하려는 것이다. 홈의 아래 주 버튼이 "역 · 배우기 시작"이므로 이어서 하려는 사람도 한 번만 더 누르면 된다.

상태: 화면이 나타날 때 성공 햅틱을 한 번 낸다.

전환: "장면 목록으로" → 덮개를 닫고 내비게이션 스택을 홈까지 되돌린다. 홈에서 장면 1은 완료, 장면 2는 열림으로 보인다.

중간에 나갔을 때: 장면 완료와 다음 장면 열림은 단어 읽기의 마지막 단어를 끝낸 시점에 저장한다. 이 화면에서 앱을 닫아도 다음에 켜면 홈에 반영돼 있다. 이 화면은 다시 보여 주지 않는다.

## 13. 화면에 나오는 문구 모음

개발 담당이 문자열을 한곳에서 옮길 수 있게 모았다. 장면 이름, 글자, 숫자는 데이터에서 채운다.

| 화면 | 문구 |
|---|---|
| H | 니혼go / 히라가나 / 발음 소리 / 완료 / {장면} · {세션} 시작 / {장면} · {세션} 이어서 하기 |
| S (목표 단어 카드) | 글자를 배우면 읽는 {장면} 단어 / 이제 읽을 수 있는 {장면} 단어 / 배운 글자 {배운 수} / {전체} / 읽을 수 있어요 / 아직 못 읽는 글자가 있는 단어 |
| S | 새 글자 {N}자 / 배우기 / 퀴즈 / 단어 읽기 / 새 글자를 보고 따라 써요 / 발음을 고르고 기억으로 써요 / {장면}에서 보는 단어 {N}개를 읽어요 / 배우기를 끝내면 열려요 / 퀴즈를 끝내면 열려요 / 이어서 하기 · {끝낸 수} / {전체} / 완료 · 다시 하기 / {세션} 시작 / {세션} 이어서 하기 / 장면 목록으로 |
| L1 | 새 글자 / {N}획 / {장면} 단어 / 써 보기 |
| L2 | 따라 쓰기 {회차}/2 / 번호가 있는 점에서 시작해 따라 쓰세요 / 좋아요 / 완성, 한 번에 썼어요 / 완성, 틀린 획 {N}번 / 다시 쓰기 / 다음 |
| L2, Q2 | 방향이 반대예요 / 지금은 {N}번째 획 차례예요 / 너무 짧아요 / 점선 자리에서 고리를 만들어야 해요 / 이 획에는 고리가 없어요 / 위치나 모양이 달라요 |
| Q1 | 이 글자의 발음은? / 맞아요 / 정답은 {발음}예요 / 다음 |
| Q2 | 이 발음의 글자를 쓰세요 / 기억나는 대로 한 획씩 쓰세요 / 가이드를 보고 따라 쓰세요 / 완성, 기억으로 썼어요 / 완성, 이 글자는 뒤에 한 번 더 나와요 / 가이드 보기 / 다음 |
| W | 소리 내어 읽어 보세요 / (단어별 장음 안내) / 읽기 확인 / 다음 / 완료 |
| C1 | {세션} 완료 / 새 글자 {N}자를 따라 썼어요 / {N}자를 모두 한 번에 맞혔어요 / {글자들}는 다음 장면 퀴즈에 다시 나와요 / {장면} 단어 {N}개를 읽었어요 / {다음 세션} 시작 / 여기까지 하기 / 장면으로 돌아가기 |
| C2 | {장면} 장면 완료 / 히라가나 {N}자를 읽고 쓸 수 있어요 / 이제 읽을 수 있는 {장면} 단어 / 다음 장면 '{장면}'이 열렸어요 / 장면 목록으로 |
| VoiceOver (S, L1) | {단어}, {뜻}, 글자 {전체}개 중 {배운 수}개 배움 / {단어}, {뜻}, 읽을 수 있어요 / {장면} 단어, {단어}의 {글자}, {뜻} |

목표 단어의 뜻("초밥", "돈가스")은 문구가 아니라 단어 데이터의 `meaning`에서 가져온다.

"정답은 {발음}예요"에서 조사는 로마자의 끝소리와 상관없이 "예요"로 고정한다. 히라가나 46자의 로마자는 ん(n)을 빼면 모두 모음으로 끝난다. ん이 정답일 때만 "정답은 n이에요"로 쓴다.

## 14. 저장해야 하는 상태

화면 흐름이 요구하는 것만 적었다. 저장 방식은 개발 담당이 정한다.

| 항목 | 값 | 쓰는 화면 |
|---|---|---|
| 장면별 세션 완료 여부 | 세션 3개 각각 완료/미완료 | H, S |
| 세션별 진행 위치 | 끝낸 항목 목록, 퀴즈에서 다시 낼 항목 목록 | S, 세션 화면 |

목표 단어 표시(S, L1, C2) 때문에 새로 저장하는 값은 없다.

- S의 "배운 글자"는 위 표의 "장면별 세션 완료 여부"(배우기)와 "세션별 진행 위치"(배우기에서 끝낸 글자 목록, 구현의 `learnDone`)에서 계산한다(5.1).
- L1의 단어와 글자 모양, C2의 목표 단어는 장면 데이터만으로 정해진다(6.1, 5.1).
- 단어 데이터(`hiragana_scenes.json`)에 더할 항목도 없다. 지금 있는 `text`, `units`, `meaning`과 장면의 `kana`, `icon`만 쓴다.
