## 2. 모든 화면에 공통인 규칙

### 2.1 화면을 띄우는 방식

- 홈, 장면 진입, 기리 꾸미기는 `NavigationStack` 안에 둔다. 장면 진입에서 왼쪽 가장자리 스와이프로 홈에 돌아갈 수 있다.
- 세션 화면(L1, L2, W, QI, QA~QE, C1, C2)은 세션 하나에 `fullScreenCover` 하나로 띄운다. 쓰기 캔버스(L2, QC)가 화면 왼쪽 가장자리에서 16pt 떨어져 있어, 내비게이션 스택에 넣으면 획을 긋다가 뒤로 가기 스와이프가 걸린다. 전체 화면 덮개에는 가장자리 스와이프가 없다.
- 덮개 안에서는 화면을 밀지 않고 내용만 바꾼다. 배우기 → 단어 읽기, 문항 → 문항, 부 → 부, C1에서 다음 세션으로 넘어갈 때(단계 a → 단계 b, 단계 b → 퀴즈) 모두 같다. 전환은 0.2초 페이드. "동작 줄이기"가 켜져 있으면 전환 없이 바로 바꾼다.

### 2.2 세션 화면의 공통 뼈대

위에서 아래 순서.

| 영역 | 높이 | 내용 |
|---|---|---|
| 상단 바 | 44pt | 왼쪽: 닫기 버튼(`xmark`, 44×44pt). 가운데: 진행 막대. 오른쪽: 지금 구간 이름. 단계 세션은 7.2, 퀴즈 세션은 12.3 |
| 내용 영역 | 남는 높이 | 화면마다 다름. 보기만 하는 정보는 위, 누르거나 쓰는 대상은 아래 |
| 아래 버튼 영역 | 56pt + 위 12pt + 아래 8pt = 76pt | 주 버튼 하나. 보조 버튼이 있으면 주 버튼 왼쪽에 둔다 |

- 내용 영역에는 기리 줄(기리 + 말풍선, giri-companion.md 2번)이 하나 있다. 자리는 화면마다 다르고(giri-companion.md 3.1), 누르는 대상(캔버스, 선택지, 버튼)과 겹치지 않는다. C1, C2도 같다.
- 닫기 버튼은 엄지가 닿기 어려운 왼쪽 위에 둔다. 자주 쓰는 조작이 아니고, 아래에 두면 쓰다가 잘못 누르기 쉽다.
- 아래 버튼 영역은 모든 세션 화면에서 같은 자리에 둔다. 주 버튼의 위치가 화면마다 바뀌지 않아야 보지 않고 누를 수 있다.
- C1, C2에는 상단 바가 없다(11, 14번).

### 2.3 발음 표기

발음은 로마자(`romaji`)를 쓴다: す su, し shi, い i, か ka, た ta, こ ko.

### 2.4 발음 소리

- 기본값은 켜짐. 홈 오른쪽 위 메뉴(`ellipsis.circle`)의 "발음 소리" 토글로 끈다.
- 켜져 있을 때만 소리를 낼 수 있는 글자 옆에 `speaker.wave.2.fill` 아이콘(15pt, `InkSecondary`)을 붙인다. 꺼져 있으면 아이콘이 없고 글자를 눌러도 아무 일도 없다.
- 소리가 답을 알려 주는 자리에서는 답하기 전에 재생하지 않는다. 화면별로 적었다.

### 2.5 도중에 나갔을 때

닫기 버튼을 누르거나, 앱이 백그라운드로 가거나, 종료된 경우 모두 같은 규칙이다.

- 진행은 **세션마다** 항목 단위로 저장한다. 항목은 배우기의 글자 하나(소개 + 따라 쓰기 2번), 단어 읽기의 단어 하나, 퀴즈의 문항 하나다.
- 끝낸 항목은 남고, 하던 항목은 처음으로 돌아간다. 예: か의 따라 쓰기 2번째를 쓰다가 나가면, 다시 들어왔을 때 か의 L1부터 시작한다.
- 닫기 버튼은 확인 창 없이 바로 닫는다. 닫으면 장면 진입(S)으로 간다. 퀴즈가 20문항 안팎이어도 잃는 것은 하던 문항 하나뿐이라 확인 창을 두지 않는다.
- 다시 들어가는 자리는 S의 해당 행과 홈의 아래 주 버튼이다. 둘 다 "이어서 하기"로 바뀐다.
- 다시 들어갔을 때의 첫 화면:

| 세션 | 나간 자리 | 다시 들어가면 |
|---|---|---|
| 단계 | 배우기 도중 | 끝내지 않은 첫 글자의 L1 |
| 단계 | 배우기를 다 끝내고 첫 단어 전 | W의 첫 단어, 읽기 전 상태 |
| 단계 | 단어 읽기 도중 | 끝내지 않은 첫 단어의 읽기 전 상태 |
| 퀴즈 | QI (한 문항도 답하지 않음) | QI |
| 퀴즈 | 문항 도중 (한 문항이라도 답함) | 답하지 않은 다음 문항. 부 안의 첫 차례든 다시 내는 차례든 나간 자리 그대로다. QI는 다시 보여 주지 않는다. 부 머리 줄은 그 문항의 보통 모양(12.4) |
| 둘 다 | C1, C2 | 이미 완료 상태다. 다시 보여 주지 않고 S(또는 홈)에 결과가 반영돼 있다 |

- 퀴즈는 정해 둔 문항 순서, 부마다 다시 낼 문항 목록, 이번 퀴즈에서 생긴 틀린 글자도 함께 저장한다(16번). 선택지는 다시 들어갈 때 새로 섞어도 된다.
- 끝낸 세션(단계, 통과한 퀴즈)을 다시 하는 중에는 진행을 저장하지 않는다. 닫으면 다시 할 때 처음부터 시작한다. 완료 상태와 틀린 글자 기록은 바뀌지 않는다.

## 4. 장면, 세션, 단계

### 4.1 낱말

| 낱말 | 뜻 | 화면에 쓰는 이름 |
|---|---|---|
| 장면 | 스테이지 하나. 세션 3개. 새 글자 5~6자 | 데이터의 장면 이름 (스시집) |
| 단계 | 장면 안의 동선 한 칸. 새 글자 2~4자와 단어. 단계 하나 = 단계 세션 하나 | 데이터의 단계 이름 (간판, 메뉴) |
| 종합 퀴즈 | 장면의 세 번째 세션. 두 단계의 글자와 단어, 앞 장면 복습 글자를 섞어 묻는다 | 종합 퀴즈 |
| 구간 | 단계 세션 안의 배우기, 단어 읽기 | 배우기 / 단어 읽기 |
| 부 | 퀴즈 세션 안에서 한 유형의 문항을 묶은 것 | 유형 이름 (발음 고르기 등, 12.2) |

화면 문구에는 "세션", "단계", "구간", "부"라는 말을 쓰지 않는다. 단계는 이름("간판", "메뉴")으로, 구간과 부는 그 이름으로 부른다(visual-rules.md 6.3). VoiceOver 레이블은 예외로 "1단계"를 쓴다.

### 4.2 데이터에 필요한 것

장면 데이터에 단계 층을 둔다. 이름과 형식은 개발 담당이 정한다. 화면이 필요로 하는 값만 적었다.

| 항목 | 예 | 쓰는 화면 |
|---|---|---|
| 장면 id | `sushi` | 저장, 보상 지급 키 |
| 단계 id | `sushi-a`, `sushi-b` | 저장, 보상 지급 키 |
| 퀴즈 세션 id | `sushi-quiz` (장면 id에서 계산, 데이터에 따로 두지 않아도 됨) | 저장, 보상 지급 키 |
| 단계 순서 | 1, 2 | H, S, 잠금 |
| 단계 이름 | 메뉴 | H 주 버튼, S, C1, L1 단어 카드 |
| 새 글자 (배우는 순서) | い か た こ | 전부 |
| 단어 (데이터 순서) | いか, たこ, いくら, まぐろ, えび, いなり | S, L1, W, C1, C2, QD, QE |
| 퀴즈 구성 | `quiz-rules.md`가 정하는 유형별 문항 수와 순서 | QI, 퀴즈 세션 |

장면의 `kana`는 단계 글자를 순서대로 이은 것과 같다(す し い か た こ). 장면에 따로 두지 않고 단계에서 계산해도 된다.

### 4.3 열리는 순서

- 장면 1의 단계 a는 처음부터 열려 있다.
- 단계 b는 같은 장면의 단계 a를 끝내면 열린다.
- 종합 퀴즈는 같은 장면의 단계 a와 b를 모두 끝내면 열린다.
- 다음 장면의 단계 a는 이 장면의 종합 퀴즈를 통과하면 열린다. 장면 완료 = 종합 퀴즈 통과.
- 단계 세션 안의 구간은 배우기 → 단어 읽기 순서로만 진행한다. 구간을 골라 들어가는 길은 없다.
- 끝낸 단계, 통과한 퀴즈는 다시 할 수 있다. 다시 하면 처음부터 시작한다.
- 퀴즈가 열린 뒤 단계를 다시 해도 퀴즈 상태(열림, 하던 중, 통과)는 바뀌지 않는다.

### 4.4 배운 글자와 읽히는 단어의 계산

새로 저장하는 값은 없다. 데이터와 4.3의 진행 상태에서 계산한다.

| 이름 | 계산 | 1b의 값 |
|---|---|---|
| 이 단계까지의 글자 | 앞 장면들의 새 글자 전부 + 이 장면의 앞 단계 글자 + 이 단계 글자 | す し い か た こ |
| 배운 글자 | 앞 장면들의 새 글자 전부 + 이 장면에서 배우기를 끝낸 단계의 글자 전부 + 배우기 도중인 단계의 끝낸 글자(`learnDone`) | 진행에 따라 す し ~ す し い か た こ |
| 단계의 목표 단어 | 이 단계 단어 가운데 가나 칸(`kanaUnits`)이 모두 "이 단계까지의 글자"에 드는 단어. 데이터 순서 | いか, たこ |
| 단계의 못 읽는 단어 | 이 단계의 나머지 단어. 데이터 순서 | いくら, まぐろ, えび, いなり |
| 장면의 목표 단어 | 두 단계의 목표 단어를 단계 순서대로 이은 것. C2와 퀴즈 QD·QE의 기본 단어 목록 | すし, いか, たこ |

- 글자 하나를 "배웠다"고 보는 시점은 배우기에서 그 글자의 2번째 따라 쓰기를 완성하고 주 버튼을 누른 때다.
- 배우기 구간을 끝낸 단계(완료한 단계 포함)는 글자 전부를 배운 것으로 본다. 끝낸 단계를 다시 하는 동안에도 단어가 도로 흐려지지 않는다.
- 탁음·반탁음 글자(ぐ, び)와 가르치지 않는 한자(丼 등)는 언제나 배운 글자가 아니다.
- 퀴즈는 배운 글자 계산에 영향을 주지 않는다.
- 목표 단어 여부를 데이터에 적지 않는다. 위 계산으로 정해진다.

375×667pt에서 장면 행은 y 약 230부터 아래 고정 영역 위 끝(y 491)까지 261pt에 약 3.4개 보인다(144pt 때 3.8개, 기리 동행 개정 전 약 4.5개). 402×874pt에서는 y 약 272부터 664까지 392pt에 약 5.1개(144pt 때 5.5개). 주 버튼 자리는 그대로다(giri-companion.md 3.2).

### 5.1 퀴즈가 남았음을 보여 주는 방법

- 장면 행은 "2/3"만 보여 준다. 행에 "퀴즈 차례" 같은 글자를 더하지 않는다.
- 이유: 다음 장면은 퀴즈를 통과해야 열리므로, 퀴즈가 남은 장면은 언제나 하나뿐이고 그 장면이 아래 주 버튼의 대상이다. 주 버튼이 "스시집 · 종합 퀴즈 시작"이라고 말하므로 같은 말을 행에 또 쓸 필요가 없다. 행 오른쪽 글자를 "퀴즈 차례"(약 70pt)로 바꾸면 375pt 폭에서 글자 줄 자리(아래 폭 확인)가 모자란다.
- 분모가 3인 것으로 "단계 둘을 끝내도 하나가 더 있다"가 드러난다. 무엇이 남았는지는 S의 퀴즈 행(6.3)이 보여 준다.
- VoiceOver는 남은 것을 말로 읽는다(아래).

폭 확인(375pt): 행 내용 폭 311pt − 그림 52 − 간격 12 = 247pt. 오른쪽 "2/3 ›"(약 50pt)를 빼면 글자 줄에 약 197pt. 가장 긴 줄은 6자 + 가운뎃점("ま み も · あ や は"): 글자 6 × 20 + 글자 사이 4칸 × 5 + 가운뎃점 묶음 약 22 = 약 162pt로 들어간다.

주 버튼 폭: 가장 긴 문구 "소바·우동집 · 종합 퀴즈 이어서 하기"가 17pt 굵게 약 285pt로 343pt 안에 들어간다. 넘치면 한 줄을 유지하고 글자를 0.85까지 줄인다(`minimumScaleFactor(0.85)`).

### 5.2 상태 (장면 1 행과 주 버튼)

| 상태 | 장면 1 행 오른쪽 | 아래 주 버튼 문구 | 기리 말풍선 |
|---|---|---|---|
| 처음 | 0/3 | 스시집 · 간판 시작 | 첫 여행지는 스시집이에요. 같이 가 봐요 |
| 간판 도중에 나감 | 0/3 | 스시집 · 간판 이어서 하기 | 스시집 간판 하던 데부터 이어서 해요 |
| 간판 끝 | 1/3 | 스시집 · 메뉴 시작 | 스시집 메뉴를 읽으러 가요 |
| 메뉴 도중에 나감 | 1/3 | 스시집 · 메뉴 이어서 하기 | 스시집 메뉴 하던 데부터 이어서 해요 |
| 메뉴 끝 | 2/3 | 스시집 · 종합 퀴즈 시작 | 스시집에서 읽은 걸 같이 확인해 봐요 |
| 퀴즈 도중에 나감 | 2/3 | 스시집 · 종합 퀴즈 이어서 하기 | 스시집 종합 퀴즈 하던 데부터 이어서 해요 |
| 퀴즈 통과 (장면 1 완료) | 완료 (체크 배지) | 돈카츠집 · 간판 시작 (장면 2 행이 열림으로 바뀜) | 다음 여행지는 돈카츠집이에요. 간판부터 봐요 |

장면 2의 내용이 아직 없는 빌드: 장면 2 행은 열림으로 표시하되 누르면 "준비 중이에요" 알림만 띄우고 아래 주 버튼은 숨긴다(개발 중 임시 규칙, 전과 같음). 기리 줄은 남고 "다음 여행지는 아직 준비 중이에요"라고 말한다.

잠긴 행: 이름과 글자를 `InkSecondary`로 낮추고 그림을 흑백으로, 자물쇠 배지를 붙인다. 눌러도 반응하지 않는다(`disabled`). 새 글자는 잠겨 있어도 보여 준다.

VoiceOver: 행 하나를 하나의 요소로 읽는다.

- "1번 스시집, 간판 す し, 메뉴 い か た こ, 3개 중 1개 완료"
- "1번 스시집, 간판 す し, 메뉴 い か た こ, 3개 중 2개 완료, 종합 퀴즈 차례"
- "1번 스시집, 완료" / "2번 돈카츠집, 잠김"

그림과 배지는 읽지 않는다. 기리 그림도 읽지 않고, 말풍선은 목록 다음, 주 버튼 앞에 대사 그대로 읽는다(giri-companion.md 6.1).

전환:

- 열린 장면 행 또는 끝낸 장면 행 탭 → S 장면 진입(push).
- 아래 주 버튼 탭 → 문구에 적힌 세션(fullScreenCover). 세션을 닫으면 그 장면의 S가 아래에 깔려 있도록, 덮개를 띄우기 전에 S를 먼저 push한다.

## 6. S 장면 진입

목적: 이 장면의 단계 두 개와 각 단계에서 읽게 될 단어, 마지막 종합 퀴즈를 보여 주고, 기리가 장면을 소개하며 다음 세션을 시작하게 한다.

```
간판과 메뉴를 끝내고 종합 퀴즈가 할 차례인 상태
┌──────────────────────────────────────┐
│ ‹ 니혼go                             │  내비게이션 바(뒤로)
│ 스시집                               │  큰 제목
│ ┌──────────────────────────────────┐ │
│ │ ✓  간판                    완료 ›│ │  단계 행 (1a, 완료)
│ │    す し                         │ │
│ ├──────────────────────────────────┤ │
│ │ すし                        초밥 │ │  목표 단어
│ │                 ✓ 읽을 수 있어요 │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ ✓  메뉴                    완료 ›│ │  단계 행 (1b, 완료)
│ │    い か た こ                   │ │
│ ├──────────────────────────────────┤ │
│ │ いか                      오징어 │ │
│ │                 ✓ 읽을 수 있어요 │ │
│ ├──────────────────────────────────┤ │
│ │ たこ                        문어 │ │
│ │                 ✓ 읽을 수 있어요 │ │
│ ├──────────────────────────────────┤ │
│ │ 아직 못 읽는 글자가 있는 단어    │ │
│ │ いくら  まぐろ  えび  いなり     │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ ③  종합 퀴즈                   › │ │  퀴즈 행 (할 차례)
│ │    글자 6자 · 단어 3개           │ │
│ └──────────────────────────────────┘ │
├──────────────────────────────────────┤  아래 고정 영역 (176pt)
│ ┌────────┐ ┌───────────────────────┐ │
│ │        │◁│ 여기 단어는 다 봤어요.│ │  기리 줄 (96pt)
│ │  기리  │ │ 같이 확인해 볼까요?   │ │
│ │  96pt  │ └───────────────────────┘ │
│ └────────┘                           │
│ ┌──────────────────────────────────┐ │
│ │          종합 퀴즈 시작          │ │  아래 고정 주 버튼
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 내비게이션 바. 뒤로 버튼(기본), 큰 제목은 장면 이름.
2. (main의 Lottie 시제품이 들어오면) 장면 그림 섹션. 기리를 이 그림 위에 겹치지 않는다(giri-companion.md 3.3, 5.1).
3. 단계 섹션 2개. `List`의 `insetGrouped` 섹션 하나가 단계 하나다. 섹션 머리글은 없다. 섹션 안의 행 순서: 단계 행 → 목표 단어 행(단어마다) → 못 읽는 단어 줄.
4. 종합 퀴즈 섹션 1개. 퀴즈 행 하나만 있다(6.3).
5. 아래 고정 영역. 홈(5번의 5)과 같은 176pt: 기리 줄(기리 96pt, 말하기, 말풍선 최대 3줄) + 주 버튼. 말풍선은 장면 소개와 다음 할 일(6.7 표). 큰 글자 크기에서는 기리 줄을 목록 맨 위 행으로 옮긴다.

섹션 사이 간격 16pt(`listSectionSpacing(16)`). `List`의 맨 위 여백 8pt.

### 6.1 단계 행

| 요소 | 값 |
|---|---|
| 높이 | 72pt (행 내용 최소 높이 50pt) |
| 왼쪽 | 상태 아이콘, 28pt 폭 (6.2 표) |
| 가운데 (아이콘 오른쪽 12pt) | 윗줄: 단계 이름(`.headline`, `Ink`). 4pt 아래 아랫줄: 단계의 새 글자(20pt, 글자 사이 한 칸, 일본어 로캘). 글자는 배웠는지와 상관없이 `Ink`. 잠긴 단계만 `InkSecondary` |
| 오른쪽 | 상태 글자(`.subheadline`, `InkSecondary`)와 `chevron.right`. 6.2 표 |
| 누르기 | 행 전체. 잠긴 단계는 `disabled` |

### 6.2 단계 행의 상태

| 상태 | 아이콘 | 오른쪽 | 탭 |
|---|---|---|---|
| 할 차례 | 번호 원(`1.circle.fill`, `2.circle.fill`, `AccentColor`) | `chevron.right`만 | 세션 시작 |
| 하던 중 | 번호 원(`AccentColor`) | "이어서" + `chevron.right` | 2.5의 자리에서 이어서 |
| 완료 | `checkmark.circle.fill`(`Correct`) | "완료" + `chevron.right` | 처음부터 다시 (진행 저장 안 함) |
| 잠김 | `lock.fill`(`InkSecondary`) | 없음 | 반응 없음 |

- 색 밖의 구분: 아이콘 모양(번호, 체크, 자물쇠)과 오른쪽 글자.
- VoiceOver: "1단계 간판, 새 글자 す し, 완료, 다시 하기" / "2단계 메뉴, 새 글자 い か た こ, 할 차례" / "2단계 메뉴, 잠김, 간판을 끝내면 열려요".

### 6.3 퀴즈 행

| 요소 | 값 |
|---|---|
| 높이 | 72pt (단계 행과 같음) |
| 왼쪽 | 상태 아이콘, 28pt 폭. 번호 원은 `3.circle.fill`(visual-rules.md 7.1의 세션 번호) |
| 가운데 | 윗줄: "종합 퀴즈"(`.headline`, `Ink`). 4pt 아래 아랫줄(`.subheadline`): 아래 표 |
| 오른쪽 | 단계 행과 같은 규칙 |
| 누르기 | 행 전체. 잠긴 퀴즈는 `disabled` |

| 상태 | 아이콘 | 아랫줄 | 오른쪽 | 탭 |
|---|---|---|---|---|
| 잠김 | `lock.fill`(`InkSecondary`) | "{단계 b 이름}까지 끝내면 열려요" (`InkSecondary`). 예: 메뉴까지 끝내면 열려요 | 없음 | 반응 없음 |
| 할 차례 | `3.circle.fill`(`AccentColor`) | "글자 {n}자 · 단어 {w}개" + 복습 글자가 있으면 " · 복습 {r}자" (`InkSecondary`, `monospacedDigit`) | `chevron.right` | QI |
| 하던 중 | `3.circle.fill`(`AccentColor`) | 할 차례와 같음 | "이어서" + `chevron.right` | 2.5의 자리에서 이어서 |
| 통과 | `checkmark.circle.fill`(`Correct`) | 할 차례와 같음 | "완료" + `chevron.right` | QI부터 다시 (진행 저장 안 함, 보상 없음) |

- n은 장면 새 글자 수, w는 퀴즈에 나오는 단어 수(QD·QE에 쓰는 서로 다른 단어 수), r은 복습 글자 수. 스시집: "글자 6자 · 단어 3개". 돈카츠집에서 장면 1의 틀린 글자가 2자면 "글자 6자 · 단어 3개 · 복습 2자".
- 단어 유형(QD, QE)이 `quiz-rules.md`에서 빠지면 " · 단어 {w}개"를 쓰지 않는다.
- 아랫줄 폭(375pt): 행 내용 폭 311 − 아이콘 28 − 12 − 오른쪽 약 50 = 약 221pt. 가장 긴 "글자 6자 · 단어 4개 · 복습 3자"가 15pt로 약 205pt. 잠긴 행은 오른쪽이 비어 약 271pt이고, 가장 긴 "개찰구·승강장까지 끝내면 열려요"가 약 230pt.
- 퀴즈 행에는 단어 행을 붙이지 않는다. 퀴즈에 나오는 단어는 위 두 섹션의 목표 단어와 같다.
- VoiceOver: "종합 퀴즈, 글자 6자, 단어 3개, 할 차례" / "종합 퀴즈, 잠김, 메뉴까지 끝내면 열려요" / "종합 퀴즈, 완료, 다시 하기".

### 6.4 목표 단어 행과 못 읽는 단어 줄

배치는 전과 같다.

| 요소 | 높이 | 내용 |
|---|---|---|
| 목표 단어 행 | 52pt (위아래 안쪽 여백 6 + 내용 40) | 왼쪽: 단어(시스템 글꼴 28pt, 일본어 로캘, 글자 사이 2pt, 글자마다 6.5의 모양). 오른쪽(오른쪽 정렬, 두 줄): 뜻(15pt, `InkSecondary`), 상태(13pt). 단어와 오른쪽 묶음 사이 최소 12pt |
| 못 읽는 단어 줄 | 60pt (위아래 안쪽 여백 8 + 내용 44) | 윗줄 "아직 못 읽는 글자가 있는 단어"(13pt, `InkSecondary`). 4pt 아래 단어들을 한 줄로(17pt, 일본어 로캘, 단어 사이 16pt, 글자마다 6.5의 모양). 뜻과 발음 표기는 싣지 않는다 |

- 목표 단어 행의 상태 줄: 배운 글자 수가 전체보다 적으면 "배운 글자 1 / 2"(`InkSecondary`, `monospacedDigit`). 모두 배웠으면 `checkmark`(13pt, `Correct`) + "읽을 수 있어요"(`Ink`).
- 배운 글자 수는 가나 칸 가운데 "배운 글자"(4.4)에 드는 칸의 수. 같은 글자가 두 번 나오면 두 번 센다. 한자 칸은 세지 않는다.
- 잠긴 단계의 단어도 그린다. 앞으로 무엇을 읽게 되는지가 이 화면의 내용이다(PLAN.md 3번 "장면 연결").
- 단어 행과 줄은 누를 수 없다. 발음 소리가 켜져 있어도 재생하지 않는다.
- 못 읽는 단어가 0개인 단계(1a 간판, 6a 등)는 줄을 그리지 않는다.
- 폭(375pt): 행 내용 폭 311pt. 가장 넓은 목표 단어는 4자(28×4 + 2×3 = 118pt) + 12 + "읽을 수 있어요"(약 105pt) = 235pt. 가장 긴 못 읽는 단어 줄은 1b "いくら まぐろ えび いなり"(235pt)와 5b "やきそば はずれ りんごあめ"(236pt). 모두 들어간다. 넘치는 데이터가 생기면 줄을 바꾼다(줄당 +22pt).
- VoiceOver: 목표 단어 행은 "いか, 오징어, 글자 2개 중 1개 배움" 또는 "いか, 오징어, 읽을 수 있어요". 못 읽는 단어 줄은 "아직 못 읽는 글자가 있는 단어, いくら, まぐろ, えび, いなり".

### 6.5 단어 속 글자의 모양

| 글자 상태 | 조건 | 모양 |
|---|---|---|
| 배운 글자 | 4.4의 "배운 글자"에 든다 | `Ink`, 굵게 |
| 안 배운 글자 | 그 밖 (탁음, 한자 포함) | `InkSecondary`, 보통 굵기 |

스시집에서 나올 수 있는 모양(굵게 = 배운 글자, ✓ = 읽을 수 있어요):

| 진행 | すし | いか | たこ | 못 읽는 단어 줄 |
|---|---|---|---|---|
| 처음 | すし 0 / 2 | いか 0 / 2 | たこ 0 / 2 | いくら まぐろ えび いなり |
| 간판에서 す | **す**し 1 / 2 | 0 / 2 | 0 / 2 | 그대로 |
| 간판 끝 | **すし** ✓ | 0 / 2 | 0 / 2 | 그대로 |
| 메뉴에서 い | **すし** ✓ | **い**か 1 / 2 | 0 / 2 | **い**くら まぐろ えび **い**なり |
| 메뉴에서 い か | **すし** ✓ | **いか** ✓ | 0 / 2 | **い**くら まぐろ えび **い**なり |
| 메뉴에서 い か た | **すし** ✓ | **いか** ✓ | **た**こ 1 / 2 | 그대로 |
| 메뉴 배우기 끝 이후 (퀴즈 전후 모두) | **すし** ✓ | **いか** ✓ | **たこ** ✓ | **い**くら まぐろ えび **い**なり |

- 상태가 바뀌는 애니메이션은 없다. 세션을 닫고 돌아왔을 때 바뀐 모양이 그대로 보인다.
- 색만으로 구분하지 않기: 글자는 굵기도 다르고, 행마다 상태 줄의 숫자나 문구가 함께 바뀐다.

| 퀴즈 하던 중 | ✓ | ✓ | ③ 이어서 | 종합 퀴즈 이어서 하기 | 종합 퀴즈 하던 데부터 이어서 해요 |
| 퀴즈 통과 | ✓ | ✓ | ✓ 완료 | 장면 목록으로 | 스시집은 이제 읽을 수 있어요 |

### 6.8 세로 계산과 스크롤

이 화면은 `List`라서 스크롤된다. 아래 주 버튼은 `safeAreaInset`으로 고정이다.

375×667pt, 스시집:

| 영역 | 높이(pt) |
|---|---|
| 상태 바 20 + 내비게이션 바 44 + 큰 제목 52 | 116 |
| 목록 맨 위 여백 | 8 |
| 1a 섹션 (단계 행 72 + 단어 52) | 124 |
| 섹션 간격 | 16 |
| 1b 섹션 (단계 행 72 + 단어 52 × 2 + 못 읽는 단어 줄 60) | 236 |
| 섹션 간격 | 16 |
| 퀴즈 섹션 (퀴즈 행 72) | 72 |
| 아래 고정 영역(8 + 기리 줄 96 + 8 + 56 + 8) | 176 |

- 기리 동행 개정과 크기 개정으로 아래 고정 영역이 72pt에서 176pt로 늘어, 스시집도 375×667pt에서 97pt를 스크롤한다. 목록이 보이는 높이는 375×667pt 375pt, 402×874pt 506pt. 주 버튼과 기리 줄은 고정이라 늘 보인다.

- 화면이 처음 나타날 때 "할 차례" 또는 "하던 중"인 행(단계 행 또는 퀴즈 행)이 보이는 영역 밖이면, 그 행이 목록 맨 위에 오도록 스크롤한다(`ScrollViewReader`, 애니메이션 없이). 다음 세션은 항상 아래 주 버튼으로도 시작할 수 있다.
- 섹션 간격, 큰 제목 영역은 `List`의 기본 배치를 가정한 값이다. 기기에서 확인한다.

### 6.9 전환

- 단계 행, 퀴즈 행, 주 버튼 탭 → 그 세션(fullScreenCover).
- 뒤로 버튼 또는 가장자리 스와이프 → 홈.
- 세션에서 닫고 나오면 이 화면으로 온다. 끝낸 글자, 단계, 퀴즈가 반영돼 있다.

## 7. 단계 세션의 흐름

### 7.1 순서와 항목 수

| 구간 | 화면 | 항목 수 | 1a 간판 | 1b 메뉴 |
|---|---|---|---|---|
| 배우기 | L1 → L2 ×2, 글자마다 | 단계의 새 글자 수 | 2 | 4 |
| 단어 읽기 | W | 단계의 단어 수 (단계 b는 다시 읽기 단어 1개를 더함) | 1 | 7 |
| 완료 | C1 | | | |

- 구간 사이에 안내 화면을 두지 않는다. 배우기의 마지막 글자 L2에서 주 버튼 문구가 "단어 읽기 시작"으로 바뀌는 것으로 다음 할 일을 알린다(9번). 단어 읽기는 W의 기리가 "같이 소리 내어 읽어 봐요"로 할 일을 다시 말한다.
- 퀴즈가 빠져 단계 세션은 전 추정(1a 약 1.3분, 1b 약 3.1분)보다 짧아진다.

### 7.2 상단 바

```
┌──────────────────────────────────────┐
│ ✕   ━━━━━━━━━━━━━━ ─────────── 배우기│
└──────────────────────────────────────┘
          배우기        단어 읽기
```

| 요소 | 값 |
|---|---|
| 닫기 | `xmark`, 44×44pt, 왼쪽 여백 4pt |
| 진행 막대 | 닫기 버튼 오른쪽 8pt부터 구간 이름 왼쪽 8pt까지. 칸 2개를 같은 폭으로, 칸 사이 4pt. 높이 4pt, 모서리 2pt. 빈 부분 `InkSecondary` 0.2, 찬 부분 `AccentColor` |
| 칸이 차는 정도 | 배우기: 끝낸 글자 수 / 새 글자 수. 단어 읽기: 끝낸 단어 수 / 단어 수. 끝낸 구간의 칸은 꽉 찬다 |
| 구간 이름 | 오른쪽, 폭 72pt 오른쪽 정렬, 오른쪽 여백 16pt. "배우기" / "단어 읽기", `.subheadline`, `InkSecondary` |

- 375pt 폭에서 막대 폭은 375 − 4 − 44 − 8 − 8 − 72 − 16 = 223pt, 칸 하나 약 109pt.
- VoiceOver: 막대와 이름을 하나의 요소로 "배우기, 4개 중 1개".

### 7.3 배우기 → 단어 읽기 전환

- 마지막 글자의 2번째 따라 쓰기를 완성하면 주 버튼이 "단어 읽기 시작"으로 활성화된다(그 전 글자들은 "다음").
- 누르면 0.2초 페이드로 W의 첫 단어 읽기 전 상태가 나온다. 상단 바의 배우기 칸이 꽉 차고 구간 이름이 "단어 읽기"로 바뀐다.
- 햅틱은 글자 완성 때의 성공 햅틱 하나뿐이다. 전환에 따로 넣지 않는다.

## 8. L1 배우기: 글자 소개

목적: 새 글자 하나의 모양, 발음, 그 글자가 나오는 단어, 쓰기 포인트를 쓰기 전에 보여 준다. 보기만 한다.

단계의 새 글자 순서(1a: す → し, 1b: い → か → た → こ)로 글자마다 L1 → L2(따라 쓰기 2번)를 반복한다.

```
┌──────────────────────────────────────┐
│ ✕   ━━━━━━━─────── ─────────── 배우기│  상단 바
│                                      │
│ 새 글자                              │
│          ┌──────────────┐            │
│          │      か      │            │  획 데이터로 그린 글자, 200×200pt
│          └──────────────┘            │
│                 ka                   │  발음
│                3획                   │
│ ┌──────────────────────────────────┐ │
│ │ 🍴 스시집 메뉴 단어              │ │  단어 카드
│ │ いか                      오징어 │ │  い 굵게, か 강조
│ │   ▔▔                             │ │
│ └──────────────────────────────────┘ │
│ ┌────────┐ ┌───────────────────────┐ │
│ │        │ │ 1획 끝은 왼쪽으로     │ │  기리 줄 (96pt, 쓰기 포인트)
│ │ 손 들기│◁│ 올려요. 3획은 짧게    │ │
│ │  96pt  │ │ 따로 써요             │ │
│ │        │ └───────────────────────┘ │
│ └────────┘                           │
│ ┌──────────────────────────────────┐ │
│ │             써 보기              │ │  주 버튼
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(7.2).
2. 머리글 "새 글자"(`InkSecondary`).
3. 글자 표시. 200×200pt, 획 데이터(`Kana.strokes`)를 `Ink`로 그린다. 획마다 시작점 번호 원, 고리가 있는 획에는 고리 점선 원. 누르거나 쓸 수 없다. 발음 소리가 켜져 있으면 눌러서 들을 수 있다.
4. 발음(28pt). 그 아래 "{N}획"(`InkSecondary`).
5. 단어 카드(8.1, 8.2). 보여 줄 단어가 없으면 그리지 않는다.
6. 기리 줄. 단어 카드 아래 8pt. 기리 96pt, 손 들기 표정. 줄 높이 96pt(4줄이면 100pt). 말풍선은 그 글자의 쓰기 포인트, 최대 4줄. 쓰기 포인트가 없는 글자는 "번호 순서대로 따라 써 봐요". 전의 쓰기 포인트 상자(전구 아이콘, 노랑 옅은 바탕)는 없앤다(giri-companion.md 3.4).
7. 주 버튼 "써 보기".

### 8.1 단어를 고르는 규칙

글자 하나에 단어 하나. 데이터만으로 정해지므로 처음과 다시 할 때 같은 단어가 나온다.

1. 아는 글자 = 앞 장면들의 새 글자 + 이 장면의 앞 단계 글자 + 이 단계의 새 글자 가운데 지금 글자까지(지금 글자 포함).
2. 후보 = **이 단계의 단어** 가운데 가나 칸에 지금 글자가 있는 단어. 없으면 이 장면의 다른 단계 단어에서 같은 조건으로 찾는다. 탁음 글자는 다른 글자로 본다.
3. 후보마다 점수 = 가나 칸 가운데 아는 글자에 드는 칸 수 ÷ 가나 칸 수.
4. 점수가 가장 높은 후보. 같으면 데이터에서 앞 단어.
5. 후보가 없으면 카드를 그리지 않는다.

스시집의 결과([ ]는 지금 글자, 굵게는 앞에서 배운 글자):

| 글자 | 후보와 점수 | 고른 단어 | 카드의 모양 | 뜻 |
|---|---|---|---|---|
| す | すし 1/2 | すし | [す]し | 초밥 |
| し | すし 2/2 | すし | **す**[し] | 초밥 |
| い | いか 1/2, いくら 1/3, いなり 1/3 | いか | [い]か | 오징어 |
| か | いか 2/2 | いか | **い**[か] | 오징어 |
| た | たこ 1/2 | たこ | [た]こ | 문어 |
| こ | たこ 2/2 | たこ | **た**[こ] | 문어 |

### 8.2 단어 카드의 배치

- 자리: 획 수 줄 아래 12pt, 기리 줄 위 8pt. 좌우 여백 16pt.
- 바탕 `CardBackground`, 모서리 12pt, `Outline` 2pt, 안쪽 여백 12pt.
- 윗줄(18pt): 장면 아이콘(13pt, `InkSecondary`) + 4pt + "{장면} {단계} 단어"(13pt, `InkSecondary`). 예: "스시집 메뉴 단어". 밥집 3장면의 아이콘은 `fork.knife`.
- 4pt 아래 아랫줄(34pt): 왼쪽 단어(28pt, 일본어 로캘, 글자 사이 2pt), 오른쪽 끝 뜻(15pt, `Ink`). 기준선을 맞춘다.
- 카드 높이 80pt.

| 글자 | 조건 | 모양 |
|---|---|---|
| 지금 글자 | 지금 배우는 글자와 같은 칸 | `AccentColor`, 굵게, `Highlight` 0.45 형광펜 바탕, 글자 아래 2pt에 밑줄(2pt) |
| 앞에서 배운 글자 | 8.1의 아는 글자이고 지금 글자가 아님 | `Ink`, 굵게 |
| 안 배운 글자 | 그 밖 | `InkSecondary`, 보통 굵기 |

- 로마자와 단어 읽기는 싣지 않는다. 카드는 누를 수 없다.
- VoiceOver: "스시집 메뉴 단어, いか의 か, 오징어".
- L2에는 카드를 넣지 않는다(캔버스 크기 우선).

### 8.4 스시집의 글자별 내용

| 글자 | 발음 | 획 수 | 쓰기 포인트 문구 (`hiragana_tips.json`, hiragana-allocation.md 10.3) | 추정 줄 수 |

## 9. L2 배우기: 따라 쓰기

목적: 가이드 획 위에 한 획씩 따라 써서 획순과 모양을 익힌다. 글자마다 2번, 두 번 모두 가이드가 보인다.

```
┌──────────────────────────────────────┐
│ ✕   ━━━━━━━─────── ─────────── 배우기│  상단 바
│ か  ka                  따라 쓰기 1/2│  글자·발음, 오른쪽에 회차
│ ┌────────┐ ┌───────────────────────┐ │
│ │        │ │ 1획 끝은 왼쪽으로     │ │  기리 줄 (96pt, 작은 화면 80pt,
│ │  기리  │◁│ 올려요. 3획은 짧게    │ │          쓰기 포인트 최대 4줄)
│ │        │ │ 따로 써요             │ │
│ └────────┘ └───────────────────────┘ │
│  번호가 있는 점에서 시작해 따라 쓰세요│  판정 줄(높이 28pt)
│ ┌──────────────────────────────────┐ │
│ │                                  │ │
│ │          캔버스(정사각형)        │ │  가이드 획, 시작점 번호
│ │                                  │ │
│ └──────────────────────────────────┘ │
│ ┌───────────┐ ┌────────────────────┐ │
│ │ 다시 쓰기 │ │        다음        │ │  보조 버튼 / 주 버튼(완성 전 비활성)
│ └───────────┘ └────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래):

1. 상단 바(7.2).
2. 글자 정보 줄(52pt). 왼쪽 글자(34pt)와 발음, 오른쪽 "따라 쓰기 1/2"(`InkSecondary`). 발음 소리가 켜져 있으면 글자를 눌러 들을 수 있다.
3. 기리 줄. 기리 96pt, 작은 화면(높이 700pt 미만)에서 80pt. 말하기 표정. 말풍선은 L1과 같은 문구, 최대 4줄, 넘치면 끝을 말줄임표. 캔버스가 300pt보다 작아지는 화면에서는 줄 수를 줄이고 그다음 기리를 줄인다(giri-companion.md 2.4.2). 375×667pt에서는 3줄 이하 335pt, 4줄 315pt, 402×874pt에서는 370pt(3번, giri-companion.md 3.5). 전의 쓰기 포인트 상자는 없앤다.
4. 판정 줄. 28pt 고정, 한 줄, 가운데 정렬.
5. 쓰기 캔버스. 좌우 여백 16pt, 정사각형, 아래 버튼 영역 바로 위. 남는 세로 공간은 기리 줄과 판정 줄 사이에 둔다. 캔버스 안의 표시는 visual-rules.md 5번.
6. 아래 버튼 영역. 왼쪽 "다시 쓰기"(112pt), 오른쪽 주 버튼(남는 폭). 사이 12pt.

상태:

| 상태 | 판정 줄 | 캔버스 | 버튼 | 햅틱 | 기리 |
|---|---|---|---|---|---|
| 처음 | "번호가 있는 점에서 시작해 따라 쓰세요" (`InkSecondary`) | 가이드 획 전체, 1번 시작점, 1번 획의 고리 점선 원 | 다시 쓰기·주 버튼 비활성 | 없음 | 말하기, 쓰기 포인트 |
| 쓰는 중 | 직전 문구 유지 | 손가락을 따라 `Ink` 0.6 선 | 변화 없음 | 없음 | 그대로 |
| 획 맞음 | `checkmark.circle.fill` "좋아요" | 맞은 획이 기준 획 모양의 `Ink` 선으로. 다음 획의 시작점 번호와 고리 표시 | 다시 쓰기 활성 | 가볍게 | 그대로 (획마다 반응하지 않음) |
| 획 틀림 | `xmark.circle.fill` + 아래 문구 | 그은 선이 0.9초 `Wrong` 선으로 남았다 사라짐. 고리를 빼먹었으면 그 자리에 `Wrong` 점선 원 | 다시 쓰기 활성 | 오류 | 그대로 |
| 글자 완성 | `checkmark.seal.fill` "완성, 한 번에 썼어요" / "완성, 틀린 획 {N}번" | 모든 획 `Ink`. 표시 없음. 더 그어도 반응 없음 | 주 버튼 활성 | 성공 | 웃음 + 깡충(0.3초). 말풍선 그대로 |

다음 회차나 다음 글자로 넘어가면 기리는 말하기로 돌아온다. "다시 쓰기"를 눌러도 말하기로 돌아온다.

주 버튼 문구:

| 경우 | 문구 |
|---|---|
| 1번째 따라 쓰기 | 다음 |
| 마지막이 아닌 글자의 2번째 | 다음 |
| 단계 마지막 글자(1a는 し, 1b는 こ)의 2번째 | 단어 읽기 시작 |

획이 틀렸을 때의 문구(`StrokeVerdict`, QC에서도 같다):

| 판정 | 문구 |
|---|---|
| `reversed` | 방향이 반대예요 |
| `wrongOrder` | 지금은 {N}번째 획 차례예요 |
| `tooShort` | 너무 짧아요 |
| `missingLoop` | 점선 자리에서 고리를 만들어야 해요 |
| `extraLoop` | 이 획에는 고리가 없어요 |
| `offTarget` | 위치나 모양이 달라요 |

- "다시 쓰기": 이번 회차를 첫 획부터 다시. 틀린 횟수도 0으로. 완성 뒤에도 누를 수 있다.
- 따라 쓰기에서는 틀려도 막지 않고 맞을 때까지 같은 획을 긋는다. 틀린 횟수는 "틀린 글자" 기록에 넣지 않는다.

전환:

- 1번째 완성 후 "다음" → 같은 글자의 2번째. 캔버스가 비워지고 "따라 쓰기 2/2".
- 2번째 완성 후 "다음" → 다음 글자의 L1. 배우기 칸이 한 글자만큼 찬다.
- 마지막 글자의 2번째 완성 후 "단어 읽기 시작" → W의 첫 단어(7.3).

중간에 나갔을 때: 이 글자는 끝내지 않은 것으로 남고, 다시 들어오면 이 글자의 L1부터.

## 10. W 단어 읽기

목적: 이 단계에서 실제로 보는 단어를 배운 글자로 읽어 본다. 읽고 나서 스스로 확인하고, 채점하지 않는다. 확인하면 기리가 그 단어가 무엇인지, 어디에 쓰여 있는지 말해 주고, 그림이 있는 단어는 그림이 나타난다.

단어 순서: (단계 b만) 단계 a의 다시 읽기 단어 하나(quiz-rules.md 9.2) → 이 단계의 목표 단어(데이터 순서) → 못 읽는 단어(데이터 순서). S의 그 단계 섹션과 같은 순서다.

- 1a: すし
- 1b: すし(다시 읽기) → いか → たこ → いくら → まぐろ → えび → いなり

```
읽기 전                                     확인 후

│                                      │   │                                      │
│        ma          gu    ro          │   │        ma          gu    ro          │  발음 표기(작게)
│        ま          ぐ    ろ          │   │        ま          ぐ    ろ          │  단어(크게)
│                                      │   │               maguro                 │  읽기
│                                      │   │                참치                  │  뜻
│ ┌────────┐                           │   │ ┌────────┐ ┌───────────────────────┐ │
│ │        │ ┌──────────────────────┐  │   │ │        │◁│ (단어 설명, planner   │ │  기리 줄 (96pt,
│ │  생각  │◁│ 같이 소리 내어 읽어  │  │   │ │ 손 들기│ │  작성, 40자 이하,     │ │   높이 100pt 고정)
```

구성 요소(위에서 아래):

1. 상단 바(7.2).
2. 단어. 상단 바 아래 24pt. 글자마다 두 칸을 쌓는다: 위 발음 표기(로마자 15pt, `InkSecondary`, 높이 20pt), 아래 글자(56pt). 글자 칸 폭 64pt, 사이 4pt. 5자까지 336pt로 375pt에 들어간다. 6자 이상은 글자 48pt·칸 52pt로 줄이고, 그래도 넘치면 두 줄. 스시집의 가장 긴 단어는 3자(いくら, まぐろ, いなり). 이 단어 블록은 퀴즈 QD에서도 그대로 쓴다.
3. 확인 후에만 보이는 줄: 단어 아래 16pt에 읽기(로마자 22pt, 최소 높이 44pt), 4pt 아래 뜻(17pt, 22pt). 읽기 전에도 자리(70pt)를 비워 둔다.
4. 기리 줄. 뜻 아래 16pt. 기리 96pt, 말풍선 최대 읽기 전 3줄·확인 후 4줄, 줄 높이 100pt 고정(확인할 때 기리가 움직이지 않게). 읽기 전에는 생각 표정과 안내, 확인 후에는 손 들기 표정과 단어 설명(아래 표, giri-companion.md 3.6). **W에서는 기리가 숨쉬지 않는다**(그림이 있든 없든. W의 반복 움직임 자리는 단어 그림이 쓴다, word-art.md 6.4).
5. 그림 영역. 기리 줄 아래 끝 + 16pt부터 아래 버튼 영역 위 끝 − 16pt까지. 그림은 이 영역의 가운데, 한 변 S = min(176, 영역 높이)pt의 정사각, 투명 바탕 그대로(카드·테두리 없음). S가 96pt 밑이면 그리지 않는다. **"읽기 확인" 뒤에만** 읽기·뜻과 같은 0.2초 페이드로 나타나고, 확인 전에는 빈 자리다(틀·실루엣 없음). 그림이 없는 단어와 아직 그림이 생성되지 않은 단어는 빈 자리 그대로다. 움직이는 그림은 확인 0.25초 뒤 Lottie 재생을 시작한다. 누를 수 없고 VoiceOver에서 읽지 않는다. 자세한 규칙은 word-art.md 2~4, 6, 8번.
6. 주 버튼. 읽기 전 "읽기 확인", 확인 후 "다음", 마지막 단어의 확인 후 "완료".

- 전의 맨 위 안내 "소리 내어 읽어 보세요"와 확인 후의 보조 설명 줄(`note`, 15pt)은 없앤다. 안내는 기리가 읽기 전에 말하고, 보조 설명은 기리의 단어 설명으로 옮긴다. 붙여 쓴 한자의 "외우지 않아도 돼요"(PLAN.md 3번)도 기리 설명에 들어간다.

기리 말풍선:

| 상태 | 표정 | 말풍선 (위 줄부터 먼저 맞는 것 하나) |
|---|---|---|
| 읽기 전, 단계 b 맨 앞의 다시 읽기 단어 | 생각 | {단계 a}에서 본 단어예요. 다시 읽어 봐요 |
| 읽기 전, 이 세션에서 발음 표기가 붙은 첫 단어 | 생각 | 위에 작게 쓴 건 아직 안 배운 글자예요 |
| 읽기 전, 붙여 쓴 한자가 있는 단어 | 생각 | 한자는 위에 쓴 발음으로 읽어요 |
| 읽기 전, 그 밖 | 생각 | 같이 소리 내어 읽어 봐요 |
| 확인 후 | 손 들기 | 단어의 기리 설명(planner, 40자 이하, 2문장 이하). 비어 있으면 "{장면} {단계}에서 볼 수 있어요" |

- 다시 읽기 단어가 앞 단계의 단어라는 것은 위 첫 줄의 문구로만 알린다. 단어 블록에 따로 표시하지 않는다. 다시 읽기 단어도 상단 바의 단어 수와 C1의 "단어 {N}개"에 센다.
- 375×667pt 세로: 상단 바 20~64, 단어 88~172, 읽기 188~232, 뜻 236~258, 기리 줄 274~374, 그림 영역 390~575(그림 176pt, 394.5~570.5), 아래 버튼 영역 591~667. 두 줄로 쓰는 긴 단어(くつをぬいでください, +72pt)에서도 기리 줄 아래 끝 y 446으로 들어가고, 그림은 113pt(462~575)로 줄어든다. 402×874pt: 기리 줄 316~416, 그림 영역 432~748(그림 176pt, 502~678), 아래 버튼 영역 764~840. 다른 기기와 큰 글자 크기는 word-art.md 2.3, 2.4.

발음 표기 규칙:

- "이 단계까지의 글자"(4.4)에는 붙이지 않는다. 위 칸은 비워 두되 높이는 유지한다.
- 그 밖의 글자, 탁음·반탁음 글자, 한자 칸에는 붙인다.
- 읽기 전부터 보인다.

상태:

| 상태 | 화면 | 기리 | 주 버튼 | 햅틱 |
|---|---|---|---|---|
| 읽기 전 | 단어와 발음 표기. 그림 영역은 비어 있음 | 생각, 읽기 전 안내. 숨쉬지 않음 | 읽기 확인 | 없음 |

VoiceOver: 확인하면 "{읽기}, {뜻}. {기리 설명}"을 알림 하나로 읽는다. 단어 그림은 읽지 않는다(장식, word-art.md 8번).

발음 소리: 켜져 있으면 글자를 누를 때 그 글자, 확인 후 읽기 줄을 누르면 단어 전체를 읽는다. 읽기 전에도 막지 않는다.

전환:

- "읽기 확인" → 확인 후 상태. "다음" → 다음 단어.
- 마지막 단어에서 "완료" → 단계 완료와 보상을 저장하고 C1(11번). 단계 a·b, 처음·다시 모두 C1이다.

중간에 나갔을 때: 확인 후 "다음"을 누른 단어까지 저장한다. 다시 들어오면 그다음 단어의 읽기 전 상태부터.

## 11. C1 완료 (단계 완료, 다시 한 퀴즈)

목적: 세션 하나가 끝났음을 알리고, 다음 세션으로 바로 이어 가게 한다. 점수와 통계는 싣지 않는다.

나오는 때:

| 경우 | 언제 |
|---|---|
| 단계 a 처음 끝냄 | W의 마지막 "완료" |
| 단계 b 처음 끝냄 | W의 마지막 "완료" |
| 끝낸 단계를 다시 함 | W의 마지막 "완료" |
| 통과한 퀴즈를 다시 함 | 퀴즈의 마지막 문항 뒤 "완료" (12.6) |

퀴즈를 처음 통과하면 C1이 아니라 C2(14번)다.

구성 요소(위에서 아래). 상단 바는 없다.

1. 기리 줄. 기리(웃는 표정, 120×120pt)와 체크 배지(`checkmark.circle.fill` 32pt, `Correct`). 모양, 등장 움직임은 visual-rules.md 7.2와 reward-flow.md 7번. 기리는 화면 왼쪽 여백 16pt에 두고(기리 동행 개정 전에는 가운데), 오른쪽에 말풍선(최대 3줄, 줄 높이는 120pt 그대로)을 둔다. 말풍선은 등장 시작 0.15초 뒤에 뜬다. 문구는 아래 표, 치수는 giri-companion.md 3.9. 기리 아래 끝을 내용 영역의 위에서 3분의 1 지점에 둔다(위 여백 = 내용 ÷ 3 − 120, 최소 24pt).
2. 24pt 아래 제목(`.title2` 굵게), 8pt 아래 요약 한 줄(`.body`, `InkSecondary`). 문구는 아래 표.
3. 24pt 아래 글자 줄(34pt, 글자 사이 16pt). 단계는 그 단계의 새 글자, 다시 한 퀴즈는 장면의 새 글자. 단계 C1에는 글자 밑 점이 없다(단계에 퀴즈가 없다). 다시 한 퀴즈의 C1만 이번 퀴즈에서 틀린 글자 밑에 점(지름 6pt, `HighlightStrong`, 글자 아래 4pt)을 찍고, 16pt 아래 안내 한 줄(`.subheadline`, `Ink`) "{글자들}를 이번에 헷갈렸어요"를 둔다. 틀린 글자가 없으면 점과 줄이 없다.
4. 24pt 아래 목표 단어 묶음: "이제 읽을 수 있는 단어"(15pt, `InkSecondary`) + 8pt + 목표 단어를 한 줄로(22pt, 일본어 로캘, `Ink` 굵게, 단어 사이 16pt). 단계는 단계의 목표 단어, 다시 한 퀴즈는 장면의 목표 단어. 누를 수 없다. 넘치면 줄을 바꾼다.
5. (처음 끝낸 세션만) 24pt 아래 받은 엔 줄. reward-flow.md 5번의 부품 그대로. 다시 한 세션에는 그리지 않는다.
6. 버튼 영역: 주 버튼 + 4pt + 글자 버튼 "여기까지 하기"(`.headline`, `AccentColor`, 높이 44pt). 다시 한 세션은 글자 버튼이 없다.

문구:

| 경우 | 기리 말풍선 | 제목 | 요약 | 주 버튼 | 글자 버튼 |
|---|---|---|---|---|---|
| 단계 a 처음 끝냄 | {단계 a} 다 읽었어요. 다음은 {단계 b}예요 | 스시집 간판 완료 | 새 글자 {n}자를 배우고 단어 {N}개를 읽었어요 | {단계 b} 시작 (메뉴 시작) | 여기까지 하기 |
| 단계 b 처음 끝냄 | 이제 종합 퀴즈만 남았어요 | 스시집 메뉴 완료 | 같은 형식 | 종합 퀴즈 시작 | 여기까지 하기 |
| 끝낸 단계를 다시 함 | 한 번 더 읽으니 눈에 잘 들어와요 | 같은 형식 | 같은 형식 | 장면으로 돌아가기 | 없음 |
| 통과한 퀴즈를 다시 함 | 다시 해도 다 읽었네요 | 스시집 종합 퀴즈 완료 | {N}문항을 모두 맞혔어요 | 장면으로 돌아가기 | 없음 |

- N(단어 수)에는 단계 b의 다시 읽기 단어를 센다(10번).

- 단계 b를 처음 끝냈을 때 퀴즈 바로 앞이라도 C1을 보여 준다. 단계 b의 받은 엔(100엔)과 목표 단어를 알리는 자리이고, "여기까지 하기"로 퀴즈 전에 쉬어 갈 수 있게 한다. 퀴즈는 20문항 안팎이라 단계 b에 바로 붙이면 한 번에 5분을 넘긴다.
- 단계 b를 처음 끝냈는데 퀴즈를 이미 통과한 경우는 없다(퀴즈는 단계 b 뒤에 열린다).

375×667pt 세로 계산(처음 끝낸 단계, 버튼 영역 12 + 56 + 4 + 44 + 8 = 124, 내용 영역 523pt):

| 영역 | 높이(pt) |
|---|---|
| 위 여백 (523 ÷ 3 − 120) | 54 |
| 캐릭터 | 120 |
| 간격 24 + 제목 28 + 간격 8 + 요약 22 | 82 |
| 간격 24 + 글자 줄 34 | 58 |
| 간격 24 + 목표 단어 묶음(20 + 8 + 28) | 80 |
| 간격 24 + 받은 엔 줄 22 | 46 |
| 합계 | 440 (사용 가능 523) |

다시 한 퀴즈(버튼 영역 76, 내용 571pt): 위 여백 70 + 120 + 82 + 58 + 점 10 + 안내 줄 36(16 + 20) + 80 = 456pt로 들어간다. 받은 엔 줄은 없다.

- 기리 줄은 높이 120pt 그대로라 위 계산은 기리 동행 개정과 크기 개정(2026-11-15, C1·C2는 크기를 바꾸지 않음) 뒤에도 같다. 체크 배지(x 101~139pt)와 말풍선 몸통(x 148pt부터)은 겹치지 않는다.
- 요약 "새 글자 4자를 배우고 단어 7개를 읽었어요"는 17pt로 약 290pt라 343pt 안에 한 줄로 들어간다.
- 목표 단어가 가장 많은 단계(6a 4개, 290pt)도 한 줄이다. 다시 한 퀴즈의 장면 목표 단어가 두 줄이 되는 장면(이자카야 7개)은 +36pt로 492pt, 여전히 들어간다.

상태: 나타날 때 성공 햅틱 한 번과 캐릭터 등장 움직임(visual-rules.md 6.2). 그 밖의 상태는 없다.

전환:

- "{단계 b} 시작" → 같은 덮개 안에서 단계 b의 첫 글자 L1. 진행 막대가 비워지고 새로 시작한다.
- "종합 퀴즈 시작" → 같은 덮개 안에서 퀴즈 세션의 QI. 상단 바가 퀴즈 막대(12.3)로 바뀐다.
- "여기까지 하기", "장면으로 돌아가기" → 덮개를 닫고 S로.

중간에 나갔을 때: 세션 완료와 보상 지급은 이 화면이 뜨기 전에 저장한다. 이 화면을 다시 보여 주지 않는다.

## 12. 종합 퀴즈 세션의 흐름

### 12.1 무엇이 나오나

| 재료 | 스시집 | 쓰는 유형 |
|---|---|---|
| 장면의 새 글자 전부 | す し い か た こ (6자) | QA, QB, QC |
| 장면의 목표 단어 (4.4) | すし, いか, たこ | QD, QE |
| 복습 글자: 앞 장면들의 퀴즈에서 틀린 글자 | 장면 1은 없음. 장면 2부터 | QA, QB, QC (어느 유형에 넣을지는 quiz-rules.md) |

- 단어의 목록과 수, 복습 글자 수(PLAN.md 8번, 임시 최대 3자), 유형별 문항 수는 `quiz-rules.md`가 정한다. 화면은 그 값을 받아 그린다.
- 오답 선택지를 고르는 규칙도 `quiz-rules.md`가 정한다. 화면이 요구하는 조건은 13.1에 있다.
- 틀린 글자 기록(다음 장면 퀴즈에 섞는 대상)의 기준도 `quiz-rules.md`가 정한다. 그 문서가 오기 전의 기본값: QA·QB에서 그 글자를 묻는 문항을 틀렸거나, QC에서 그 글자에 가이드를 본 경우. QD·QE의 오답은 글자로 기록하지 않는다.

### 12.2 부(유형 묶음)와 순서

- 문항은 유형마다 한 부로 묶는다. 한 부 안에서는 같은 유형만 연달아 나온다. 같은 손 동작(2×2 칸, 한 줄 목록, 캔버스)이 몇 문항 이어져야 흔들리는 환경에서 보지 않고 누를 자리를 익힌다. 유형이 문항마다 바뀌면 문항마다 질문을 다시 읽어야 한다.
- 부의 순서는 `quiz-rules.md`를 따른다. 정하지 않으면 아래 순서다. 고르기 → 쓰기 → 고르기로 손 동작이 바뀌어 20문항 안팎이 한 가지 동작으로 이어지지 않는다.

| 순서 | 유형 | 화면 | 부 이름 (화면 문구) | 질문 |
|---|---|---|---|---|
| 1 | (가) 글자 보고 발음 고르기 | QA | 발음 고르기 | 이 글자의 발음은? |
| 2 | (나) 발음 보고 글자 고르기 | QB | 글자 고르기 | 이 발음의 글자는? |
| 3 | (다) 기억으로 쓰기 | QC | 기억으로 쓰기 | 이 발음의 글자를 쓰세요 |
| 4 | (라) 단어 보고 읽기 고르기 | QD | 읽기 고르기 | 이 단어의 읽기는? |
| 5 | (마) 단어 보고 뜻 고르기 | QE | 뜻 고르기 | 이 단어의 뜻은? |

- 부 안의 문항 순서는 섞는다. 같은 글자가 앞 부의 마지막 문항과 다음 부의 첫 문항으로 연달아 나오지 않게 한다.
- `quiz-rules.md`가 빼는 유형은 부가 없다. 부의 수는 1~5개다.

### 12.3 상단 바

```
┌──────────────────────────────────────┐
│ ✕   ━━━━ ━━── ──── ──── ────   퀴즈  │
└──────────────────────────────────────┘
      발음 글자 쓰기 읽기  뜻
```

| 요소 | 값 |
|---|---|
| 닫기 | 7.2와 같음 |
| 진행 막대 | 부의 수만큼 칸을 같은 폭으로, 칸 사이 4pt. 높이·색·모서리는 7.2와 같음 |
| 칸이 차는 정도 | 그 부에서 맞힌 문항 수 / 그 부의 문항 수. 다시 내는 문항은 분모를 늘리지 않는다. 끝낸 부의 칸은 꽉 찬다 |
| 구간 이름 | "퀴즈" 하나로 둔다. 부 이름은 내용 영역의 부 머리 줄(12.4)이 보여 준다. 72pt 칸에 "기억으로 쓰기"가 들어가지 않기 때문이다 |

- 375pt 폭에서 막대 223pt, 부 5개면 칸 하나 약 41pt, 부 3개면 약 72pt.
- QI에서는 모든 칸이 비어 있다.
- VoiceOver: "퀴즈, 24개 중 7개, 글자 고르기".

### 12.4 부 머리 줄: 유형이 바뀌는 지점과 부 안의 진행

모든 문항 화면(QA~QE)의 상단 바 바로 아래에 한 줄을 둔다. 높이 18pt 고정(문구가 바뀌어도 아래가 움직이지 않게), 위 여백 8pt, 좌우 여백 20pt, 왼쪽 정렬, `.footnote`.

| 경우 | 문구 | 모양 |
|---|---|---|
| 부의 첫 문항 (두 번째 부부터) | 여기부터 {부 이름} {m}문항 | `Ink` 굵게 |
| 부의 첫 문항 (첫 부) | {부 이름} 1 / {m} | `InkSecondary`, 숫자 `monospacedDigit` |
| 부의 나머지 문항 | {부 이름} {k} / {m} | `InkSecondary`, 숫자 `monospacedDigit` |
| 다시 내는 문항 | `arrow.counterclockwise` + 4pt + "다시 풀기 · {남은 수}개 남음" | `InkSecondary`. 아이콘도 `InkSecondary` |

- k는 지금 문항이 그 부에서 몇 번째인지(첫 차례 기준), m은 그 부의 문항 수.
- 유형이 바뀌는 지점은 세 가지가 함께 알린다: 부 머리 줄이 굵은 "여기부터 기억으로 쓰기 6문항"으로 바뀌고, 질문 문구가 바뀌고, 아래 선택지(또는 캔버스)의 모양이 바뀐다. 상단 바에서도 다음 칸이 차기 시작한다. 부 사이에 안내 화면을 따로 두지 않는다. 탭을 늘리지 않고 20문항 안팎을 짧은 묶음(부당 3~9문항)으로 나눠 보이게 하는 것이 목적이다.
- VoiceOver: 부의 첫 문항이 나타날 때 "여기부터 기억으로 쓰기, 6문항"을 알림으로 읽는다.

```
│ │  (기리)  │◁│ 차례예요. 헷갈린 건 │ │          말풍선 최대 4줄)

│ │          │ └─────────────────────┘ │
```

구성 요소(위에서 아래):

1. 상단 바(12.3). 칸은 모두 비어 있다.
2. 기리 줄. 상단 바 아래 16pt. 기리 120pt(말하기, 입은 아이템, 배경 제외), 말풍선 최대 4줄, 줄 높이 120pt. 문구는 처음 "{장면} 마지막 차례예요. 헷갈린 건 한 번 더 나와요", 통과한 퀴즈를 다시 할 때 "한 번 더 같이 확인해 봐요"(giri-companion.md 3.7).
3. 16pt 아래 제목 "{장면} 종합 퀴즈"(`.title2` 굵게, 가운데).
4. (기리 동행 개정으로 뺌) 설명 "배운 글자와 단어를 섞어 물어요". 기리의 말과 아래 부 목록이 대신한다.
5. 24pt 아래 장면 글자 줄(34pt, 글자 사이 16pt, `Ink`, 일본어 로캘). 6자 폭 34 × 6 + 16 × 5 = 284pt.
6. 24pt 아래 부 목록. 부마다 한 줄 28pt, 좌우 여백 20pt. 왼쪽 부 이름(`.body`, `Ink`), 오른쪽 "{m}문항"(`.body.monospacedDigit()`, `InkSecondary`). 12.2의 순서대로. 누를 수 없다.
7. (복습 글자가 있을 때만) 16pt 아래 "지난 장면에서 헷갈린 글자 {글자들}도 나와요"(`.subheadline`, `Ink`, 가운데).
8. 8pt 아래 "중간에 나가도 이어서 할 수 있어요"(`.footnote`, `InkSecondary`, 가운데). 20문항 안팎이 한 번에 끝나지 않아도 된다는 것을 알린다.
9. 아래 버튼 영역: 주 버튼 "퀴즈 시작". 보조 버튼 없음.

- 375×667pt: 내용 영역 527pt. 16 + 120 + 16 + 28 + 24 + 34 + 24 + 84(부 3개) + 16 + 20 + 8 + 18 = 408pt로 들어간다(부 5개여도 464pt). 큰 글자 크기에서 넘치면 내용 영역만 스크롤된다.
- 복습 줄 폭: "지난 장면에서 헷갈린 글자 た, こ, す도 나와요" 15pt로 약 300pt, 343pt 안에 한 줄.
- 햅틱 없음. 기리는 숨쉬기만 한다(giri-companion.md 5.2). 등장 움직임은 C1·C2에만 있다.
- 끝낸 퀴즈를 다시 할 때도 QI를 보여 준다.

전환: "퀴즈 시작" → 첫 부의 첫 문항.

### 12.6 틀린 문항을 다시 내기

- 한 부에서 틀린 문항은 그 부의 첫 차례 문항이 모두 끝난 뒤 이어서 다시 낸다. 다음 부로 넘어가기 전이다. 같은 손 동작이 이어지는 동안 다시 풀게 한다.
- 다시 낸 문항도 틀리면 그 부의 다시 풀기 끝에 또 낸다. 그 부의 모든 문항을 맞혀야 다음 부로 간다(PLAN.md 3번 "틀린 문항은 끝에 다시 내고 다 맞혀야 끝난다").
- 다시 낼 때 고르기 유형은 선택지를 새로 섞는다. 같은 자리를 눌러 맞히지 않게 한다.
- QC를 다시 낼 때는 가이드가 꺼진 처음 상태부터다.
- 표시: 부 머리 줄이 "다시 풀기 · {남은 수}개 남음"(12.4). 상단 바의 칸은 맞힐 때 찬다.
- 마지막 부의 마지막 문항을 맞히면(다시 풀기 포함) 주 버튼이 "다음" 대신 "완료"가 된다. "완료" → 퀴즈 통과와 보상을 저장하고 처음 통과면 C2, 다시 한 퀴즈면 C1.

### 12.7 문항 수와 시간 (예시)

`quiz-rules.md`가 오기 전, 화면을 확인하려고 둔 예시값이다. 값은 그 문서를 따른다.

| 장면 | 발음 고르기 | 글자 고르기 | 기억으로 쓰기 | 읽기 고르기 | 뜻 고르기 | 합계 |
|---|---|---|---|---|---|---|
| 1 스시집 (복습 없음) | 6 | 6 | 6 | 3 | 3 | 24 |
| 2 돈카츠집 (복습 2자, 고르기 두 부에 섞음) | 8 | 8 | 6 | 3 | 3 | 28 |

## 13. 퀴즈 문항 화면

### 13.1 공통

화면 뼈대(위에서 아래): 상단 바(12.3) → 부 머리 줄(12.4) → 기리 줄(질문) → 문제(글자, 발음, 단어) → (남는 공간) → 판정 줄 → 답하는 곳(선택지 또는 캔버스) → 아래 버튼 영역.

| 요소 | 값 |
|---|---|
| 기리 줄 (전의 질문 줄 자리) | 부 머리 줄 아래 8pt. 기리 96pt, 높이 96pt 고정(말풍선 최대 3줄 80pt가 기리 높이 안에 들어감. QC는 걸침 배치, 13.4). 질문을 기리가 말한다. 문구와 상태별 표정·말풍선은 아래 "기리" 표와 giri-companion.md 3.8, 3.11 |
| 판정 줄 | 28pt 고정, 가운데 정렬, `.subheadline`. 아이콘은 문구 왼쪽 4pt. 문구는 `Ink` |
| 답하는 곳 | 아래 버튼 영역 바로 위(사이는 버튼 영역 위 여백 12pt). 판정 줄은 답하는 곳 위 12pt. 남는 공간은 문제와 판정 줄 사이에 둔다 |
| 아래 버튼 영역 | 고르기 유형: 주 버튼 "다음"(답하기 전 비활성) 하나. QC: 보조 "가이드 보기" + 주 "다음". 마지막 문항은 "완료"(12.6) |
| 넘김 | 자동으로 넘기지 않는다. 맞아도 "다음"을 누른다. 결과를 보고 넘기게 하고, 흔들리는 환경에서 다음 문항 선택지를 잘못 누르는 일을 막는다 |

선택지 칸의 모양(모든 고르기 유형): 바탕 `CardBackground`, 모서리 16pt, `Outline` 2pt, 좌우 여백 16pt, 칸 사이 12pt.

고르기 유형의 상태(QA, QB, QD, QE 같은 규칙):

| 상태 | 판정 줄 | 선택지 | 주 버튼 | 햅틱 |
|---|---|---|---|---|
| 처음 | 비어 있음 | 네 칸 기본 모양, 누를 수 있음 | 다음 비활성 | 없음 |
| 정답 | `checkmark.circle.fill`(`Correct`) "맞아요" | 고른 칸 `Correct` 3pt 외곽선 + 오른쪽 위 `checkmark.circle.fill` 20pt. 나머지 0.4. 더 누를 수 없음. 유형별 "답한 뒤 보이는 것"이 나타남 | 다음 활성 | 성공 |
| 오답 | `xmark.circle.fill`(`Wrong`) "정답은 {정답}예요" | 고른 칸 `Wrong` 3pt + `xmark.circle.fill`. 정답 칸 `Correct` 3pt + `checkmark.circle.fill`. 나머지 0.4. 유형별 "답한 뒤 보이는 것"이 나타남 | 다음 활성 | 오류 |
| 다시 내는 문항 | 처음과 같음. 부 머리 줄만 다름(12.4) | 새로 섞은 네 칸 | 다음 비활성 | 없음 |

- 색 밖의 구분: 외곽선 굵기(2pt → 3pt), 체크·엑스 아이콘 모양, 판정 문구, 햅틱.

기리 (QA, QD, QC 공통. QC의 쓰기 상태는 13.4):

| 상태 | 표정 | 말풍선 |
|---|---|---|
| 처음 | 생각 | 질문: QA "이 글자, 어떻게 읽을까요?", QD "이 단어, 어떻게 읽을까요?", QC "이 발음의 글자를 써 봐요" |
| 부의 첫 문항 (2부, 3부) | 생각 | QD "이번엔 단어예요. 어떻게 읽을까요?", QC "이번엔 기억으로 써 봐요" |
| 다시 내는 문항 | 생각 | QA·QD "한 번 더 봐요. 어떻게 읽을까요?", QC "한 번 더 기억으로 써 봐요" |
| 정답 | 웃음 + 깡충(0.3초) | 0.15초에 사라짐. 자리는 남는다 |
| 오답 | 아쉬움 | 헷갈린 점을 짚는 말. 고른 답이 정답과 헷갈리는 쌍이면 쌍의 짚는 말(planner), 아니면 QA "{고른 로마자}는 {그 글자}예요. {정답 글자}는 {정답}로 읽어요", QD "이 단어의 {원래 글자}는 {로마자}예요"(giri-companion.md 3.8) |

- 답하기 전의 표정은 늘 생각이다. 기리는 답을 암시하지 않는다.
- QB, QE는 quiz-rules.md에서 쓰지 않는 유형이다. 다시 쓰게 되면 같은 기리 줄을 질문 줄 자리에 두고, 질문 문구만 기리 말투로 바꾼다.
- 판정 줄은 그대로다. 기리의 말은 판정 줄의 "정답은 ta예요"를 되풀이하지 않고 왜 헷갈렸는지를 더한다.
- VoiceOver: 오답이면 "정답은 ta예요. {기리의 짚는 말}"을 알림 하나로 읽는다. 문항이 바뀌면 초점을 기리 말풍선(질문)으로 옮긴다.
- 오답 문구의 조사: 정답이 받침 없는 말로 끝나면 "예요", 받침이 있으면 "이에요". 로마자는 n으로 끝나면 "이에요"(정답은 n이에요, 정답은 katsudon이에요), 가나는 ん으로 끝나면 "이에요", 한국어 뜻은 받침 판별 함수로 고른다(정답은 오징어예요, 정답은 돈가스덮밥이에요).
- 선택지 조건(오답을 고르는 규칙은 `quiz-rules.md`): 네 칸은 모두 다른 값이다. 같은 로마자, 같은 뜻이 두 번 나오지 않는다. 네 칸의 자리는 문항마다 섞는다.
- 답하고 "다음"을 누르기 전에 나가도 그 문항의 결과는 저장한다. 답하기 전이면 그 문항이 다시 나온다.

### 13.2 QA 발음 고르기 (유형 가)

목적: 글자를 보고 발음을 고른다.

```
┌──────────────────────────────────────┐
│ ✕   ━━── ──── ──── ──── ────   퀴즈  │  상단 바
│ 발음 고르기 3 / 6                    │  부 머리 줄
│ ┌────────┐                           │
│ │        │ ┌───────────────────────┐ │
│ │  생각  │◁│ 이 글자, 어떻게       │ │  기리 줄 (96pt 고정)
│ │  96pt  │ │ 읽을까요?             │ │
│ │        │ └───────────────────────┘ │
│ └────────┘                           │
│          ┌──────────────┐            │
│          │      た      │            │  획 데이터로 그린 글자, 160×160pt
│          └──────────────┘            │
│                                      │
│                                      │  판정 줄(28pt)
│ ┌───────────────┐ ┌───────────────┐  │
│ │      ka       │ │      ta       │  │  선택지 2×2, 칸 높이 72pt
│ └───────────────┘ └───────────────┘  │
│ ┌───────────────┐ ┌───────────────┐  │
│ │      i        │ │      ko       │  │
│ └───────────────┘ └───────────────┘  │
│ ┌──────────────────────────────────┐ │
│ │               다음               │ │  주 버튼(답하기 전 비활성)
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

- 문제: 글자 표시 160×160pt, 기리 줄 아래 8pt, 가운데. 획 데이터로 그리고 번호·고리 표시는 없다.
- 선택지: 2열 2행, 칸 높이 72pt, 칸 폭 (화면 폭 − 32 − 12) ÷ 2. 로마자 `.title2`.
- 답한 뒤 보이는 것: 없음(문제의 글자와 정답 칸이 이미 짝을 보여 준다).
- 발음 소리: 답하기 전에는 재생하지 않고 스피커 아이콘도 없다. 답한 뒤 글자 표시에 나타난다.
- 문구 예: 오답 "정답은 ta예요". 이때 기리: ko를 골랐으면 "ko는 こ예요. た는 ta로 읽어요", na를 골랐으면 た/な 쌍의 짚는 말(planner).

### 13.3 QB 글자 고르기 (유형 나)

목적: 발음을 보고 네 글자 가운데 맞는 글자를 고른다. 비슷한 모양(い/り, た/な 등)을 구별하게 한다.

```
답한 뒤 (오답)
┌──────────────────────────────────────┐
│ ✕   ━━━━ ━━── ──── ──── ────   퀴즈  │
│ 여기부터 글자 고르기 6문항           │  부 머리 줄 (부의 첫 문항, 굵게)
│ 이 발음의 글자는?                    │  질문
│                 ka                   │  발음 48pt
│                                      │
│     ✕  정답은 か예요                 │  판정 줄
│ ┌───────────────┐ ┌───────────────┐  │
│ │      た     ✕ │ │      か     ✓ │  │  선택지 2×2, 칸 높이 88pt
│ │      ta       │ │      ka       │  │  답한 뒤 로마자
│ └───────────────┘ └───────────────┘  │
│ ┌───────────────┐ ┌───────────────┐  │
│ │      こ       │ │      い       │  │
│ │      ko       │ │      i        │  │
│ └───────────────┘ └───────────────┘  │
│ ┌──────────────────────────────────┐ │
│ │               다음               │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

- 문제: 로마자 `.system(size: 48, design: .rounded)`, 줄 높이 58pt, 기리 줄 아래 8pt, 가운데. 발음 소리가 켜져 있으면 눌러서 들을 수 있다(소리가 로마자와 같은 정보라 답을 더 알려 주지 않는다).
- 선택지: 2열 2행, 칸 높이 **88pt**. 칸 안: 위 여백 8pt, 획 데이터로 그린 글자 56×56pt(바탕 없음, 번호·고리 없음, 선 굵기는 좌표계 5를 그대로 비례), 로마자 줄 18pt(`.footnote`, `InkSecondary`, 답하기 전에는 비워 둠), 아래 여백 6pt.
- 글자를 시스템 글꼴이 아니라 획 데이터로 그리는 이유: 비슷한 글자를 구별하는 문항이라 교과서체에 가까운 모양이 중요하다(visual-rules.md 2.3). 56pt에서 선 굵기 약 2.6pt.
- 답한 뒤 보이는 것: 네 칸 모두 글자 아래에 로마자가 나타난다. 고른 오답 글자가 무슨 발음인지 바로 보인다. 흐려진 칸(0.4)의 로마자도 함께 흐려진다.
- 문구 예: 오답 "정답은 か예요", ん이면 "정답은 ん이에요".
- VoiceOver: 칸마다 "선택지 1, た"처럼 글자를 일본어로 읽는다. 글자를 소리로 읽으면 발음이 드러나 문항이 쉬워지지만, 모양을 보고 고르는 유형이라 VoiceOver로는 다른 방법이 없다. 그대로 받아들인다. 답한 뒤에는 "선택지 1, た, ta, 고른 답, 오답"처럼 결과를 붙인다.

### 13.4 QC 기억으로 쓰기 (유형 다)

목적: 발음만 보고 가이드 없이 글자를 쓴다.

```
┌──────────────────────────────────────┐
│ ✕   ━━━━ ━━━━ ━━── ──── ────   퀴즈  │
│ 기억으로 쓰기 2 / 6                  │  부 머리 줄
│ ┌────────┐ ┌───────────────────────┐ │
│ │        │◁│ 이 발음의 글자를      │ │  말풍선 (2줄, 작은 화면)
│ │  생각  │ │ 써 봐요               │ │
│ │  96pt  │ └───────────────────────┘ │
│ │        │       ka 🔊               │  발음(48pt). 기리는 그 왼쪽까지 (걸침)
│ └────────┘                           │
│     기억나는 대로 한 획씩 쓰세요     │  판정 줄(28pt)
│ ┌──────────────────────────────────┐ │
│ │       캔버스(십자 점선만)        │ │
│ └──────────────────────────────────┘ │
│ ┌───────────┐ ┌────────────────────┐ │
│ │가이드 보기│ │        다음        │ │
│ └───────────┘ └────────────────────┘ │
└──────────────────────────────────────┘
```

구성 요소(위에서 아래): 상단 바, 부 머리 줄, 기리 줄(전의 질문 줄 자리), 발음(로마자 48pt, 발음 소리가 켜져 있으면 눌러서 들을 수 있음), 판정 줄, 캔버스(가이드 획·시작점 번호·고리 원 없음, 십자 점선만), 아래 버튼 영역(왼쪽 "가이드 보기" 112pt, 오른쪽 "다음").

- 기리와 말풍선은 걸침 배치다(giri-companion.md 2.4.3). 기리 96pt를 왼쪽 여백 16pt에 두고, 말풍선은 기리 위 끝에 맞춰 오른쪽에, 발음 줄은 말풍선 아래 8pt에 화면 가운데로 둔다. 기리의 아래쪽은 발음 줄 왼쪽 빈자리(x 16~112)까지 내려온다. 블록 높이 = max(96, 말풍선 + 8 + 발음 58).
- 말풍선 줄 수: 4줄(블록 166pt)로 잡아도 캔버스가 화면 폭 − 32를 지키면 4줄, 아니면 2줄(블록 126pt). 문항 사이에 바뀌지 않는다. 375×667pt는 2줄이고 캔버스 319pt, 375×812pt는 4줄이고 343pt, 402×874pt는 4줄이고 370pt.

| 상태 | 판정 줄 | 캔버스 | 버튼 | 햅틱 | 기리 |
|---|---|---|---|---|---|
| 처음 | "기억나는 대로 한 획씩 쓰세요" (`InkSecondary`) | 십자 점선만 | 가이드 보기 활성, 다음 비활성 | 없음 | 생각, 질문(13.1) |
| 획 맞음 | `checkmark.circle.fill` "좋아요" | 맞은 획이 `Ink` 기준 획으로 | 변화 없음 | 가볍게 | 그대로 |
| 획 틀림 | `xmark.circle.fill` + 9번 문구 | 0.9초 `Wrong` 선. 고리를 빼먹었으면 `Wrong` 점선 원 | 변화 없음 | 오류 | 그대로 |
| 가이드 켜짐 | `lightbulb.fill` "가이드를 보고 따라 쓰세요" | 따라 쓰기와 같은 가이드. 맞게 쓴 획은 그대로 | 가이드 보기 비활성 | 없음 | 말하기, 그 글자의 쓰기 포인트(없으면 "가이드를 따라 같이 써 봐요"). 375×667pt에서는 2줄로 잘린다 |
| 완성(가이드 없이) | `checkmark.seal.fill` "완성, 기억으로 썼어요" | 모든 획 `Ink` | 다음 활성 | 성공 | 웃음 + 깡충, 말풍선 사라짐 |
| 완성(가이드를 봄) | `checkmark.seal.fill` "완성, 이 글자는 뒤에 한 번 더 나와요" | 모든 획 `Ink` | 다음 활성 | 성공 | 기본, 말풍선 사라짐 |

- 가이드가 켜지는 경우: "가이드 보기"를 누를 때, 한 글자에서 획을 3번 틀렸을 때(3번째 빨간 표시가 사라진 뒤).
- 가이드를 본 글자는 틀린 것으로 보고 이 부의 다시 풀기에 낸다(12.6). 가이드 없이 완성할 때까지 반복한다.
- 가이드 없이 완성했으면 도중에 획을 1~2번 틀렸어도 맞힌 것으로 본다.
- 캔버스 크기: 375×667pt에서 319pt(13.7, 기리 동행 개정 전 343pt, 크기 개정 뒤에도 같음). 402×874pt에서 370pt.
- 중간에 나갔을 때: 완성하고 "다음" 전에 나가도 결과는 저장한다. 완성 전이면 그 글자를 처음부터 다시 낸다. 이미 가이드를 봤다면 틀린 글자 기록은 남긴다.

### 13.5 QD 읽기 고르기 (유형 라)

목적: 장면의 단어를 보고 읽기(로마자)를 고른다. 글자 하나가 아니라 단어 단위로 읽는다.

```
답한 뒤 (정답)
┌──────────────────────────────────────┐
│ ✕   ━━━━ ━━━━ ━━━━ ━━── ────   퀴즈  │
│ 읽기 고르기 2 / 3                    │  부 머리 줄
│ ┌────────┐                           │
│ │  웃음  │                           │  기리 줄 (96pt 고정, 정답 뒤 말풍선 없음)
│ │  96pt  │                           │
│ └────────┘                           │
│                                      │  발음 표기 칸(20pt, 비어 있음)

│                오징어                │  답한 뒤: 뜻

│ ┌───────────────┐ ┌───────────────┐  │

└──────────────────────────────────────┘
```

- 문제: W의 단어 블록(10번 2) 그대로. 위 발음 표기 칸 20pt + 글자 56pt(줄 64pt), 기리 줄 아래 16pt, 가운데. 발음 표기 규칙은 W와 같고 기준 글자는 "이 장면의 글자 전부"다. 한자 칸(かつ丼의 丼 등)에는 표기가 붙는다. 표기가 붙는 칸이 있는 단어를 낼지와 그때의 오답은 `quiz-rules.md`가 정한다(표기된 부분이 오답을 가려내는 단서가 되지 않게).
- 답한 뒤 보이는 줄: 단어 아래 8pt에 뜻(`.body`, `InkSecondary`, 높이 26pt). 답하기 전에는 자리만 비워 둔다(문제가 움직이지 않게).
- 선택지: 2열 2행, 칸 높이 72pt, 로마자 `.title2`. 칸 안 글 폭 = 칸 폭 − 24pt(375pt에서 약 141pt). 가장 긴 목표 단어 읽기 "omotenashi"가 `.title2`로 약 125pt라 들어간다.
- 넘칠 때: 네 칸 가운데 하나라도 한 줄에 들어가지 않으면 그 문항은 QE의 한 줄 목록 배치(13.6)로 그린다. 문항마다 판단한다.
- 발음 소리: 답하기 전에는 재생하지 않는다. 답한 뒤 단어를 누르면 단어 전체를 읽는다.
- 문구 예: 오답 "정답은 ika예요". 이때 기리: ita를 골랐으면(か → た로 바꾼 오답) "이 단어의 か는 ka예요".
- 단어 그림은 답하기 전에도 뒤에도 쓰지 않는다. 그림은 뜻을 알려 줘 답의 단서가 되고, 답한 뒤에는 남는 공간(67pt)이 96pt보다 작다(word-art.md 5.1). C1·C2의 목표 단어 묶음에도 그림을 붙이지 않는다(word-art.md 5.2).

### 13.6 QE 뜻 고르기 (유형 마)

목적: 장면의 단어를 보고 뜻을 고른다. 현지에서 본 단어가 무엇인지 아는 것까지 확인한다.

```
답한 뒤 (오답)
┌──────────────────────────────────────┐

│ 이 단어의 뜻은?                      │  질문

│              た    こ                │  단어(56pt)
│                 tako                 │  답한 뒤: 읽기
│      ✕  정답은 문어예요              │  판정 줄
│ ┌──────────────────────────────────┐ │
│ │ 오징어                         ✕ │ │  선택지 한 줄 목록, 칸 높이 52pt
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ 문어                           ✓ │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ 초밥                             │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │

│ ┌──────────────────────────────────┐ │
│ │               다음               │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

- 문제: QD와 같은 단어 블록.
- 답한 뒤 보이는 줄: 단어 아래 8pt에 읽기(로마자 `.title3`, `InkSecondary`, 높이 26pt).
- 선택지: 1열 4행, 칸 높이 52pt, 칸 사이 12pt, 폭은 화면 폭 − 32. 뜻은 `.body`, `Ink`, 왼쪽 정렬, 안쪽 좌우 여백 16pt. 답한 뒤 아이콘(20pt)은 칸 오른쪽 끝에서 16pt 안쪽, 세로 가운데(2×2 칸의 오른쪽 위와 달리 한 줄 칸이라 오른쪽 가운데에 둔다).
- 1열로 둔 이유: 뜻이 2열 칸(글 폭 약 141pt)에 들어가지 않는다. 목표 단어 뜻 가운데 긴 것 "유부 올린 (소바·우동)", "당첨 (제비뽑기 결과)"은 17pt로 약 200~230pt다. 1열의 글 폭은 375pt에서 343 − 32 − 아이콘 자리 28 = 283pt.
- 뜻이 283pt를 넘으면 두 줄로 쓰고 그 칸만 높이를 늘린다(줄당 +22pt). 그만큼 위 문제와 판정 줄 사이의 남는 공간이 줄어든다.
- 발음 소리: 답하기 전에도 단어를 누르면 읽어 준다(소리는 뜻을 알려 주지 않는다).
- 문구 예: 오답 "정답은 문어예요", "정답은 돈가스덮밥이에요".

### 13.7 375×667pt에서 엄지 범위 확인

y는 화면 맨 위에서 잰 값. 안전 영역 위 20pt, 상단 바 20~64, 아래 버튼 영역 591~667(주 버튼 603~659). 엄지 범위 = y 333.5 아래(3번).

| 유형 | 선택지(또는 캔버스) 자리 | 맨 위 누르는 곳의 y | 엄지 범위 안 | 위쪽 내용(부 머리 줄 72~90, 기리 98~194 공통)과 남는 공간 |
|---|---|---|---|---|
| QA | 2×2, 72pt: 1행 435~507, 2행 519~591 | 435 | 들어감 (여유 101pt) | 기리 줄 98~194. 글자 202~362. 판정 줄 395~423. 남는 공간 33pt |
| QB (쓰지 않음) | 2×2, 88pt: 1행 403~491, 2행 503~591 | 403 | 들어감 (여유 69pt) | 기리 줄 98~194. 발음 202~260. 판정 줄 363~391. 남는 공간 103pt |
| QC | 캔버스 319pt: 272~591 | 272 | 캔버스 아래쪽 81%가 들어감 (기리 동행 개정 전 75%) | 걸침 배치: 말풍선 98~158, 기리 98~194(발음 줄 왼쪽). 발음 166~224. 판정 줄 232~260. 남는 공간 0pt |
| QD | 2×2, 72pt: 1행 435~507, 2행 519~591 | 435 | 들어감 (여유 101pt) | 기리 줄 98~194. 단어 210~294, 뜻 302~328. 판정 줄 395~423. 남는 공간 67pt |
| QE (쓰지 않음) | 1×4, 52pt: 347~399, 411~463, 475~527, 539~591 | 347 | 들어감 (여유 13.5pt) | 기리 줄 98~194. 단어 210~294, 읽기 302~328. 판정 줄 307~335와 겹친다(−21pt). 다시 쓰게 되면 문제 영역을 스크롤하거나 QE만 기리 80pt·줄 80pt로 줄인다 |

- 기리 줄(96pt)이 질문 줄(22pt)보다 74pt 높아 위쪽 내용이 74pt 내려갔다(3차의 60pt 기리 줄보다 36pt). 고르기 유형은 선택지가 아래에 고정이라 남는 공간만 줄고, QC는 걸침 배치라 3차와 같다(giri-companion.md 2.4.3, 3.8).
- 402×874pt(부 머리 줄 114~132, 기리 140~236): 고르기 유형의 선택지 608~764, QC 캔버스 394~764(370pt). 모두 엄지 범위(y 437 아래) 안이거나 캔버스 아래 88%가 범위 안이다.

- 선택지 칸의 가로: QA·QB·QD는 왼쪽 칸 x 16~181.5, 오른쪽 칸 x 193.5~359. QE는 x 16~359. 오른손 엄지에서 가장 먼 곳은 각 유형 첫 행의 왼쪽 위 모서리다(QE (16, 347), QB (16, 403)). 정답 자리는 섞이므로 특정 칸이 늘 멀지 않다.
- QE가 가장 빠듯하다. 뜻이 두 줄인 칸이 하나 생기면 첫 행이 y 325로 올라가 엄지 범위를 8.5pt 벗어난다. 이때는 칸 사이를 12pt에서 8pt로 줄인다(visual-rules.md 4.2의 최소 간격 8pt, 3곳에서 12pt 확보). 두 줄 칸이 둘 이상이면 판정 줄이 단어 블록 쪽으로 붙고 첫 행이 범위를 벗어나는 것을 받아들인다. 지금 히라가나 목표 단어의 뜻은 모두 한 줄이다.
- 세 유형 모두 누르는 대상은 44pt 이상(72, 88, 52pt)이고, 서로 다른 대상 사이는 12pt 이상이다.
- 402×874pt(아래 안전 영역 34): 아래 버튼 영역 764~840. QE 첫 행 y 520, QB 첫 행 y 576, 엄지 범위(y 437 아래) 안이다.
- 큰 글자 크기(`accessibility1` 이상): 선택지 칸의 높이를 글자에 맞춰 늘리고, 문제와 답하는 곳을 한 `ScrollView`로 묶는다. 아래 버튼 영역은 고정이다. QA·QB·QD의 로마자는 `minimumScaleFactor(0.8)`. 가나와 획 데이터 글자는 고정 크기다(visual-rules.md 2.4).

## 14. C2 장면 완료 (퀴즈 첫 통과)

목적: 장면 하나를 끝냈고 다음 장면이 열렸음을 알린다. 이번 퀴즈에서 헷갈린 글자가 다음 장면 퀴즈에 다시 나온다는 것을 알린다.

나오는 때: 종합 퀴즈를 처음 통과했을 때(12.6의 "완료").

```
┌──────────────────────────────────────┐
│ ┌────────┐  ┌──────────────────────┐ │
│ │ (기리) │ ◁│ 헷갈린 글자는 다음   │ │  기리 120pt + 체크 배지 + 말풍선
│ │        │  │ 여행지에서 또 봐요   │ │
│ └──────(✓)  └──────────────────────┘ │
│           스시집 장면 완료           │  제목
│     히라가나 6자를 읽고 쓸 수 있어요 │  요약
│   た, こ는 다음 장면 퀴즈에 다시 나와요│  틀린 글자 줄 (있을 때만)
│                                      │
│   이제 읽을 수 있는 스시집 단어      │  목표 단어 (장면 전체)
│          すし   いか   たこ          │
│                                      │
│  ¥ {받은 엔}엔을 받았어요 · 가진 엔 …│  리워드 묶음 (reward-flow.md 6)
│        새 아이템 2개가 열렸어요      │
│         [썸네일]     [썸네일]        │
│                                      │
│   다음 장면 '돈카츠집'이 열렸어요    │
│ ┌──────────────────────────────────┐ │
│ │           장면 목록으로          │ │  주 버튼
│ └──────────────────────────────────┘ │
│              기리 꾸미기             │  글자 버튼 (조건부)
└──────────────────────────────────────┘
```

구성 요소는 보상 브랜치의 reward-flow.md 6.2와 같고, 이 개정에서 바뀌는 값만 적는다.

| 요소 | 값 |
|---|---|
| 기리 줄 | C1(11번의 1)과 같다. 기리 120pt를 왼쪽에, 말풍선(최대 3줄)을 오른쪽에. 줄 높이 120pt라 reward-flow.md 6.4의 세로 계산은 그대로다. 문구: 틀린 글자 없음 "{장면}에서 본 글자, 이제 다 읽혀요", 틀린 글자가 다음 장면 퀴즈에 섞임 "헷갈린 글자는 다음 여행지에서 또 봐요", 히라가나 8장면 완료 "히라가나 여행을 다 마쳤어요. 같이 와서 즐거웠어요"(giri-companion.md 3.11) |
| 제목 | "{장면} 장면 완료" (스시집 장면 완료) |
| 요약 | "히라가나 {N}자를 읽고 쓸 수 있어요". N은 장면의 새 글자 수(스시집 6) |
| 틀린 글자 줄 (새로) | 이번 퀴즈에서 틀린 글자(12.1)가 있을 때만. 요약 아래 4pt, `.subheadline`, `Ink`, 가운데, 높이 20pt. 문구는 아래 |
| 목표 단어 묶음 | 머리 "이제 읽을 수 있는 {장면} 단어", 단어는 4.4의 "장면의 목표 단어". 스시집: すし, いか, たこ (164pt, 한 줄) |
| 받은 엔 줄 | 퀴즈 세션 첫 완료분 `{받은 엔}`(100엔). 히라가나 마지막 장면이면 마일스톤과 합친 값(reward-flow.md 6.3) |
| 열린 아이템 | 그 장면의 아이템 |
| 다음 장면 줄 | "다음 장면 '{장면}'이/가 열렸어요". 마지막 장면(료칸)은 줄 없음 |
| 장면 글자 줄 | 넣지 않는다(reward-flow.md 6.2의 4). 틀린 글자는 글자 줄의 점 대신 문구로 알린다 |

틀린 글자 줄의 문구:

| 경우 | 문구 |
|---|---|
| 다음 장면 퀴즈에 섞이는 경우 (12.1, quiz-rules.md) | {글자들}는 다음 장면 퀴즈에 다시 나와요 |
| 다음 장면 퀴즈에 섞이지 않는 경우 (마지막 히라가나 장면 등) | 헷갈린 글자 {글자들} |

- 글자 사이는 ", ". 조사 "는/은"은 마지막 글자의 발음으로 고른다(ん이면 "은").
- 폭: "た, こ, す는 다음 장면 퀴즈에 다시 나와요" 15pt로 약 290pt. 343pt를 넘으면 두 줄(+20pt).

세로 계산: 틀린 글자 줄이 있으면 +24pt(4 + 20). 대신 그때만 묶음 사이 간격 세 곳(요약 → 목표 단어, 목표 단어 → 리워드, 리워드 → 다음 장면)을 24pt에서 16pt로 줄여 −24pt. 나머지 합계는 reward-flow.md 6.4의 488pt 그대로라 375×667pt에서 글자 버튼이 있어도 523/523pt로 들어간다. 틀린 글자 줄이 두 줄이면 20pt 넘쳐 내용 영역이 스크롤된다. 버튼은 고정이다.

- 상태: 나타날 때 성공 햅틱 한 번과 기리 등장 움직임, 0.15초 뒤 말풍선 뜨기. 틀린 글자가 있어도 웃는 표정이다(visual-rules.md 7.2).
- 전환: "장면 목록으로" → 덮개를 닫고 스택을 홈까지 되돌린다. "기리 꾸미기" → 덮개를 닫고 홈 위에 K(reward-flow.md 2.2).
- 중간에 나갔을 때: 퀴즈 통과, 장면 완료, 다음 장면 열림, 틀린 글자 기록, 보상 지급은 마지막 문항의 "완료"에서 한 번에 저장한다. 이 화면은 다시 보여 주지 않는다.

## 16. 저장해야 하는 상태

저장 방식과 형식 버전 번호는 개발 담당이 정한다. 예전 진도는 비우고, 엔과 아이템은 남긴다(PLAN.md 3번 "리워드 아이템").

| 항목 | 값 | 쓰는 화면 |
|---|---|---|
| 세션별 완료 여부 | 세션 id(`{장면}-a`, `{장면}-b`, `{장면}-quiz`) → 완료/미완료 | H, S, 잠금, C1·C2 분기, 보상 지급 키 |
| 단계 세션 진행 | 배우기에서 끝낸 글자(`learnDone`), 단어 읽기에서 끝낸 단어(`wordsDone`) | S의 "이어서", 2.5, 4.4 |
| 퀴즈 세션 진행 | 정해 둔 문항 목록(부 순서, 부마다 문항의 유형과 대상 글자·단어), 지금 부, 부마다 끝낸 문항과 다시 낼 문항, 이번 퀴즈의 틀린 글자, 손댄 적 있는지 | S의 "이어서", 2.5, 12.4의 k/m, 상단 바 |
| 장면별 틀린 글자 | 장면 id → 글자 목록 (퀴즈 첫 통과 때 확정) | C2, 다음 장면 퀴즈의 복습 글자, S·QI의 복습 수 |
| 발음 소리 | 켜짐/꺼짐, 기본 켜짐 | H 메뉴, 글자를 누를 수 있는 모든 화면 |

- 지금 구현(`StepProgress`의 `quiz`, `quizWrong`)에서 퀴즈 진행을 단계에서 떼어 퀴즈 세션으로 옮긴 것이다. 단계 진행에는 퀴즈 값이 없다.
- 퀴즈의 문항 목록은 처음 시작할 때(QI의 "퀴즈 시작") 한 번 만들어 저장한다. 이어 할 때 문항이 바뀌지 않게 하기 위해서다. 선택지 섞기는 저장하지 않아도 된다.
- 다시 하는 세션의 진행은 저장하지 않는다(2.5). 메모리에만 두고, 덮개를 닫으면 버린다.
- 보상 지급(reward-flow.md 11.2의 `RewardGrant`)은 세션 첫 완료마다 한 번: 단계 a, 단계 b, 퀴즈 각 100엔. 퀴즈 첫 통과 때 장면 아이템이 열린다.

## 17. 결정이 필요한 것

PM이 정할 것만 둔다. 화면은 아래 "그린 모양"대로 그렸고, 다르게 정하면 적은 곳만 바꾸면 된다.

| 번호 | 정해야 하는 것 | 그린 모양 | 왜 PM이 정해야 하나 | 다르게 정하면 |
|---|---|---|---|---|
| 1 | (풀림) 퀴즈 안내(QI)에 기리를 둘지 | 기리 동행 결정(2026-11-14)으로 QI를 포함한 모든 세션 화면에 기리를 둔다(12.5, giri-companion.md) | | |
| 2 | 종합 퀴즈 세션의 길이 | 예시 24문항, 약 3.8분(12.7). 도중에 나가도 문항 단위로 이어 하고, QI에서 그것을 알린다 | PLAN.md 3번 "한 세션 2~3분"을 넘는다. 문항 수는 planner가 `quiz-rules.md`에서 정하지만, 상한을 지킬지 넘길지는 기획 기준을 바꾸는 일이다 | 3분 안으로 줄이면 문항 수만 바뀌고 화면은 그대로다(부 수 1~5, 문항 1~30 모두 같은 규칙). 한 부를 빼면 상단 바 칸이 줄 뿐이다 |

### 17.1 이 개정으로 함께 바뀌는 기획 문서 문구 (PM 반영용)

결정이 아니라, 이미 내려진 PM 결정과 문구를 맞추는 일이다.

- PLAN.md 3번 "퀴즈 방식"(사지선다만 적혀 있음), "쓰기 난이도"(퀴즈의 기억으로 쓰기), "세션 진행"(단계 세션 안의 퀴즈), "복습"(다음 장면 퀴즈), "진도 구조"(두 단계를 끝내면 다음 장면): 종합 퀴즈 세션 기준으로 고친다.
- PLAN.md 5번 "장면 하나의 흐름"의 2번(퀴즈): 단계 세션에서 빼고 장면 끝 세션으로 옮긴다.
- PLAN.md 8번의 "흐름 개편에 맞춘 리워드 조정 … 재화 지급 단위": 세션 3개 × 100엔으로 풀렸다.
- scene-art/brief.md 2.2의 장면 행 오른쪽 "0/2", "1/2"는 "0/3"~"2/3"이 된다(designer가 다음 개정 때 고친다).

### 17.2 전 개정의 채택안 가운데 바뀐 것

2026-11-14에 채택된 1~13번 가운데 이 개정으로 바뀐 것: 2(P2·P3 안내 화면 → 없앰, 마지막 글자의 주 버튼 문구로 대신), 3(3칸 막대 → 단계 2칸, 퀴즈는 부 수만큼), 5(단계 b 끝은 C2 → C1, C2는 퀴즈 통과), 8(오답 선택지 순서 → quiz-rules.md), 9(틀린 글자 안내 P3 → C2), 13(C1 목표 단어 묶음 → 그대로 두고 단계 b C1에도 넣음). 나머지(1 밥집 묶음 제목 없음, 4 단계 a C1의 주 버튼, 6 다시 할 때 저장 안 함, 7 S의 새 글자 줄 뺌, 10 홈 장면 행 둘째 줄, 11 id 규칙에 `{장면}-quiz` 추가, 12 か 문구)는 그대로다.
